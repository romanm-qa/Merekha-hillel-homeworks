# Python Fundamentals

## Что такое Python

Python — это высокоуровневый язык программирования.

Он считается одним из самых популярных языков благодаря простому синтаксису и широкому применению:
- Backend разработка
- Автоматизация тестирования
- Data Science
- Искусственный интеллект
- Скрипты и автоматизация задач

---

## Интерпретируемый и компилируемый язык

### Компилируемый язык

Перед запуском исходный код переводится в машинный код с помощью компилятора.

Схема работы:

Source Code → Compiler → Executable File → Program

Примеры:
- C
- C++
- Go
- Rust

### Интерпретируемый язык

Код выполняется интерпретатором во время запуска программы.

Схема работы:

Source Code → Interpreter → Program

Примеры:
- Python
- JavaScript
- Ruby

Python относится к интерпретируемым языкам.

## Типизация в Python

Python обладает:

- динамической типизацией (Dynamic Typing)
- строгой типизацией (Strong Typing)

---

## Динамическая типизация

Динамическая типизация означает, что программисту не нужно заранее указывать тип переменной.

Python сам определяет тип на основе присвоенного значения.

Пример:

```python
name = "Roman"
age = 29
price = 99.99
is_active = True
```

Python автоматически определит тип каждой переменной.

Также одна и та же переменная может хранить значения разных типов:

```python
value = 10
value = "Hello"
```

Это возможно благодаря динамической типизации.

---

## Строгая типизация

Строгая типизация означает, что Python не выполняет автоматическое преобразование несовместимых типов данных.

Например:

```python
print(5 + "2")
```

Результат:

```python
TypeError
```

Python не понимает, нужно ли:
- превратить число в строку
- или строку в число

Поэтому выбрасывает ошибку.

Правильный вариант:

```python
print(5 + int("2"))
```

или

```python
print(str(5) + "2")
```

---

## Динамическая и строгая типизация одновременно

Это разные характеристики языка.

Динамическая типизация отвечает за определение типа переменной.

Строгая типизация отвечает за взаимодействие различных типов данных между собой.

Поэтому Python одновременно является:

- динамически типизированным языком
- строго типизированным языком

## Основные типы данных

### int

Целые числа.

Примеры:

```python
age = 29
count = 100
```

### float

Числа с плавающей точкой.

Примеры:

```python
price = 99.99
temperature = 36.6
```

### str

Строковый тип данных.

Примеры:

```python
name = "Roman"
city = "Kyiv"
```

### bool

Логический тип данных.

Может принимать только два значения:

```python
True
False
```

Пример:

```python
is_active = True
is_admin = False
```

---

## Проверка типа данных

Для определения типа используется функция:

```python
type()
```

Пример:

```python
name = "Roman"

print(type(name))
```

Результат:

```python
<class 'str'>
```
