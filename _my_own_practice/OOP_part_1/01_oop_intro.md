# Object-Oriented Programming (OOP)

## Парадигмы программирования

Парадигма программирования — это стиль или подход к написанию программ.

Основные парадигмы:

### 1. Процедурное программирование

Программа состоит из последовательности инструкций, функций и процедур.

Пример:

```python
def greet(name):
    print(f"Hello, {name}")

greet("Roman")
```

### 2. Объектно-ориентированное программирование (OOP)

Программа строится вокруг объектов.

Объект объединяет:

- данные (атрибуты)
- поведение (методы)

Пример:

```python
class User:
    pass
```

### 3. Функциональное программирование

Основной акцент делается на функциях и обработке данных.

Пример:

```python
numbers = [1, 2, 3]

squared = list(map(lambda x: x ** 2, numbers))
```

---

## Что такое ООП

Object-Oriented Programming (ООП) — это парадигма программирования, в которой программа строится вокруг объектов.

ООП помогает:

- структурировать код
- переиспользовать код
- упрощать поддержку проекта
- описывать реальные сущности в виде объектов

---

## Основные понятия ООП

### Класс (Class)

Класс — это шаблон для создания объектов.

Пример:

```python
class Car:
    pass
```

### Объект (Object)

Объект — это экземпляр класса.

Пример:

```python
my_car = Car()
```

---

## Четыре принципа ООП

### 1. Инкапсуляция (Encapsulation)

Скрытие внутренней реализации объекта.

### 2. Наследование (Inheritance)

Создание нового класса на основе существующего.

### 3. Полиморфизм (Polymorphism)

Разные объекты могут иметь одинаковый интерфейс, но разное поведение.

### 4. Абстракция (Abstraction)

Сокрытие лишних деталей и отображение только важного.
