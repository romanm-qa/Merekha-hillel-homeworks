# Условия Python — вопросы для собеседования

Сначала ответь самостоятельно, затем сверься с ответом. Примеры «Что выведет код?» разбирай без запуска.

## if, elif, else и pass

### 1. Для чего нужны условия?

Чтобы выбирать действия в зависимости от истинности выражений или значений.

### 2. Как работают if, elif и else?

`if` проверяет первое условие. `elif` проверяет следующее, если предыдущие не подошли. `else` выполняется, если ни одно условие цепочки не подошло.

### 3. Обязательны ли elif и else?

Нет. Можно использовать только `if`, `if/else`, `if/elif` или полную цепочку `if/elif/else`.

### 4. Сколько веток выполняется в одной цепочке if/elif/else?

Только первая подходящая. Если подходящей нет и `else` отсутствует, не выполнится ни одна ветка.

### 5. Чем несколько if отличаются от if/elif?

Отдельные `if` проверяются независимо: могут выполниться несколько блоков. В цепочке после первого истинного условия остальные условия не проверяются.

### 6. Почему порядок условий важен?

Первое подходящее условие завершает выбор ветки. Если поставить слишком широкое условие раньше узкого, узкая ветка может никогда не выполниться.

```python
score = 95
if score >= 60:
    print("Зачтено")
elif score >= 90:
    print("Отлично")
```

Выведется «Зачтено». Ветку `score >= 90` нужно поставить раньше.

### 7. К какому if относится else?

К своей конструкции `if` на соответствующем уровне отступа. Он не относится автоматически ко всем предыдущим независимым `if`.

### 8. Зачем нужны двоеточие и отступы?

Двоеточие открывает блок, отступы определяют его границы и вложенность. Обычно используют четыре пробела на уровень.

### 9. Что делает pass?

Ничего. Это заглушка для синтаксически обязательного блока. `pass` не завершает программу и не пропускает последующий код.

### 10. Можно ли написать условие после else?

Нет. Для дополнительного условия нужен `elif`. Запись `else age < 18:` неверна.

## Истинность значений

### 11. Должно ли условие обязательно быть сравнением?

Нет. Python может проверить истинность объекта напрямую: например, `if users:`.

### 12. Что означают truthy и falsy?

Truthy-значение считается истинным при проверке условия, falsy — ложным. Это характеристика поведения в условии; сам объект не обязан иметь тип `bool`.

### 13. Какие изученные значения falsy?

`False`, `None`, числовой ноль и пустые строки и коллекции: `''`, `[]`, `()`, `{}`, `set()`, `frozenset()`.

### 14. Что возвращает bool()?

`True` или `False` в соответствии с истинностью переданного объекта. Вызов `bool()` без аргументов возвращает `False`.

### 15. Является ли отрицательное число falsy?

Нет. Ненулевые числа, включая отрицательные, truthy.

### 16. Чему равны bool('False'), bool('0') и bool(' ')?

Все три результата — `True`: строки непустые. `bool()` не интерпретирует текст строки как логическое значение или число.

### 17. Почему bool([0]) равно True?

Список непустой. Истинность списка не зависит от истинности его отдельных элементов.

### 18. Чем if value отличается от if value is not None?

Первое проверяет истинность, второе — что значение не является `None`. Ноль, пустая строка и пустой список проходят вторую проверку, но не первую.

### 19. Как правильно проверить None?

Через `value is None` или `value is not None`.

### 20. Как проверить, что список пуст?

Если переменная содержит список, удобно использовать `if not items:`. Для непустого списка — `if items:`.

## Сравнения и логические операторы

### 21. Чем = отличается от ==?

`=` присваивает значение. `==` сравнивает значения.

### 22. Какие операторы сравнения ты знаешь?

`==`, `!=`, `<`, `>`, `<=`, `>=`. Для обычных чисел сравнения возвращают `bool`.

### 23. Чем > отличается от >=?

`>` не включает равенство, `>=` включает. При `age = 18` выражение `age > 18` ложно, а `age >= 18` истинно.

### 24. Что означает 0 <= number < 10?

Число не меньше 0 и меньше 10. Нижняя граница включена, верхняя исключена. Для переменной-числа соответствует `number >= 0 and number < 10`.

### 25. Есть ли особенность вычисления цепочек сравнений?

Выражение между сравнениями вычисляется один раз. Если одно сравнение ложно, следующие части цепочки не вычисляются.

### 26. Чем == отличается от is?

`==` сравнивает значения, `is` проверяет идентичность объектов. Для обычного сравнения строк и чисел нужен `==`; для проверки `None` — `is None`.

### 27. Когда условие с and истинно?

Когда оба операнда truthy. В цепочке из нескольких операндов — когда все truthy.

### 28. Когда условие с or истинно?

Когда хотя бы один операнд truthy.

### 29. Что делает not и что возвращает?

Отрицает истинность операнда и всегда возвращает `bool`: `not 0` — `True`, `not 5` — `False`.

### 30. Какой приоритет у сравнений, not, and и or?

В рассматриваемых выражениях: сравнения → `not` → `and` → `or`. Скобки задают нужную группировку.

### 31. Что такое короткое замыкание?

Правый операнд не вычисляется, когда выбор результата уже определён левым. У `and` это происходит при falsy слева, у `or` — при truthy слева.

### 32. Как короткое замыкание помогает избежать деления на ноль?

Защитная проверка должна стоять первой:

```python
divisor = 0
result = divisor != 0 and 10 / divisor > 2
print(result)  # False
```

Левая часть ложна, поэтому деление не выполняется.

### 33. Всегда ли and и or возвращают bool?

Нет, они возвращают один из операндов.

| Выражение | Возвращаемое значение |
| --- | --- |
| `a and b` | `a`, если `a` falsy; иначе `b` |
| `a or b` | `a`, если `a` truthy; иначе `b` |

### 34. Что возвращает длинная цепочка and или or?

`and` — первый falsy-операнд либо последний, если все truthy. `or` — первый truthy-операнд либо последний, если все falsy. Остаток цепочки после найденного результата не вычисляется.

### 35. Чем value or default отличается от замены только None?

`or` выбирает default для любого falsy-значения, включая 0 и пустые коллекции. Для замены только `None` нужна явная проверка:

```python
score = 0
result = score if score is not None else 100
print(result)  # 0
```

### 36. Почему if choice == 1 or 2 — ошибка логики?

Выражение читается как `(choice == 1) or 2`. При ложном сравнении возвращается truthy-число 2, поэтому условие всё равно проходит.

Правильно: `choice == 1 or choice == 2` или `choice in (1, 2)`.

### 37. Можно ли заменить and и or на & и |?

Для обычных логических проверок этого делать не следует. `and` и `or` используют истинность и короткое замыкание. `&` и `|` — другие операторы: например, побитовые для целых чисел и операции над множествами для `set`.

## Условное выражение

### 38. Как записывается условное выражение?

`value_if_true if condition else value_if_false`.

```python
age = 20
status = "Adult" if age >= 18 else "Minor"
```

### 39. Что вычисляется первым в условном выражении?

Условие, затем только выбранная ветка.

### 40. Обязателен ли else в условном выражении?

Да. Выражение должно выбирать значение для обоих исходов.

### 41. Когда лучше использовать обычный if/else?

Когда в ветке несколько действий или логика становится сложной для чтения. Условное выражение удобно для простого выбора значения.

## match/case

### 42. Для чего нужен match/case?

Для сопоставления значения с образцами. Простые образцы — конкретные числа и строки. Более сложные могут описывать структуру данных.

### 43. С какой версии доступен match/case?

С Python 3.10.

### 44. Сколько веток case выполняется?

В простых примерах — только первая подходящая. Автоматического перехода в следующую ветку нет, `break` не нужен.

### 45. Что означает case _?

Запасной образец, подходящий для любого значения. Его ставят последним. `_` не связывает значение с переменной.

### 46. Что произойдёт, если ни один case не подошёл и case _ отсутствует?

Ни одна ветка не выполнится. Выполнение продолжится после `match`.

### 47. Как объединить несколько вариантов в case?

Через `|`, например `case "start" | "run":`.

### 48. Одинаковы ли case 1 и case '1'?

Нет. Один сопоставляет с числом, другой — со строкой. `input()` возвращает строку.

### 49. Чем case 'start' отличается от case start?

Первый сопоставляет со строкой. Второй захватывает проверяемое значение в переменную `start`, а не сравнивает с её прежним содержимым.

### 50. Можно ли простой match/case заменить if/elif/else?

Да, выбор конкретных значений можно выразить через сравнения в цепочке. Выбор записи зависит от ясности кода.

## Вложенные условия

### 51. Что такое вложенный if?

Проверка внутри блока другой условной конструкции. Она выполняется только тогда, когда выполнение дошло до содержащей её ветки.

### 52. Когда вложенные if можно заменить and?

Когда требуется выполнить действие при одновременном выполнении условий. Если нужны разные действия для разных причин отказа, вложенные проверки или отдельная цепочка могут быть удобнее.

### 53. В чём ошибка двух отдельных if при определении знака числа?

В записи `if y < 0`, затем `if y > 0 ... else ...` последний `else` относится только ко второму `if`. При отрицательном `y` выведутся и сообщение об отрицательном числе, и сообщение из `else`. Нужна цепочка `if/elif/else`.

## Что выведет код?

### 54. Независимые проверки

```python
number = 12
if number > 0:
    print("Positive")
if number % 2 == 0:
    print("Even")
```

Ответ:

```text
Positive
Even
```

### 55. Связь else с if

```python
choice = 2
if choice == 2:
    print("Option 2")
if choice == 3:
    print("Option 3")
else:
    print("Unknown")
```

Ответ:

```text
Option 2
Unknown
```

### 56. Пустота и содержимое списка

```python
items = [False]
print(bool(items))
print(bool(items[0]))
```

Ответ:

```text
True
False
```

### 57. Возврат операндов

```python
print("" or "Guest")
print("Roman" and "Ready")
print(0 and 100)
print(not [])
```

Ответ:

```text
Guest
Ready
0
True
```

### 58. Приоритет

```python
print(True or False and False)
print((True or False) and False)
```

Ответ:

```text
True
False
```

### 59. Проверка None

```python
score = 0
if score:
    print("Truthy")
if score is not None:
    print("Provided")
```

Ответ: только `Provided`.

### 60. Вычисление выбранной ветки

```python
divisor = 0
result = 10 / divisor if divisor != 0 else "No division"
print(result)
```

Ответ: `No division`. Деление не вычисляется.

### 61. Тип значения в match

```python
choice = "1"
match choice:
    case 1:
        print("Number")
    case "1":
        print("String")
    case _:
        print("Other")
```

Ответ: `String`.

### 62. Логическая ошибка с or

```python
choice = 3
result = choice == 1 or 2
print(result)
print(bool(result))
```

Ответ:

```text
2
True
```

## Задачи для самостоятельной практики

Решения здесь не приведены. Сначала запиши условия своими словами, затем код. Пока можно решать обычными блоками, без функций и циклов.

1. По числу определить: положительное, отрицательное или ноль.
2. По возрасту и наличию билета вывести разрешение на вход либо конкретную причину отказа. Вход разрешён с 18 лет при наличии билета.
3. По баллам от 0 до 100 определить результат: от 90 — «Отлично», от 75 — «Хорошо», от 60 — «Зачтено», ниже — «Не зачтено». Значения вне диапазона обработать отдельно.
4. По команде через `match/case` обработать `start`/`run`, `stop`/`exit` и неизвестную команду.
5. Если результат равен `None`, вывести «Не получен». Иначе вывести результат, включая допустимый 0.
6. Проверить право редактирования: пользователь должен быть администратором или владельцем и при этом не должен быть заблокирован.
7. Проверить, входит ли число в диапазон от 0 включительно до 10 исключительно и является ли оно чётным.

Для числовых границ проверяй значения ниже границы, на ней и выше неё. Для логических условий — разные сочетания True и False.
