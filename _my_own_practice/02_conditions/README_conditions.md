## 1. if, elif и else

| Конструкция | Когда выполняется |
| --- | --- |
| `if условие:` | Если условие истинно |
| `elif условие:` | Если предыдущие условия цепочки ложны, а это истинно |
| `else:` | Если ни одно условие цепочки не подошло |

После условия ставится двоеточие. Блок выделяется отступом — обычно четыре пробела. У `else` собственного условия нет. `elif` и `else` необязательны.

```python
score = 85
print(f"Исходные баллы: {score!r}")
if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Зачтено")
else:
    print("Не зачтено")
```

Выведется «Хорошо». В цепочке выполняется только первая подходящая ветка. После неё остальные условия этой цепочки не проверяются.

Порядок проверок важен: если сначала поставить `score >= 60`, то при 85 баллах сразу выполнится эта ветка.

### Независимые if и цепочка if/elif

```python
number = 12
if number > 0:
    print("Положительное")
if number % 2 == 0:
    print("Чётное")
```

Выведутся обе строки: каждый `if` проверяется отдельно.

```python
number = 12
if number > 0:
    print("Положительное")
elif number % 2 == 0:
    print("Чётное")
```

Выведется только «Положительное».

| Задача | Подход |
| --- | --- |
| Выполнить все подходящие независимые действия | Несколько `if` |
| Выбрать один вариант | `if/elif/else` |
| Проверить что-то внутри выбранной ветки | Вложенный `if` |

### К какому if относится else

`else` относится к своей конструкции `if` на соответствующем уровне отступа, а не ко всем предыдущим проверкам.

```python
choice = 2
if choice == 1:
    print("Вариант 1")
if choice == 2:
    print("Вариант 2")
if choice == 3:
    print("Вариант 3")
else:
    print("Нет такой опции")
```

Выведутся «Вариант 2» и «Нет такой опции». Последний `else` связан только с `if choice == 3`.

Для такого выбора удобнее цепочка `if/elif/else`. При отдельных `if` запасной вариант можно проверить через `if choice not in (1, 2, 3)`.

### pass

`pass` — инструкция-заглушка, которая ничего не делает. Она позволяет оставить обязательный блок без действий.

```python
age = 20
if age >= 18:
    pass
print("Выполнение продолжается")
```

`pass` не завершает программу и не прекращает выполнение последующего кода.

## 2. Truthy и falsy

Условие не обязательно должно содержать сравнение. Python может проверить истинность самого объекта. `bool(value)` явно показывает результат этой проверки.

| Значение | Истинность |
| --- | --- |
| `False`, `None` | Falsy |
| Числовой ноль: `0`, `0.0` | Falsy |
| Пустая строка `''` | Falsy |
| Пустые коллекции: `[]`, `()`, `{}`, `set()`, `frozenset()` | Falsy |
| Ненулевые числа, включая отрицательные | Truthy |
| Непустые строки и коллекции | Truthy |
| `True` | Truthy |

```python
users = []
print(f"Исходный список: {users!r}")
if users:
    print("Есть пользователи")
else:
    print("Список пуст")
```

Проверка `if not users` позволяет выполнить блок, когда список пуст.

### Частые неожиданности

```python
print(bool("0"))      # True
print(bool("False"))  # True
print(bool(" "))      # True
print(bool([0]))      # True
print(bool(0))        # False
```

Строка с пробелом непустая. Текст `'False'` не превращается в логическое `False` через `bool()`. Список `[0]` содержит элемент, поэтому его истинность — `True`, независимо от истинности самого элемента.

### Проверка None

Для проверки именно отсутствующего значения используем `is None` или `is not None`.

```python
score = 0
print(bool(score))        # False
print(score is not None)  # True
```

`if score` проверяет истинность. `if score is not None` проверяет, что значение не является `None`. Это важно, если ноль, пустая строка или пустая коллекция допустимы как переданные данные.

## 3. Сравнения и логические операторы

### Операторы сравнения

Для обычных чисел результат сравнения — `True` или `False`.

| Оператор | Значение | Пример |
| --- | --- | --- |
| `==` | Равно | `10 == 10` → `True` |
| `!=` | Не равно | `10 != 20` → `True` |
| `<` | Меньше | `10 < 20` → `True` |
| `>` | Больше | `10 > 20` → `False` |
| `<=` | Меньше или равно | `18 <= 18` → `True` |
| `>=` | Больше или равно | `18 >= 18` → `True` |

`=` присваивает значение, `==` сравнивает значения. `is` проверяет, один ли это объект; для обычного сравнения чисел и строк используем `==`.

### Цепочки сравнений

```python
number = 7
print(0 <= number < 10)             # True
print(number >= 0 and number < 10)  # True
```

Диапазон включает 0 и не включает 10. Цепочка сравнений проверяется слева направо с коротким замыканием; выражение в середине вычисляется один раз.

### and, or, not

| Оператор | Когда результат считается истинным |
| --- | --- |
| `a and b` | Оба операнда truthy |
| `a or b` | Хотя бы один операнд truthy |
| `not a` | Операнд `a` falsy |

Для логических значений:

| `a` | `b` | `a and b` | `a or b` |
| --- | --- | --- | --- |
| `False` | `False` | `False` | `False` |
| `False` | `True` | `False` | `True` |
| `True` | `False` | `False` | `True` |
| `True` | `True` | `True` | `True` |

```python
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("Вход разрешён")
```

### Приоритет и скобки

В рассматриваемых выражениях порядок такой: **сравнения → not → and → or**. Скобки задают нужную группировку.

```python
is_admin = True
is_owner = False
is_blocked = True

print(is_admin or is_owner and not is_blocked)    # True
print((is_admin or is_owner) and not is_blocked)  # False
```

Во втором варианте отсутствие блокировки обязательно и для администратора, и для владельца.

### Короткое замыкание

Python не вычисляет правый операнд, если результат выбора уже определён левым:

- Для `and`: если слева falsy, справа не вычисляется.
- Для `or`: если слева truthy, справа не вычисляется.

```python
divisor = 0
print(divisor != 0 and 10 / divisor > 2)  # False
print(divisor == 0 or 10 / divisor > 2)   # True
```

Оба примера не вызывают деление на ноль: правая часть не выполняется. Порядок проверок важен — защита должна стоять перед делением.

### and и or возвращают операнды

Они не обязаны возвращать `bool`. Для двух операндов:

| Выражение | Что возвращает |
| --- | --- |
| `a and b` | `a`, если он falsy; иначе `b` |
| `a or b` | `a`, если он truthy; иначе `b` |
| `not a` | Всегда `True` или `False` |

```python
print("" or "Guest")       # 'Guest'
print("Roman" or "Guest")  # 'Roman'
print("" and "Guest")      # ''
print("Roman" and "Guest") # 'Guest'
```

В длинной цепочке `and` возвращает первый falsy-операнд или последний операнд, если все truthy. `or` возвращает первый truthy-операнд или последний, если все falsy.

### Значение по умолчанию через or

```python
score = 0
result = score or 100
print(result)  # 100

result = score if score is not None else 100
print(result)  # 0
```

`or` выбирает запасное значение для любого falsy-операнда. Если нужно заменить только `None`, используй явную проверку.

### Ошибка: choice == 1 or 2

```python
choice = 3
wrong_result = choice == 1 or 2
print(wrong_result)        # 2
print(bool(wrong_result))  # True
```

Это выражение означает `(choice == 1) or 2`. Число 2 считается истинным, поэтому такая проверка не подходит для выбора между 1 и 2.

Правильно:

```python
choice = 3
print(choice == 1 or choice == 2)  # False
print(choice in (1, 2))           # False
```

## 4. Условное выражение

Выбирает одно из двух значений:

```python
age = 20
status = "Совершеннолетний" if age >= 18 else "Несовершеннолетний"
print(f"Возраст: {age!r}, статус: {status!r}")
```

Общая форма: `значение_если_истина if условие else значение_если_ложь`.

Сначала вычисляется условие, затем только выбранная ветка. `else` здесь обязателен.

Обычная запись того же выбора:

```python
age = 20
if age >= 18:
    status = "Совершеннолетний"
else:
    status = "Несовершеннолетний"
```

Условное выражение удобно для простого выбора значения. Для нескольких действий в ветке или сложной логики лучше обычный `if/elif/else`.

## 5. match/case

`match/case` сопоставляет значение с образцами. В наших примерах образцы — конкретные числа и строки.

```python
choice = 2
print(f"Исходный выбор: {choice!r}")
match choice:
    case 1:
        print("Вариант 1")
    case 2:
        print("Вариант 2")
    case 3:
        print("Вариант 3")
    case _:
        print("Нет такой опции")
```

Выполняется первая подходящая ветка. Перехода в следующие ветки нет, `break` не нужен.

- `case _` — запасной вариант, подходящий для любого значения; ставим его последним.
- `_` не сохраняет проверяемое значение.
- Если подходящей ветки нет и `case _` отсутствует, ни один блок не выполнится. Программа продолжит работу после `match`.
- `match/case` доступен с Python 3.10.

### Несколько образцов в одной ветке

```python
command = "exit"
match command:
    case "start" | "run":
        print("Запуск")
    case "stop" | "exit":
        print("Остановка")
    case _:
        print("Неизвестная команда")
```

Здесь `|` объединяет альтернативные образцы.

### Число и строка

`case 1` и `case "1"` различаются. `input()` возвращает строку: чтобы сравнивать введённое значение с числовыми образцами, требуется преобразование, например `int()`.

### Имя в case — не сравнение с переменной

`case "start":` сопоставляет со строкой. Обычное имя в `case start:` захватывает значение в переменную `start`, а не проверяет равенство с ранее заданной переменной.

Для простого выбора конкретных значений подходит и `if/elif/else`. Возможности `match/case` шире: сопоставление структур коллекций относится к дальнейшему изучению.

## 6. Вложенные условия

Вложенная проверка находится внутри выбранной внешней ветки.

```python
age = 20
has_ticket = False
print(f"Возраст: {age!r}, есть билет: {has_ticket!r}")
if age >= 18:
    if has_ticket:
        print("Вход разрешён")
    else:
        print("Нужен билет")
else:
    print("Вход только с 18 лет")
```

При возрасте меньше 18 проверка билета не выполняется. Внутренний `else` отвечает за билет, внешний — за возраст. Связь определяется отступами.

### Вычисление после проверки диапазона

```python
x = 1
if 0 <= x < 11:
    y = 3 * x - 6
    print(f"x: {x!r}, y: {y!r}")
    if y < 0:
        print("Отрицательное")
    elif y > 0:
        print("Положительное")
    else:
        print("Ноль")
else:
    print("x вне диапазона")
```

Для выбора знака нужна одна цепочка. Если написать отдельный `if y < 0`, затем `if y > 0 ... else ...`, при отрицательном `y` выполнятся и первая ветка, и последний `else`.

### Когда достаточно and

Если нужен только общий ответ о доступе:

```python
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("Вход разрешён")
else:
    print("Вход запрещён")
```

Если нужны разные сообщения о причинах отказа, вложенные проверки позволяют выразить их отдельно.

## Что важно запомнить

- Отдельные `if` независимы; цепочка `if/elif/else` выбирает одну ветку.
- Порядок условий и отступы влияют на результат.
- `pass` ничего не делает и не завершает выполнение.
- Пустые коллекции и ноль falsy; непустая коллекция `[0]` truthy.
- `if value` и `if value is not None` решают разные задачи.
- `and` и `or` используют короткое замыкание и возвращают операнды.
- Скобки помогают явно выразить нужную логику.
- Условное выражение выбирает значение; `match/case` сопоставляет с образцами.
- Для проверки границ полезно пробовать значения непосредственно ниже границы, на ней и выше неё.
