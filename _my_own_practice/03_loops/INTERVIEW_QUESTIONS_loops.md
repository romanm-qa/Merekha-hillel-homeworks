# Вопросы к собеседованию: циклы в Python

Сначала попробуй ответить самостоятельно, затем сверяйся с ответом. В задачах на вывод сначала проследи выполнение кода без запуска.

## Основы

### 1. Для чего нужны циклы?

Для повторения действий: обработки элементов коллекции, повторения ввода или выполнения кода до изменения условия.

### 2. Чем отличаются for и while?

`for` перебирает элементы итерируемого объекта. `while` выполняет тело, пока условие истинно. Оба цикла могут выполнить ноль итераций.

```python
for number in [1, 2, 3]:
    print(number)

number = 1
while number <= 3:
    print(number)
    number += 1
```

### 3. Что такое итерация и тело цикла?

Итерация — одно выполнение тела цикла. Тело — блок кода с отступом после `for` или `while`.

### 4. Когда while проверяет условие?

Перед каждой итерацией, включая первую. После выполнения тела управление возвращается к проверке условия.

### 5. Сколько раз выполнится тело, если условие while сразу ложно?

Ни одного раза.

### 6. Что означает while number?

Проверку истинности `number`. Для обычных чисел это эквивалентно `while number != 0`. Отрицательные числа тоже истинны.

### 7. Можно ли использовать список в условии while?

Да. Непустой список истинен, пустой — ложен. Например, можно удалять элементы через `pop()`, пока список не опустеет.

Список `[0]` истинен: проверяется наличие элементов, а не истинность каждого из них.

### 8. Почему цикл может стать бесконечным?

Если условие остаётся истинным, а выполнение не прерывается. Например, забыли изменить счётчик или `continue` пропускает его изменение.

### 9. Для чего используют while True?

Для повторения действий до явного выхода, например меню или запроса ввода. В учебных примерах выход обычно организуют через `break`.

### 10. Какие объекты можно перебирать через for?

Итерируемые: строки, списки, кортежи, словари, множества, `range` и другие. Обычное целое число не итерируемо: попытка его перебрать вызывает `TypeError`.

### 11. Что получает переменная цикла for?

Очередной элемент объекта. Это не обязательно индекс.

```python
names = ["Roman", "Alex"]
for name in names:
    print(name)  # Сначала Roman, затем Alex.
```

### 12. Что происходит при переборе пустого списка?

Тело не выполняется. Если у цикла есть `else`, он выполняется после нормального завершения пустого перебора.

## range, enumerate и zip

### 13. Что возвращает range()?

Объект типа `range`, представляющий последовательность целых чисел. Это не список и не генератор. Он не хранит отдельный элемент для каждого числа диапазона.

### 14. Какие аргументы принимает range()?

`range(stop)`, `range(start, stop)`, `range(start, stop, step)`. По умолчанию начало — `0`, шаг — `1`. Правая граница не включается.

### 15. Как получить числа от 1 до 5 включительно?

```python
for number in range(1, 6):
    print(number)
```

### 16. Как перебирать числа в обратную сторону?

Использовать отрицательный шаг, например `range(5, 0, -1)` даёт `5, 4, 3, 2, 1`.

### 17. Что произойдёт при нулевом шаге range()?

Возникнет `ValueError`.

### 18. Почему range(5, 0) пустой?

Шаг по умолчанию положительный. Начальное значение `5` уже не удовлетворяет границе «меньше 0», поэтому элементов нет.

### 19. Обязательно ли преобразовывать range() в список перед циклом?

Нет. `for` может напрямую перебирать `range`. `list(range(...))` полезен, когда нужен именно список, например для показа всех значений.

### 20. Что означает переменная _ в цикле?

Обычное имя, которым часто обозначают неиспользуемое значение. Например, в `for _ in range(3)` важно количество повторений.

### 21. Для чего нужен enumerate()?

Чтобы получать номер и элемент одновременно. По умолчанию нумерация начинается с `0`; параметр `start` меняет её начало.

```python
for position, name in enumerate(["Roman", "Alex"], start=1):
    print(position, name)
```

### 22. Меняет ли enumerate(names, start=1) индексы списка?

Нет. Он меняет только выдаваемые номера. Первый элемент списка по-прежнему находится под индексом `0`.

### 23. Для чего нужен zip()?

Для совместного перебора нескольких итерируемых объектов. Он выдаёт кортежи соответствующих элементов.

```python
for name, score in zip(["Roman", "Alex"], [90, 85]):
    print(name, score)
```

### 24. Что происходит, если объекты в zip() имеют разную длину?

По умолчанию перебор завершается на самом коротком. Оставшиеся элементы длинного объекта не входят в результат.

### 25. Как перебрать ключи и значения словаря?

```python
user = {"name": "Roman", "role": "student"}
for key, value in user.items():
    print(key, value)
```

Обычный `for key in user` перебирает ключи, а `user.values()` позволяет перебрать значения.

## Управление циклом

### 26. Чем отличаются break и continue?

`break` завершает ближайший цикл. `continue` пропускает остаток текущей итерации: `for` получает следующий элемент, `while` заново проверяет условие.

### 27. Завершает ли break всю программу?

Нет. Выполнение продолжается после цикла.

### 28. Можно ли использовать break и continue вне цикла?

Нет. Это синтаксическая ошибка — `SyntaxError`.

### 29. Чем pass отличается от continue?

`pass` ничего не делает: выполнение идёт к следующей строке. `continue` пропускает оставшуюся часть итерации. `pass` можно использовать как заглушку пустого блока.

### 30. Когда выполняется else у цикла?

После нормального завершения: `for` исчерпал элементы или условие `while` стало ложным. Выполненный `break` пропускает `else`. Исключение, вышедшее из цикла, или `return` из функции тоже могут прервать выполнение до `else`.

### 31. Выполнится ли else, если итераций не было?

Да: например, при переборе пустого списка или изначально ложном условии `while`.

### 32. Мешает ли continue выполнению else?

Нет. Даже если все итерации прошли через `continue`, после нормального завершения `else` выполнится.

### 33. К чему относится else после цикла с внутренним if?

К циклу, если стоит на одном уровне отступов с `for` или `while`. Он не является веткой внутреннего `if`.

### 34. Где полезен for...else?

В поиске: нашли элемент — выполнили `break`; перебрали всё без совпадения — вывели сообщение в `else`.

## Вложенные циклы и ввод

### 35. Что такое вложенный цикл?

Цикл внутри тела другого цикла. Каждый раз, когда выполнение доходит до внутреннего `for`, начинается новый перебор указанного объекта.

### 36. Сколько раз выполнится внутреннее тело при range(3) снаружи и range(2) внутри?

`3 * 2 = 6` раз, если оба перебора выполняются полностью.

### 37. Завершит ли break во внутреннем цикле внешний цикл?

Нет. Он завершает только ближайший цикл. `continue` тоже действует на ближайший цикл.

### 38. Как получить все сочетания элементов двух списков?

Через вложенные циклы. `zip()` даёт соответствующие пары, а вложенные циклы — все сочетания.

```python
for color in ["red", "blue"]:
    for size in ["S", "M"]:
        print(color, size)
```

### 39. Как собрать плоский список из списка списков?

Внешним циклом перебрать вложенные списки, внутренним — их элементы и добавить каждый элемент в результат через `append()`.

### 40. Что возвращает input() и как обработать неверный ввод числа?

`input()` возвращает строку. Для целого числа используется `int()`. Ошибку преобразования можно обработать через `except ValueError` и повторить запрос.

### 41. Как ограничить ввод тремя попытками?

Использовать `for` с `range(3)` или нумерацию через `range(1, 4)`. При успехе выйти через `break`. Сообщение об исчерпании попыток можно разместить в `else` у цикла.

## Что выведет код?

### 42. Порядок вывода и изменения счётчика

```python
number = 3
while number > 0:
    print(number)
    number -= 1
print("После:", number)
```

Ответ:

```text
3
2
1
После: 0
```

Вывод идёт перед уменьшением. При `0` тело больше не выполняется.

### 43. Уменьшение перед выводом

```python
number = 3
while number > 0:
    number -= 1
    print(number)
```

Ответ:

```text
2
1
0
```

На последней итерации проверка прошла при значении `1`, затем значение уменьшилось до `0` и было выведено.

### 44. Выход через break

```python
for number in [1, 2, 3, 4]:
    if number == 3:
        break
    print(number)
else:
    print("Готово")
```

Ответ: `1` и `2`, каждое на новой строке. `break` пропустит и вывод `3`, и блок `else`.

### 45. Пропуск через continue

```python
for number in [1, 2, 3]:
    if number == 2:
        continue
    print(number)
else:
    print("Готово")
```

Ответ:

```text
1
3
Готово
```

### 46. Пустой перебор

```python
for number in []:
    print(number)
else:
    print("Пусто")
```

Ответ: `Пусто`. Итераций не было, но цикл завершился нормально.

### 47. Правая граница range

```python
print(list(range(2, 8, 2)))
print(list(range(3, 0, -1)))
```

Ответ:

```text
[2, 4, 6]
[3, 2, 1]
```

### 48. Разная длина в zip

```python
for name, score in zip(["Roman", "Alex", "Kate"], [90, 85]):
    print(name, score)
```

Ответ:

```text
Roman 90
Alex 85
```

### 49. break во вложенном цикле

```python
for outer in range(2):
    for inner in range(3):
        if inner == 1:
            break
        print(outer, inner)
```

Ответ:

```text
0 0
1 0
```

Внутренний цикл каждый раз заканчивается на `inner == 1`. Внешний продолжает работу.

### 50. Найди причину бесконечного цикла

```python
number = 0
while number < 5:
    if number == 3:
        continue
    print(number)
    number += 1
```

Ответ: после вывода `0`, `1`, `2` значение становится равным `3`. `continue` постоянно пропускает увеличение, поэтому условие остаётся истинным. Нового вывода при этом нет.

Исправление: организовать изменение счётчика так, чтобы `continue` его не пропускал, сохранив нужные границы обработки.
