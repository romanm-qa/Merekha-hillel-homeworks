# Циклы (Loops) в Python

## Что такое цикл

Цикл — это одна из стандартных конструкций управления потоком выполнения программы.

Циклы используются, когда один и тот же блок кода необходимо выполнить несколько раз.

Например:

- повторить одно и то же действие несколько раз;
- пройтись по элементам списка, строки, словаря или другой коллекции;
- выполнять код до тех пор, пока выполняется определённое условие.

В Python существует два основных вида циклов:

- `while`
- `for`

---

## Цикл `while`

Цикл `while` используется вместе с условием.

Он выполняет блок кода до тех пор, пока условие возвращает `True`.

Общий синтаксис:

```python
while condition:
    # code
```

Принцип работы:

1. Python проверяет условие.
2. Если условие равно `True`, выполняется тело цикла.
3. После выполнения тела цикла условие проверяется снова.
4. Если условие стало `False`, цикл завершается.

---

### Пример

```python
x = int(input("Please input 0 to stop iteration: "))
sum_result = 0

while x:
    sum_result += x
    x = int(input("Please input 0 to stop iteration: "))

print(sum_result)
```

В этом примере программа получает числа от пользователя и складывает их.

- Переменная `x` хранит число, которое ввёл пользователь.
- Переменная `sum_result` хранит сумму всех введённых чисел.

Важно:

Переменную `x` необходимо создать **до начала цикла**, потому что она используется в условии:

```python
while x:
```

Цикл работает, пока значение `x` не равно `0`.

В Python:

- `0` считается `False`;
- любое другое число считается `True`.

Когда пользователь вводит `0`, условие становится ложным, цикл завершается, после чего выводится сумма всех введённых чисел.

---

## Оператор `continue`

Оператор `continue` используется внутри цикла.

Он **пропускает текущую итерацию** и сразу переходит к следующей.

То есть весь код, расположенный после `continue` в текущей итерации, уже не выполнится.

### Пример

```python
n = int(input("Input integer number: "))
sum_result = 0
x = 1

while x < n:
    x += 1

    if x % 2:
        continue

    sum_result += x

print(f"Sum of even numbers: {sum_result}")
```

В этом примере программа считает сумму всех чётных чисел.

Условие

```python
x % 2
```

проверяет остаток от деления числа на `2`.

Если остаток есть — число нечётное.

Для нечётных чисел срабатывает оператор `continue`, поэтому строка

```python
sum_result += x
```

не выполняется.

Если число чётное, оператор `continue` не срабатывает, и число добавляется к сумме.

---

## Оператор `break`

Оператор `break` используется для **досрочного выхода из цикла**.

Он полностью завершает цикл, даже если условие цикла всё ещё равно `True`.

### Пример

```python
x = int(input("Input integer number: "))
is_prime = True
div = 2

while div < x:
    if not x % div:
        is_prime = False
        break

    div += 1

if is_prime:
    print("Prime")
else:
    print("Not prime")
```

В этом примере программа проверяет, является ли число простым.

Переменная `is_prime` — это **флаг**.

Флаг — это обычная переменная, которая хранит состояние программы.

Чаще всего она принимает значения:

- `True`
- `False`

В начале программы предполагается, что число простое:

```python
is_prime = True
```

Затем программа проверяет, делится ли число `x` на числа от `2` до `x - 1`.

Если найден хотя бы один делитель, значит число не является простым.

Тогда флаг меняется:

```python
is_prime = False
```

После этого выполняется оператор

```python
break
```

Дальше продолжать проверку уже нет смысла, поэтому цикл сразу завершается.

---

## Цикл `while...else`

У цикла `while` может быть блок `else`.

Он выполняется **один раз после завершения цикла**, если цикл закончился обычным способом, то есть **без использования `break`**.

### Пример

```python
x = 1

while x < 5:
    print(x)
    x += 1
else:
    print("Loop was stopped at:")
    print(x)
```

Результат:

```text
1
2
3
4
Loop was stopped at:
5
```

Здесь цикл завершился потому, что условие

```python
x < 5
```

стало ложным (`False`).

Поэтому блок `else` выполнился.

> **Важно:** если внутри цикла сработает оператор `break`, блок `else` выполняться не будет.

---

💡 **Полезно знать**

Иногда можно встретить конструкцию:

```python
while True:
    ...
```

Так создаётся **бесконечный цикл**.

Обычно такой цикл завершается оператором `break`, когда выполнится нужное условие.

## Цикл `for`

Цикл `for` используется для перебора элементов последовательности или коллекции.

Например:

- строки;
- списка;
- кортежа;
- словаря;
- множества;
- результата функции `range()`.

В отличие от `while`, цикл `for` автоматически получает следующий элемент последовательности и не требует вручную изменять счётчик.

---

### Пример

```python
for i in range(5):
    print(i)
```

Результат:

```text
0
1
2
3
4
```

Функция `range(5)` создаёт последовательность чисел от `0` до `4`.

Правая граница (`5`) **не входит** в диапазон.

На каждой итерации переменная `i` получает следующее значение из этой последовательности.

---

## Когда лучше использовать `for`

Если заранее известно:

- сколько раз должен выполниться цикл;
- или нужно перебрать элементы коллекции,

то почти всегда лучше использовать именно `for`.

Такой код получается короче, проще и читается легче.

---

## `for` вместо `while`

Во многих случаях цикл `for` позволяет написать тот же код намного проще.

Например, проверку простого числа можно записать так:

```python
x = int(input("Input integer number: "))

is_prime = True

for div in range(2, x):
    if not x % div:
        is_prime = False
        break

if is_prime:
    print("Prime")
else:
    print("Not prime")
```

Здесь

```python
for div in range(2, x)
```

сам перебирает числа от `2` до `x - 1`.

Нам уже не нужно:

- создавать переменную

```python
div = 2
```

- увеличивать её вручную

```python
div += 1
```

Цикл делает это автоматически.

---

## Цикл `for...else`

У цикла `for` тоже может быть блок `else`.

Он работает точно так же, как и у `while`.

Блок `else` выполнится только в том случае, если цикл завершился **без оператора `break`**.

### Пример

```python
x = int(input("Input integer number: "))

for div in range(2, x):
    if not x % div:
        print("Not prime")
        break
else:
    print("Prime")
```

Здесь блок `else` позволяет избавиться от дополнительной переменной `is_prime`.

Если найден делитель:

- выполняется `break`;
- блок `else` не выполняется.

Если цикл завершился полностью и `break` ни разу не выполнился, значит делителей нет и число является простым.

---

## Iterable и Iterator

Цикл `for` умеет работать не только с функцией `range()`.

Он может перебирать любой **итерируемый объект** (*iterable*).

**Iterable** — это объект, который способен отдавать свои элементы по одному.

Примеры итерируемых объектов:

- список (`list`);
- строка (`str`);
- кортеж (`tuple`);
- словарь (`dict`);
- множество (`set`);
- файл;
- `range()`.

Например:

```python
name = "Roman"

for letter in name:
    print(letter)
```

Результат:

```text
R
o
m
a
n
```

Строка является итерируемым объектом, поэтому цикл `for` проходит по каждой букве.

---

### Что такое Iterator

**Iterator** — это специальный объект, который последовательно отдаёт элементы и запоминает, на каком месте он остановился.

Пока подробно изучать итераторы не нужно.

К этой теме мы ещё вернёмся, когда будем проходить объектно-ориентированное программирование.

Сейчас достаточно запомнить главное:

> Цикл `for` работает только с объектами, которые можно перебирать.

---

## `while` или `for`?

Используй `while`, когда:

- заранее неизвестно количество повторений;
- цикл должен работать до выполнения определённого условия;
- программа ожидает действия пользователя.

Например:

```python
while password != correct_password:
    ...
```

---

Используй `for`, когда:

- нужно пройтись по коллекции;
- известно количество повторений;
- используется `range()`.

Например:

```python
for student in students:
    print(student)
```

или

```python
for i in range(10):
    print(i)
```

В реальных Python-проектах цикл `for` используется значительно чаще, чем `while`.

---

## Типичные ошибки новичков

### Забыли изменить счётчик

```python
x = 1

while x < 5:
    print(x)
```

Такой цикл никогда не закончится, потому что значение `x` не изменяется.

---

### Неправильное условие

Всегда проверяй условие цикла.

Неверное условие может привести либо к бесконечному циклу, либо к тому, что цикл вообще не выполнится.

---

### Неправильное использование `break`

После выполнения `break` цикл сразу завершается.

Весь оставшийся код внутри цикла уже не выполнится.

---

### Неправильное использование `continue`

После выполнения `continue` Python сразу переходит к следующей итерации.

Все строки ниже `continue` в текущей итерации будут пропущены.

---

## Краткий итог

В Python существует два основных вида циклов:

- `while` — используется, когда необходимо выполнять код, пока условие истинно;
- `for` — используется для перебора элементов последовательностей и коллекций.

Оператор `continue` пропускает текущую итерацию и сразу переходит к следующей.

Оператор `break` полностью завершает выполнение цикла.

Блок `else` выполняется только в том случае, если цикл завершился без использования `break`.

Функция `range()` создаёт последовательность чисел, которая часто используется вместе с циклом `for`.

На практике цикл `for` применяется значительно чаще, чем `while`, поскольку большинство задач связано с перебором коллекций.
