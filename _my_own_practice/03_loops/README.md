# Циклы в Python

Циклы позволяют повторять действия: выполнять код, пока условие истинно, или обрабатывать элементы коллекции по одному.

## 1. Цикл while

`while` повторяет тело цикла, пока условие истинно. Условие проверяется **перед каждой итерацией**. Итерация — одно выполнение тела цикла.

```python
countdown = 3

while countdown > 0:
    print(f"Текущее значение: {countdown!r}")
    countdown -= 1

print(f"После цикла: {countdown!r}")
```

Вывод:

```text
Текущее значение: 3
Текущее значение: 2
Текущее значение: 1
После цикла: 0
```

Сначала выполняется `print()`, затем число уменьшается. После этого Python возвращается к проверке условия. При значении `0` условие ложно, поэтому тело больше не выполняется.

`countdown -= 1` означает то же самое, что `countdown = countdown - 1`.

Если условие ложно с самого начала, итераций не будет.

### Истинность объектов

В условии можно использовать сам объект:

```python
number = 3

while number:
    print(f"Число: {number!r}")
    number -= 1
```

Для чисел `while number` эквивалентно `while number != 0`. Отрицательные числа тоже истинны.

| Значение | Истинность |
| --- | --- |
| `0`, `0.0`, `False`, `None` | Ложь |
| `""`, `[]`, `()`, `{}`, `set()` | Ложь |
| Ненулевые числа | Истина |
| Непустые строки и коллекции | Истина |

Непустая коллекция истинна независимо от истинности её элементов: `bool([0])` возвращает `True`.

Пример обработки списка до его опустошения:

```python
numbers = [10, 20, 30]
print(f"Исходный список: {numbers!r}")

while numbers:
    removed_number = numbers.pop()
    print(f"Удалённый элемент: {removed_number!r}")

print(f"После цикла: {numbers!r}")
```

`pop()` без аргумента удаляет и возвращает последний элемент. Здесь исходный список изменяется.

## 2. Цикл for

`for` перебирает элементы итерируемого объекта по одному. Переменная цикла на каждой итерации получает следующий элемент.

```python
names = ["Roman", "Alex", "Kate"]
print(f"Исходный список: {names!r}")

for name in names:
    print(f"Текущее имя: {name!r}")
```

Перебирать можно строки, списки, кортежи, множества, словари и `range`. Обычное целое число не является итерируемым объектом: попытка `for item in 5` вызывает `TypeError`.

У пустого объекта итераций не будет. Порядок обхода множества не гарантируется.

### range()

`range()` задаёт последовательность целых чисел. Это отдельный тип, а не список. Для просмотра всех значений удобно использовать `list()`; самому циклу преобразование не нужно.

| Запись | Значения |
| --- | --- |
| `range(4)` | `0, 1, 2, 3` |
| `range(2, 5)` | `2, 3, 4` |
| `range(1, 8, 2)` | `1, 3, 5, 7` |
| `range(3, 0, -1)` | `3, 2, 1` |
| `range(3, 0)` | Нет значений |

Формы вызова: `range(stop)`, `range(start, stop)`, `range(start, stop, step)`.

- `start` включается, `stop` **не включается**.
- По умолчанию `start = 0`, `step = 1`.
- Отрицательный шаг задаёт движение в сторону уменьшения.
- Если начальное значение уже за границей для выбранного направления, последовательность пустая.
- Нулевой шаг вызывает `ValueError`.

```python
for number in range(3):
    print(f"Число: {number!r}")
```

Если значение переменной не требуется, её часто называют `_`:

```python
for _ in range(3):
    print("Hello!")
```

`_` — обычное имя переменной, обозначающее, что её значение здесь не используется.

### enumerate()

`enumerate()` даёт номер и элемент одновременно:

```python
names = ["Roman", "Alex", "Kate"]
print(f"Исходный список: {names!r}")

for index, name in enumerate(names):
    print(f"Индекс: {index!r}; имя: {name!r}")
```

По умолчанию нумерация начинается с `0`. `enumerate(names, start=1)` начинает нумерацию с `1`, но не меняет индексы самого списка.

### zip()

`zip()` позволяет совместно перебирать несколько объектов:

```python
names = ["Roman", "Alex", "Kate"]
scores = [90, 85, 95]
print(f"Имена: {names!r}; баллы: {scores!r}")

for name, score in zip(names, scores):
    print(f"Имя: {name!r}; балл: {score!r}")
```

Пары распаковываются в переменные `name` и `score`. По умолчанию перебор заканчивается на самом коротком объекте: лишние элементы длинного объекта не обрабатываются.

### Перебор словаря

| Запись | Что получаем |
| --- | --- |
| `for key in user` | Ключи |
| `for value in user.values()` | Значения |
| `for key, value in user.items()` | Ключи и значения |

## 3. break и continue

| Команда | Действие |
| --- | --- |
| `break` | Завершает ближайший цикл |
| `continue` | Пропускает остаток текущей итерации ближайшего цикла |

Сравнение на одинаковых данных:

```python
numbers = [1, 2, 3, 4, 5]
print(f"Исходный список: {numbers!r}")

print("С break:")
for number in numbers:
    if number == 3:
        break
    print(number)

print("С continue:")
for number in numbers:
    if number == 3:
        continue
    print(number)
```

С `break` выводятся `1, 2`; с `continue` — `1, 2, 4, 5`.

После `break` выполнение продолжается за пределами цикла. После `continue` цикл `for` получает следующий элемент, а `while` заново проверяет условие.

В `while` следи, чтобы `continue` не пропускал необходимое изменение счётчика:

```python
number = 0

while number < 5:
    number += 1
    if number == 3:
        continue
    print(f"Число: {number!r}")
```

### while True

Условие `True` всегда истинно, поэтому само по себе не завершит цикл. Часто такой цикл используют для меню или повторения ввода, а выход организуют через `break`.

Если цикл застрял, в терминале его обычно можно остановить сочетанием `Ctrl+C`.

## 4. else у цикла

Блок `else` выполняется после **нормального завершения** цикла:

- `for` исчерпал элементы;
- условие `while` стало ложным.

`break` пропускает `else`. `continue` не мешает его выполнению. Если итераций не было, `else` тоже выполняется.

```python
numbers = [5, 8, 12]
target = 99
print(f"Исходный список: {numbers!r}; ищем: {target!r}")

for number in numbers:
    if number == target:
        print(f"Число найдено: {number!r}")
        break
else:
    print(f"Число {target!r} не найдено")
```

`else` относится к циклу и стоит на одном уровне отступов с `for` или `while`. Это не ветка внутреннего `if`.

Исключение, вышедшее из цикла, или `return` из функции также могут прервать выполнение до `else`.

## 5. Вложенные циклы

Вложенный цикл расположен внутри другого цикла. Каждый раз, когда выполнение доходит до внутреннего `for`, его перебор начинается заново.

```python
for outer_index in range(2):
    print(f"Внешняя итерация: {outer_index!r}")

    for inner_index in range(3):
        print(f"    Внутренняя итерация: {inner_index!r}")
```

В этом примере внешнее тело выполняется `2` раза, внутреннее — `2 * 3 = 6` раз.

Вложенные циклы подходят для перебора списка списков и получения всех сочетаний элементов.

```python
rows = [[1, 2], [], [3, 4, 5]]
flat_numbers = []
print(f"Исходный список: {rows!r}")

for row in rows:
    for number in row:
        flat_numbers.append(number)

print(f"Плоский список: {flat_numbers!r}")
```

Внешний цикл получает строку, внутренний — её элементы. Вложенные списки могут иметь разную длину. Для пустой строки внутреннее тело не выполняется.

`break` во внутреннем цикле завершает только его. Внешний цикл продолжает работу. Аналогично, `continue` действует на ближайший цикл, внутри которого находится.

Для вывода узоров используется `print(char, end=" ")`: вместо перевода строки выводится пробел. Отдельный `print()` завершает строку после внутреннего цикла.

## 6. Циклы с вводом

В `06_input_loops.py` четыре последовательных примера:

| Пример | Как завершить |
| --- | --- |
| Повторение ввода текста | Ввести точно `stop` |
| Ввод целых чисел | Ввести `0` |
| Меню | Выбрать пункт `3` |
| Проверка входа | Ввести правильные данные или исчерпать три попытки |

Учебные данные для входа: логин `admin`, пароль `qwerty`.

`input()` всегда возвращает строку. `int()` преобразует подходящую строку в целое число. При неверном вводе возникает `ValueError`: обработчик `except` сообщает об ошибке, а `continue` возвращает к следующему запросу.

В меню `strip()` удаляет пробельные символы по краям ввода. Проверка `if name` отличает непустое имя от пустого. После приветствия меню продолжает работу.

В примере входа `range(1, MAX_ATTEMPTS + 1)` задаёт номера попыток от `1` до `MAX_ATTEMPTS` включительно. Успешный вход вызывает `break`; после трёх неудач выполняется `else` у цикла.

## Частые ошибки

- Забыть изменить значение, от которого зависит условие `while`, и получить бесконечный цикл.
- Считать, что `print()` в теле выполняется один раз: он вызывается при каждом достижении этой строки на очередной итерации.
- Ожидать, что `range()` включит правую границу.
- Перепутать завершение цикла через `break` с пропуском итерации через `continue`.
- Принять `else` у цикла за ветку внутреннего `if`.
- Ожидать, что `break` завершит сразу все вложенные циклы.
- Ожидать число от `input()` без преобразования.
