# Тип данных Dictionary

**Dictionary (словарь)** — это реализация структуры данных, которая также известна как **хеш-таблица (Hash Table)** или **ассоциативный массив (Associative Array)**.

> **Словарь** — это коллекция, в которой каждому **ключу (key)** соответствует определенное **значение (value)**.

Особенности словаря:

- изменяемый (*mutable*);
- динамический (может увеличиваться и уменьшаться);
- значения могут быть любого типа данных;
- значением может быть даже другой словарь.

В Python словарь представлен классом `dict`.

---

# Создание словаря

Создать словарь можно двумя способами.

## Способ 1. Фигурные скобки

Элементы словаря записываются в фигурных скобках.

Каждая пара состоит из:

```
ключ : значение
```

Пары разделяются запятыми.

Пример:

```python
d = {
    "name": "Filip",
    "age": 32,
    "is_registered": False,
    "rate": 12.5,
    "total_score": 200,
    "linked_ids": [1, 45, 98]
}

print(type(d))
```

Результат:

```python
<class 'dict'>
```

Обратите внимание, что значения могут иметь разные типы данных:

- строка;
- число;
- логическое значение;
- список;
- другой словарь и т.д.

---

## Способ 2. Функция `dict()`

Встроенная функция `dict()` позволяет создать словарь из последовательности пар **ключ–значение**.

Например:

```python
d2 = dict([
    (1, "foo"),
    (10, "bar")
])

print(d2)
```

Результат:

```python
{1: 'foo', 10: 'bar'}
```

Чаще всего в `dict()` передают список кортежей.

---

# Доступ к элементам словаря

Получить значение можно по ключу.

```python
name = d["name"]
```

В данном случае переменная `name` получит значение:

```python
"Filip"
```

---

## Ошибка при отсутствии ключа

Если указанного ключа нет, Python выдаст исключение `KeyError`.

```python
orders = d["orders"]
```

Результат:

```python
KeyError: 'orders'
```

Поэтому перед обращением к ключу желательно убедиться, что он существует, либо использовать метод `get()`, который рассмотрим позже.

---

# Перебор словаря

Словарь поддерживает перебор элементов с помощью цикла `for`.

Самый распространенный способ — использовать метод `items()`.

```python
for pair in d.items():
    print(pair)
```

Результат:

```python
('name', 'Filip')
('age', 33)
('is_registered', False)
('rate', 12.5)
('total_score', 200)
('linked_ids', [1, 45, 98])
```

Каждый элемент представляет собой кортеж:

```python
(ключ, значение)
```

---

## Более удобный вариант

Можно сразу распаковать кортеж на две переменные.

```python
for key, value in d.items():
    print((key, value))
```

Результат будет тем же самым:

```python
('name', 'Filip')
('age', 33)
('is_registered', False)
('rate', 12.5)
('total_score', 200)
('linked_ids', [1, 45, 98])
```

Такой способ используется значительно чаще, потому что сразу дает доступ отдельно к ключу и отдельно к значению.

---

# Проверка существования ключа

Перед обращением к элементу словаря можно проверить, существует ли нужный ключ.

```python
if "preferences" in d and d["preferences"]:
    print(d["preferences"])
```

Здесь происходит две проверки:

1. Есть ли ключ `"preferences"` в словаре.
2. Если ключ существует — содержит ли он непустое значение.

Такой подход помогает избежать ошибки `KeyError`.

---

# Ограничения словаря

Словарь является очень гибкой структурой данных.

Однако существуют некоторые ограничения.

## Ограничения для ключей

Ключами могут быть только **hashable (хешируемые)** объекты.

Например:

✅ Можно использовать:

- строки;
- числа;
- булевы значения;
- кортежи (если внутри тоже hashable-объекты).

❌ Нельзя использовать:

- списки;
- множества;
- словари.

Причина в том, что изменяемые объекты не являются hashable.

---

## Ограничения для значений

Для значений ограничений практически нет.

В качестве значения можно хранить:

- строки;
- числа;
- списки;
- множества;
- кортежи;
- словари;
- объекты классов;
- функции;
- практически любой объект Python.

Именно поэтому словари настолько универсальны.

# Методы словаря

Класс `dict` предоставляет множество встроенных методов для удобной работы со словарями.

Рассмотрим самые распространенные из них.

---

# Метод `get()`

Метод `get()` принимает ключ и возвращает соответствующее значение.

Главное отличие от обращения через квадратные скобки заключается в том, что при отсутствии ключа ошибка **не возникает**.

```python
print(d.get("preferences"))
```

Если ключ отсутствует, по умолчанию метод возвращает:

```python
None
```

---

## Значение по умолчанию

Можно самостоятельно указать, что следует вернуть, если ключ не найден.

```python
print(d.get("preferences", "There is nothing!"))
```

Результат:

```python
There is nothing!
```

Поэтому `get()` считается более безопасным способом получения значения.

---

# Метод `items()`

Метод `items()` возвращает специальный объект `dict_items`.

Каждый элемент представляет собой кортеж вида:

```python
(ключ, значение)
```

Например:

```python
for pair in d.items():
    print(pair)
```

Результат:

```python
('name', 'Filip')
('age', 33)
('is_registered', False)
('rate', 12.5)
('total_score', 200)
('linked_ids', [1, 45, 98])
```

Именно поэтому метод `items()` очень часто используют в циклах.

---

# Методы `keys()` и `values()`

## `keys()`

Возвращает объект `dict_keys`, содержащий все ключи словаря.

```python
for key in d.keys():
    print(key)
```

Результат:

```python
name
age
is_registered
rate
total_score
linked_ids
```

---

## `values()`

Метод `values()` возвращает объект `dict_values`, содержащий только значения словаря.

Например:

```python
for value in d.values():
    print(value)
```

Результат:

```python
Filip
33
False
12.5
200
[1, 45, 98]
```

---

# Метод `update()`

Метод `update()` используется для обновления словаря.

Он:

- изменяет существующие значения;
- добавляет новые пары ключ–значение, если такого ключа раньше не было.

Пример:

```python
blank_d = {
    "name": "",
    "age": 0,
    "is_registered": False,
    "rate": 0,
    "total_score": 0,
    "linked_ids": []
}

d.update(blank_d)

print(d)
```

Результат:

```python
{
    'name': '',
    'age': 0,
    'is_registered': False,
    'rate': 0,
    'total_score': 0,
    'linked_ids': []
}
```

# Алгоритмическая сложность

Словари являются одной из самых популярных структур данных в Python.

Основные преимущества словаря:

- гибкость;
- простота использования;
- высокая производительность.

Одной из причин высокой скорости работы является **алгоритмическая сложность**.

---

## Что такое алгоритмическая сложность

Алгоритмическая сложность показывает, сколько операций потребуется алгоритму при увеличении объема входных данных.

Она позволяет оценить эффективность алгоритма независимо от мощности компьютера.

Для описания сложности обычно используется **нотация Big O**.

---

# Big O

**Big O** — математическая нотация, описывающая, как изменяется время выполнения алгоритма при увеличении количества данных.

Некоторые наиболее распространенные варианты сложности:

| Сложность | Где встречается |
|-----------|-----------------|
| `O(1)` | Доступ к элементу массива по индексу |
| `O(log n)` | Бинарный поиск |
| `O(n)` | Линейный поиск максимума или минимума |
| `O(n log n)` | Merge Sort, Quick Sort |
| `O(n²)` | Bubble Sort, Insertion Sort, Selection Sort |
| `O(2ⁿ)` | Поиск всех подмножеств, некоторые рекурсивные задачи |
| `O(n!)` | Перебор всех перестановок |

Чем ниже сложность, тем лучше масштабируется алгоритм при увеличении объема данных.

---

# Hash Table (Хеш-таблица)

Словарь в Python реализован с помощью структуры данных **Hash Table (хеш-таблица)**.

В большинстве случаев доступ к элементу по ключу имеет сложность:

```text
O(1)
```

То есть получение значения происходит практически за постоянное время.

---

## Почему доступ такой быстрый

Работа хеш-таблицы состоит из двух основных этапов.

### 1. Хранение данных в массиве

Фактически данные словаря располагаются в массиве.

А доступ к элементу массива по индексу имеет сложность:

```text
O(1)
```

---

### 2. Преобразование ключа в индекс

Для каждого ключа вычисляется специальное **хеш-значение**.

На основании этого значения определяется индекс, по которому будет храниться элемент.

Таким образом Python может практически сразу определить, где находится нужное значение.

---

## Коллизии

Иногда разные ключи могут получить одинаковое хеш-значение.

Такая ситуация называется **коллизией (collision)**.

Python умеет автоматически разрешать коллизии, однако именно из-за них доступ по ключу иногда может оказаться немного медленнее, чем идеальное `O(1)`.

---

## Недостаток словарей

Главный недостаток словарей связан с использованием памяти.

Для обеспечения высокой скорости доступа словарь обычно выделяет памяти больше, чем фактически требуется для хранения данных.

Поэтому словари менее эффективны по использованию памяти по сравнению с некоторыми другими структурами данных.

---

# Когда использовать словари

Словари отлично подходят, если необходимо:

- быстро получать значение по ключу;
- хранить связанные данные;
- описывать объекты с характеристиками;
- работать с настройками, конфигурациями или JSON;
- выполнять быстрый поиск информации.
