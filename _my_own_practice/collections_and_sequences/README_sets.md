# Тип данных Set

**Set (множество)** — это еще один тип коллекций в Python.

По своим свойствам множества похожи на списки:

- изменяемые (*mutable*);
- динамические (размер может изменяться во время работы программы).

Однако у множеств есть важные отличия:

- элементы **не имеют порядка**;
- одинаковые элементы хранить нельзя;
- множество может содержать **только hashable-объекты**.

О том, что такое hashable-объекты, поговорим немного позже.

---

## Создание множества с помощью `set()`

Для создания множества используется встроенная функция:

```python
my_set = set((1, 113.5, True, "Some string"))
```

Как видно из примера, множество может содержать элементы разных типов одновременно.

⚠️ В функцию `set()` необходимо передать **итерируемый объект** (например список, кортеж, строку и т.д.).

В данном случае в качестве аргумента передается кортеж.

---

## Тип объекта

В Python множество представлено классом `set`.

```python
print(type(my_set))
```

Результат:

```python
<class 'set'>
```

---

## Создание множества через фигурные скобки

Создать множество можно и более коротким способом:

```python
my_set = {1, 113.5, True, "Some string"}
```

---

## Пустое множество

Важно помнить одну особенность.

Если написать:

```python
my_set = {}
print(type(my_set))
```

Результат будет:

```python
<class 'dict'>
```

То есть пустые фигурные скобки создают **не множество**, а **словарь**.

Это связано с тем, что фигурные скобки также используются для создания словарей.

Если необходимо создать пустое множество, используйте:

```python
my_set = set()
```

---

## Автоматическое удаление дубликатов

Если передать в `set()` коллекцию с повторяющимися элементами, множество автоматически оставит только уникальные значения.

```python
my_set = set([1, 2, 3, 1, 2])

print(my_set)
```

Результат:

```python
{1, 2, 3}
```

Именно поэтому множества часто используют для удаления дубликатов.

---

## Особенности множества

Множества являются **итерируемыми объектами**.

По ним можно проходить циклом `for`:

```python
for item in my_set:
    print(item)
```

Однако доступ по индексу отсутствует.

Нельзя сделать так:

```python
my_set[0]
```

Также множества не поддерживают:

- индексацию;
- срезы;
- порядок хранения элементов.

---

## Проверка наличия элемента

Очень часто множества используют для проверки, содержится ли элемент в коллекции.

```python
if 1 in my_set:
    pass
```

Оператор `in` работает с множествами очень быстро.

---

## Получение количества элементов

Для определения размера множества используется функция `len()`.

```python
print(len(my_set))
```

Результат:

```python
3
```

# Hashable Objects (Хешируемые объекты)

В Python практически всё является объектами.

Объект считается **hashable (хешируемым)**, если он умеет вычислять собственное хеш-значение.

Хеш используется для идентификации объекта.

Позже эта тема подробно рассматривается в разделе объектно-ориентированного программирования.

Пока достаточно запомнить следующее.

---

## Неизменяемые объекты

Все **неизменяемые (immutable)** типы данных являются hashable.

При этом некоторые пользовательские классы тоже могут быть hashable — это зависит от того, как реализован сам класс.

---

## Функция `hash()`

Если объект является hashable, можно получить его хеш с помощью встроенной функции `hash()`.

Например, кортеж является неизменяемым типом данных, поэтому для него можно получить хеш.

```python
some_tuple = (1, 2, 3)

print(hash(some_tuple))
```

Результат:

```python
529344067295497451
```

Конкретное число может отличаться на разных запусках Python.

Главное понимать, что хеш — это целое число, используемое для идентификации объекта.

---

# Операции над множествами

Работать с множествами можно двумя способами:

- с помощью операторов;
- с помощью методов.

Далее рассмотрим самые популярные операции.

---

# Объединение множеств (Union)

### Через оператор `|`

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d"}
s3 = {"c", "d"}

union = s1 | s2 | s3

print(union)
```

---

### Через метод `union()`

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d"}
s3 = {"c", "d"}

union = s1.union(s2, s3)

print(union)
```

Результат:

```python
{'h', 'a', 'n', 'b', 'd', 'c'}
```

Оба варианта возвращают множество, содержащее все уникальные элементы из всех множеств.

---

# Пересечение множеств (Intersection)

Возвращает только те элементы, которые присутствуют во всех множествах одновременно.

### Через оператор `&`

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d", "a"}
s3 = {"n", "a", "d"}

my_intersection = s1 & s2 & s3

print(my_intersection)
```

---

### Через метод `intersection()`

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d", "a"}
s3 = {"n", "a", "d"}

my_intersection = s1.intersection(s2, s3)

print(my_intersection)
```

Результат:

```python
{'a', 'd'}
```

---

# Разность множеств (Difference)

Возвращает элементы первого множества, которых нет в остальных.

### Через оператор `-`

```python
s1 = {"a", "d", "h", "c", "j"}
s2 = {"n", "b", "c", "d", "a"}
s3 = {"n", "a", "d"}

my_difference = s1 - s2 - s3

print(my_difference)
```

---

### Через метод `difference()`

```python
s1 = {"a", "d", "h", "c", "j"}
s2 = {"n", "b", "c", "d", "a"}
s3 = {"n", "a", "d"}

my_difference = s1.difference(s2, s3)

print(my_difference)
```

Результат:

```python
{'h', 'j'}
```

# Продолжение работы с множествами

## Операторы и методы

Во всех предыдущих примерах результаты были одинаковыми независимо от того, использовали мы оператор или метод.

Однако есть одно важное отличие.

### Операторы работают только с множествами

Например:

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d"}
s3 = ["c", "d"]

union = s1 | s2 | s3

print(union)
```

Результат:

```python
TypeError: unsupported operand type(s) for | ...
```

Ошибка возникает потому, что оператор `|` умеет работать только с объектами типа `set`.

---

### Методы принимают любые итерируемые объекты

```python
s1 = {"a", "d", "h"}
s2 = {"n", "b", "c", "d"}
s3 = ["c", "d"]

union = s1.union(s2, s3)

print(union)
```

Результат:

```python
{'h', 'a', 'n', 'b', 'd', 'c'}
```

Методы более универсальны — в качестве аргументов можно передавать любые итерируемые объекты:

- списки;
- кортежи;
- множества;
- строки;
- и другие коллекции.

---

# Изменение множества

Множества являются изменяемыми объектами, поэтому Python предоставляет несколько методов для изменения их содержимого.

---

# Метод `update()`

Метод `update()` объединяет текущее множество с другими коллекциями.

При этом исходное множество изменяется.

```python
s1 = {"a", "b", "k"}
s2 = {"a", "d", "h"}
s3 = {"n", "b", "d"}

s1.update(s2, s3)

print(s1)
```

Результат:

```python
{'d', 'a', 'h', 'b', 'k', 'n'}
```

По сути `update()` выполняет объединение множеств, но записывает результат прямо в исходное множество.

---

## `intersection_update()`

Работает аналогично `update()`, но вместо объединения оставляет только общие элементы.

Пример логики:

```python
s1 = {1, 2, 3}
s2 = {2, 3, 4}

s1.intersection_update(s2)

print(s1)
```

Результат:

```python
{2, 3}
```

---

## `difference_update()`

Также изменяет исходное множество.

Удаляет из него элементы, которые присутствуют в других множествах.

Пример:

```python
s1 = {1, 2, 3, 4}
s2 = {2, 4}

s1.difference_update(s2)

print(s1)
```

Результат:

```python
{1, 3}
```

---

# Добавление и удаление элементов

## Метод `add()`

Добавляет один элемент в множество.

```python
s1 = {"a", "d", "h"}

s1.add("some string")

print(s1)
```

Результат:

```python
{'some string', 'd', 'h', 'a'}
```

Если элемент уже существует, ничего не произойдет.

Это связано с тем, что множества не допускают дубликатов.

---

## Метод `remove()`

Удаляет указанный элемент.

```python
s1 = {"a", "d", "h"}

s1.remove("a")

print(s1)
```

Результат:

```python
{'d', 'h'}
```

⚠️ Если элемента нет в множестве, `remove()` вызовет ошибку `KeyError`.

---

# Очистка множества

## Метод `clear()`

Полностью очищает множество.

```python
s1.clear()

print(s1)
```

Результат:

```python
set()
```

После вызова `clear()` множество остается существовать, но становится пустым.

---

# Полезные методы множеств

| Метод | Назначение |
|--------|------------|
| `union()` | Объединение множеств |
| `intersection()` | Поиск общих элементов |
| `difference()` | Разность множеств |
| `update()` | Объединить и изменить исходное множество |
| `intersection_update()` | Оставить только общие элементы |
| `difference_update()` | Удалить элементы, присутствующие в других множествах |
| `add()` | Добавить элемент |
| `remove()` | Удалить элемент |
| `clear()` | Очистить множество |

---

# Когда использовать множества

Множества особенно полезны в следующих случаях:

- необходимо удалить дубликаты из коллекции;
- нужно быстро проверить наличие элемента;
- требуется найти общие элементы нескольких коллекций;
- необходимо определить различия между наборами данных;
- нужно объединить несколько коллекций, сохранив только уникальные значения.

---

# Итоги урока

`set` — это удобный тип данных для хранения **уникальных элементов**. Множества не сохраняют порядок элементов и не поддерживают индексацию, зато позволяют очень быстро выполнять проверку наличия значения и операции сравнения коллекций. Благодаря встроенным операциям объединения, пересечения и разности множества отлично подходят для обработки больших наборов данных, поиска совпадений и удаления повторяющихся элементов.
