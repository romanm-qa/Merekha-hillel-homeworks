# Strings (`str`)

## Что такое строка

**Строка (`str`)** — это последовательность (sequence) символов Unicode.

Особенности строк в Python:
- являются типом данных `str`;
- состоят из одного или нескольких символов;
- являются **неизменяемыми (immutable)**;
- поддерживают индексацию, срезы и перебор в цикле.

Проверить тип можно с помощью функции `type()`:

```python
print(type("Hello"))
print(type('A'))
```

Результат:

```python
<class 'str'>
<class 'str'>
```

> **Важно:** в Python нет отдельного типа данных для одного символа. Даже один символ (`"A"`) — это строка длиной 1.

---

## Создание строк

Строку можно записать несколькими способами.

### Одинарные кавычки

```python
text = 'Hello'
```

### Двойные кавычки

```python
text = "Hello"
```

### Тройные кавычки

Обычно используются для многострочного текста.

```python
text = """
Первая строка
Вторая строка
Третья строка
"""
```

Все три варианта создают объект типа `str`.

---

## Escape-последовательности

Некоторые специальные символы записываются через обратную косую черту (`\`).

### Экранирование кавычек

```python
print("This is \"double quotes\"")
print('This is \'single quotes\'')
```

Результат:

```python
This is "double quotes"
This is 'single quotes'
```

### Перенос строки (`\n`)

```python
print("Hello\nWorld")
```

Результат:

```text
Hello
World
```

### Возврат каретки (`\r`)

Используется значительно реже. Перемещает курсор в начало строки.

```python
print("Hello\rHi")
```

Результат:

```text
Hillo
```

> На практике чаще всего используются `\"`, `\'`, `\\` и `\n`.

## Ввод строки с клавиатуры

Функция `input()` всегда возвращает строку.

```python
name = input("Введите имя: ")

print(name)
```

## Неизменяемость строк (Immutable)

Строки относятся к **неизменяемым объектам**.

Это означает, что изменить отдельный символ нельзя.

```python
text = "Hello"

text[1] = "a"
```

Получим ошибку:

```python
TypeError: 'str' object does not support item assignment
```

Если изменить строку, Python не меняет существующий объект, а создаёт новый.

```python
text = "Hello"

print(id(text))

text = "Hi"

print(id(text))
```

`id()` будет разным, потому что создаётся новый объект.

---

## Индексация

Каждый символ строки имеет свой индекс.

```text
 H   e   l   l   o
 0   1   2   3   4
```

Получить символ можно по индексу.

```python
text = "Hello"

print(text[1])
```

Результат:

```python
e
```

> **Важно:** индексация начинается с **0**.

---

## Перебор строки

Так как строка является последовательностью, её можно перебирать циклом `for`.

```python
text = "Hello"

for letter in text:
    print(letter)
```

Результат:

```text
H
e
l
l
o
```

---

## Срезы (Slice)

Срез позволяет получить часть строки.

Общий синтаксис:

```python
string[start:stop:step]
```

где:

- `start` — индекс начала;
- `stop` — индекс конца (не включается);
- `step` — шаг.

### Получить часть строки

```python
text = "Hello"

print(text[1:3])
```

Результат:

```python
el
```

### Развернуть строку

Если использовать шаг `-1`, строка будет прочитана в обратном порядке.

```python
text = "Hello"

print(text[::-1])
```

Результат:

```python
olleH
```

> Срезы работают не только со строками, но и с другими последовательностями (`list`, `tuple` и др.).

## Основные методы строк

Python предоставляет большое количество методов для работы со строками. Метод вызывается через точку после объекта строки.

Общий синтаксис:

```python
string.method()
```

---

### split()

Метод `split()` разбивает строку на части по указанному разделителю и возвращает список (`list`).

```python
text = "Hello-world"

parts = text.split("-")

print(parts)
```

Результат:

```python
['Hello', 'world']
```

Можно сразу перебрать полученные части:

```python
text = "Hello-world"

for word in text.split("-"):
    print(word)
```

Результат:

```text
Hello
world
```

---

### upper() и lower()

Метод `upper()` переводит строку в верхний регистр.

Метод `lower()` переводит строку в нижний регистр.

```python
text = "Hello-world"

print(text.upper())
print(text.lower())
```

Результат:

```text
HELLO-WORLD
hello-world
```

---

### find()

Метод `find()` ищет подстроку и возвращает индекс её первого символа.

```python
text = "Hello-world"

print(text.find("world"))
```

Результат:

```python
6
```

Если подстрока не найдена, метод возвращает `-1`.

```python
text = "Hello"

print(text.find("Python"))
```

Результат:

```python
-1
```

---

### strip()

Метод `strip()` удаляет пробелы в начале и в конце строки.

```python
text = "   Hello-world   "

print(text.strip())
```

Результат:

```text
Hello-world
```

> `strip()` удаляет только пробелы по краям строки. Пробелы внутри строки остаются без изменений.

## Форматирование строк

Иногда необходимо объединить строку с другими типами данных (например, числами).

Для этого существует несколько способов.

---

### Конкатенация (`+`)

Самый простой способ — объединить строки оператором `+`.

```python
name = "Filip"
age = 33
country = "UK"

message = "Hello, my name is " + name + ", I am " + str(age) + ", I am from " + country

print(message)
```

Результат:

```text
Hello, my name is Filip, I am 33, I am from UK
```

Недостаток этого способа:
- код становится менее читаемым;
- необходимо вручную преобразовывать числа в строки с помощью `str()`.

---

### Метод format()

Более удобный способ — использовать метод `format()`.

```python
name = "Filip"
age = 33
country = "UK"

message = "Hello, my name is {}, I am {}, I am from {}.".format(name, age, country)

print(message)
```

Результат:

```text
Hello, my name is Filip, I am 33, I am from UK.
```

Также `format()` поддерживает форматирование чисел.

```python
price = 29

message = "The price is {:.2f} dollars."

print(message.format(price))
```

Результат:

```text
The price is 29.00 dollars.
```

Здесь:

- `.2f` — вывести число с двумя знаками после запятой.

---

### F-строки (f-string)

Начиная с Python 3.6 рекомендуется использовать **f-строки**.

Это самый современный и наиболее читаемый способ форматирования.

```python
name = "Filip"
age = 33
country = "UK"

message = f"Hello, my name is {name}, I am {age}, I am from {country}."

print(message)
```

Результат:

```text
Hello, my name is Filip, I am 33, I am from UK.
```

> В современном Python чаще всего используют именно **f-string**, так как они проще читаются и удобнее в использовании.

## Проверка вхождения подстроки

Оператор `in` позволяет проверить, содержится ли одна строка внутри другой.

```python
message = input()

if "Hello" in message or "Hi" in message:
    print("Это приветствие.")
```

Если подстрока найдена, выражение вернёт `True`, иначе — `False`.

---

## Краткие выводы

- `str` — неизменяемый тип данных (immutable).
- Строки являются последовательностями (sequence).
- Поддерживают индексацию, срезы и перебор в цикле `for`.
- Для работы со строками существует множество встроенных методов (`split()`, `find()`, `strip()`, `upper()`, `lower()` и другие).
- Для форматирования строк рекомендуется использовать **f-string**.
- Проверить наличие подстроки можно с помощью оператора `in`.
