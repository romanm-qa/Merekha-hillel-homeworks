# Lists (Списки)

## Что такое список (List)?

**Список (`list`)** — это встроенный изменяемый тип данных Python, предназначенный для хранения нескольких элементов в одной переменной.

Особенности списка:

- элементы расположены в определенном порядке;
- список можно изменять после создания (mutable);
- размер списка может увеличиваться и уменьшаться;
- список может хранить элементы разных типов данных.

```python
numbers = [1, 2, 3]
names = ["Alex", "John", "Kate"]
mixed = ["Python", 29, True, 5.8]
```

---

## Создание списка

Список создается при помощи квадратных скобок.

```python
my_first_list = ["Hello", 33, True, "everybody!"]
```

Проверить тип данных можно через функцию `type()`.

```python
print(type(my_first_list))
```

Вывод:

```python
<class 'list'>
```

---

## Индексация списка

Как и строки, списки индексируются с **нуля**.

```python
colors = ["red", "green", "blue"]

print(colors[0])   # red
print(colors[1])   # green
print(colors[2])   # blue
```

Также работают отрицательные индексы.

```python
print(colors[-1])   # blue
print(colors[-2])   # green
```

---

## Изменение элемента по индексу

Главное отличие списка от строки — список можно изменять.

```python
numbers = [10, 20, 30]

numbers[1] = 50

print(numbers)
```

Результат:

```python
[10, 50, 30]
```

То есть элемент с индексом `1` был заменен новым значением.

---

## Добавление элементов

### append()

Метод `append()` добавляет **один объект** в конец списка.

```python
fruits = ["apple", "banana"]

fruits.append("orange")

print(fruits)
```

Результат:

```python
['apple', 'banana', 'orange']
```

Если передать список, то он станет одним элементом.

```python
numbers = [1, 2]

numbers.append([3, 4])

print(numbers)
```

Результат:

```python
[1, 2, [3, 4]]
```

> **Важно:** `append()` всегда добавляет только один объект.

---

## Перебор списка

Список можно перебирать при помощи цикла `for`.

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

Вывод:

```python
10
20
30
```

---

## Срезы (Slicing)

Для списков работают те же срезы, что и для строк.

Получить часть списка:

```python
numbers = [1, 3, 5, 9, 11, 16, 28, 44.7, 90.6]

print(numbers[2:6])
```

Результат:

```python
[5, 9, 11, 16]
```

Использовать шаг:

```python
numbers = [1, 3, 5, 9, 11, 16, 28, 44.7, 90.6]

for number in numbers[::2]:
    print(number)
```

Вывод:

```python
1
5
11
28
90.6
```

# Основные методы списка

## sort()

Метод `sort()` сортирует список по возрастанию.

```python
numbers = [11, 5, 16, 28, 5334, 44.7, 90.6, 1, 3, 9]

numbers.sort()

print(numbers)
```

Результат:

```python
[1, 3, 5, 9, 11, 16, 28, 44.7, 90.6, 5334]
```

> **Важно:** `sort()` изменяет исходный список. Новый список не создается.

---

## len()

Функция `len()` возвращает количество элементов в списке.

```python
numbers = [10, 20, 30]

print(len(numbers))
```

Результат:

```python
3
```

---

## extend()

Метод `extend()` добавляет **все элементы** другого итерируемого объекта.

```python
numbers = [1, 2, 3]

numbers.extend([4, 5])

print(numbers)
```

Результат:

```python
[1, 2, 3, 4, 5]
```

Работает не только со списками.

```python
letters = [1, 2, 3]

letters.extend("abc")

print(letters)
```

Результат:

```python
[1, 2, 3, 'a', 'b', 'c']
```

> В отличие от `append()`, метод `extend()` добавляет каждый элемент отдельно.

---

## count()

Метод `count()` подсчитывает количество одинаковых элементов.

```python
numbers = [1, 2, 3, 2, 1, 1]

print(numbers.count(1))
```

Результат:

```python
3
```

---

## pop()

Метод `pop()` удаляет элемент из списка и одновременно возвращает его.

Без аргументов удаляется последний элемент.

```python
numbers = [10, 20, 30]

last_number = numbers.pop()

print(last_number)
print(numbers)
```

Результат:

```python
30
[10, 20]
```

Можно удалить элемент по индексу.

```python
numbers = [10, 20, 30]

numbers.pop(1)

print(numbers)
```

Результат:

```python
[10, 30]
```

Метод `pop()` часто используют при работе со **стеком (Stack)** по принципу **LIFO (Last In, First Out)** — последним добавили, первым получили.

# Дополнительные полезные методы списков

Следующие методы не рассматривались в данном уроке EPAM, однако они очень часто используются на практике и пригодятся при написании Python-кода.

## insert()

Метод `insert()` вставляет элемент по указанному индексу.

```python
numbers = [1, 2, 3]

numbers.insert(1, 100)

print(numbers)
```

Результат:

```python
[1, 100, 2, 3]
```

---

## remove()

Метод `remove()` удаляет первое найденное значение.

```python
numbers = [1, 2, 3, 2]

numbers.remove(2)

print(numbers)
```

Результат:

```python
[1, 3, 2]
```

> Если элемент отсутствует, будет вызвана ошибка `ValueError`.

---

## index()

Метод `index()` возвращает индекс первого найденного элемента.

```python
numbers = [10, 20, 30]

print(numbers.index(20))
```

Результат:

```python
1
```

---

## reverse()

Метод `reverse()` разворачивает список.

```python
numbers = [1, 2, 3, 4]

numbers.reverse()

print(numbers)
```

Результат:

```python
[4, 3, 2, 1]
```

---

## copy()

Метод `copy()` создает поверхностную копию списка.

```python
numbers = [1, 2, 3]

copy_numbers = numbers.copy()

print(copy_numbers)
```

Результат:

```python
[1, 2, 3]
```

# append() и extend()

Новички часто путают эти методы.

### append()

Добавляет **один объект**.

```python
numbers = [1, 2]

numbers.append([3, 4])

print(numbers)
```

Результат:

```python
[1, 2, [3, 4]]
```

---

### extend()

Добавляет **каждый элемент отдельно**.

```python
numbers = [1, 2]

numbers.extend([3, 4])

print(numbers)
```

Результат:

```python
[1, 2, 3, 4]
```

---

# Копирование списка

Если присвоить список другой переменной, новый список не создается.

```python
numbers = [1, 2, 3]

copy_numbers = numbers

copy_numbers.append(4)

print(numbers)
print(copy_numbers)
```

Результат:

```python
[1, 2, 3, 4]
[1, 2, 3, 4]
```

Обе переменные ссылаются на один и тот же объект.

Чтобы создать независимую копию, используйте `copy()`.

```python
numbers = [1, 2, 3]

copy_numbers = numbers.copy()

copy_numbers.append(4)

print(numbers)
print(copy_numbers)
```

Результат:

```python
[1, 2, 3]
[1, 2, 3, 4]
```

# List Comprehension

**List Comprehension** — это компактный способ создания нового списка на основе существующей последовательности.

Общий синтаксис:

```python
new_list = [expression for item in iterable]
```

где:

- `expression` — что будет записано в новый список;
- `item` — текущий элемент;
- `iterable` — последовательность, по которой выполняется перебор.

---

## Пример без List Comprehension

```python
numbers = [1, 2, 3, 4, 5]

squares = []

for number in numbers:
    squares.append(number ** 2)

print(squares)
```

Результат:

```python
[1, 4, 9, 16, 25]
```

---

## Тот же пример с List Comprehension

```python
numbers = [1, 2, 3, 4, 5]

squares = [number ** 2 for number in numbers]

print(squares)
```

Результат:

```python
[1, 4, 9, 16, 25]
```

---

## List Comprehension с условием

Можно сразу фильтровать элементы.

```python
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)
```

Результат:

```python
[2, 4, 6]
```

---

## Когда использовать

List Comprehension удобно применять, когда необходимо:

- создать новый список;
- преобразовать существующий список;
- выполнить фильтрацию элементов.

> Если выражение становится слишком длинным или сложным, лучше использовать обычный цикл `for` — такой код проще читать и поддерживать.

# Краткие выводы

- `list` — изменяемый тип данных (**mutable**).
- Списки хранят элементы в определенном порядке.
- Элементы доступны по индексу.
- Поддерживаются отрицательные индексы и срезы.
- Список может содержать объекты разных типов.
- Для перебора элементов обычно используют цикл `for`.
- Для добавления одного элемента используется `append()`.
- Для добавления нескольких элементов — `extend()`.
- Для сортировки применяется `sort()`.
- Для удаления элемента с возвратом значения используется `pop()`.
- Для получения количества элементов используется `len()`.
- Для поиска количества одинаковых элементов применяется `count()`.
- Для создания независимой копии списка рекомендуется использовать `copy()`.
