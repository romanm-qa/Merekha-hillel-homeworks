# Tuples (кортежи)

## Что такое tuple

`tuple` (кортеж) — это упорядоченная коллекция элементов, очень похожая на `list`.

Кортеж:
- хранит элементы в определенном порядке;
- поддерживает индексацию;
- поддерживает срезы (slicing);
- поддерживает цикл `for`;
- может содержать любые типы данных;
- может содержать вложенные коллекции.

Главное отличие от списка:

> **Tuple — immutable (неизменяемый) тип данных.**

После создания нельзя:
- изменить элемент;
- удалить элемент;
- добавить новый элемент.

---

## Создание кортежа

Через круглые скобки:

```python
colors = ("Red", "Green", "Blue")
```

Или вообще без скобок:

```python
colors = "Red", "Green", "Blue"
```

Оба варианта создают объект типа `tuple`.

Проверка типа:

```python
print(type(colors))
```

Результат:

```python
<class 'tuple'>
```

---

## Кортеж может хранить любые типы данных

```python
my_tuple = (
    5.5,
    True,
    "Python",
    (1, 2, 3),
    [4, 5, 6],
    {"name": "Roman"}
)
```

Так же, как и список, кортеж может содержать разные типы данных и даже другие коллекции.

---

## Пустой кортеж

```python
empty_tuple = ()

print(type(empty_tuple))
```

Получим:

```python
<class 'tuple'>
```

---

## Кортеж из одного элемента ⚠️

Очень частый вопрос на собеседованиях.

Неправильно:

```python
number = (1)

print(type(number))
```

Результат:

```python
<class 'int'>
```

Python воспринимает это как обычное число в скобках.

Правильно:

```python
number = (1,)

print(type(number))
```

Результат:

```python
<class 'tuple'>
```

> **Не скобки, а запятая делает tuple из одного элемента.**

---

## Обход кортежа

По кортежу можно проходить циклом так же, как и по списку.

```python
my_tuple = (5.5, True, "Python", (1, 2, 3))

for item in my_tuple:
    print(item)
```

Результат:

```python
5.5
True
Python
(1, 2, 3)
```

---

## Индексация

Можно получать элементы по индексу.

```python
my_tuple = (5.5, True, "Python")

print(my_tuple[0])
```

Результат:

```python
5.5
```

---

## Срезы (Slicing)

Работают абсолютно так же, как и у строк и списков.

Например, перевернуть кортеж:

```python
my_tuple = (5.5, True, "Python", (1, 2, 3))

print(my_tuple[::-1])
```

Результат:

```python
((1, 2, 3), "Python", True, 5.5)
```

---

## Что нужно запомнить

✅ `tuple` — упорядоченная коллекция.

✅ `tuple` — **immutable** (неизменяемый) тип данных.

✅ Создать можно двумя способами:

```python
a = (1, 2, 3)
```

или

```python
a = 1, 2, 3
```

✅ Пустой кортеж:

```python
()
```

✅ Кортеж из одного элемента обязательно содержит запятую:

```python
(1,)
```

✅ Поддерживаются:
- индексация;
- цикл `for`;
- срезы (`[:]`, `[::-1]` и т.д.).

# Packing и Unpacking

## Unpacking (распаковка)

Python умеет автоматически распаковывать кортеж в несколько переменных.

```python
(a, b, c) = (40, 56.6, 90)

print(a)
print(b)
print(c)
```

Результат:

```python
40
56.6
90
```

Это называется **unpacking (распаковка)**.

Python берет каждый элемент кортежа и присваивает его соответствующей переменной.

---

## Оператор распаковки *

Можно распаковать кортеж прямо при выводе.

```python
my_tuple = (40, 56.6, 90)

print(my_tuple)
print(*my_tuple)
```

Результат:

```python
(40, 56.6, 90)

40 56.6 90
```

Без `*` выводится сам кортеж.

С `*` выводятся его элементы отдельно.

---

## Packing (упаковка)

Python умеет делать и обратную операцию.

```python
a, b, c = 40, 56.6, 90

print(a)
print(b)
print(c)
```

Здесь справа автоматически создается кортеж, после чего Python сразу его распаковывает.

Такую запись называют **packing (упаковка)**.

---

## Важно

Количество переменных должно совпадать с количеством элементов.

Правильно:

```python
a, b, c = (1, 2, 3)
```

Ошибка:

```python
a, b = (1, 2, 3)
```

Получим:

```python
ValueError
```

---

# Обмен значений (Swap)

Без временной переменной:

```python
a = 1
b = 2

a, b = b, a

print(a, b)
```

Результат:

```python
2 1
```

Python делает это через упаковку и распаковку кортежа.

---

# Операторы == и is

Очень важно понимать разницу.

## ==

Проверяет **равенство значений**.

```python
x = (1, 2, 3)
y = (1, 2, 3)

print(x == y)
```

Результат:

```python
True
```

Элементы одинаковые.

---

## id()

Каждый объект в памяти имеет свой идентификатор.

```python
print(id(x))
print(id(y))
```

Если `id()` одинаковый — это один и тот же объект.

Если разный — объекты разные.

---

## is

Проверяет **являются ли две переменные одним объектом в памяти**.

```python
print(x is y)
```

В отличие от `==`, оператор `is` сравнивает не значения, а объект.

---

## Пример

```python
x = (1, 2, 3)
y = (1, 2, 3)

print(x == y)
print(x is y)
```

Возможный результат:

```python
True
True
```

или

```python
True
False
```

Это зависит от внутренней оптимизации Python.

Главное правило:

- `==` → сравнивает значения.
- `is` → сравнивает объекты.

---

## Еще пример

```python
x = 2 ** 100
y = 2 ** 100

print(x == y)
print(x is y)
```

Результат обычно будет:

```python
True
False
```

Значения одинаковые, но объекты разные.

# Что нужно запомнить

✅ `tuple` используется для хранения неизменяемых данных.

✅ Поддерживает:
- индексацию;
- срезы;

✅ Можно распаковывать:

a, b, c = (1, 2, 3)

a, b = b, a

✅ `id()` показывает идентификатор объекта в памяти.

# Когда использовать tuple вместо list

Используй **tuple**, когда данные **не должны изменяться**.

Например:

```python
days = (
    "Monday",
    "Tuesday",
    "Wednesday",
    "Thursday",
    "Friday",
    "Saturday",
    "Sunday",
)
```

Используй **list**, когда нужно:

- добавлять элементы;
- удалять элементы;
- изменять существующие значения.

# Итоги

В этой теме мы познакомились с кортежами (`tuple`) — неизменяемым типом данных в Python.

Основные выводы:

- `tuple` используется для хранения упорядоченных данных, которые не должны изменяться после создания;
- кортеж поддерживает индексацию, срезы и перебор в цикле `for`;
- кортеж можно создать как с круглыми скобками, так и без них;
- для создания кортежа из одного элемента обязательно нужна запятая (`(1,)`);
- кортеж может содержать элементы любых типов данных, включая другие коллекции;
- с помощью **packing** несколько значений автоматически объединяются в кортеж;
- с помощью **unpacking** элементы кортежа можно быстро распределить по переменным;
- распаковка позволяет удобно менять значения переменных местами без использования временной переменной;
- оператор `==` сравнивает значения объектов, а оператор `is` проверяет, ссылаются ли переменные на один и тот же объект в памяти;
- `tuple` стоит использовать в случаях, когда данные должны оставаться неизменными, а `list` — когда их необходимо изменять.
