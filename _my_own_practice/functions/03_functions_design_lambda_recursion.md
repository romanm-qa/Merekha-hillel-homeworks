# 1. Принципы проектирования функций

После изучения основ создания функций возникают следующие вопросы:

- как правильно разделить большую задачу на функции;
- как функции должны взаимодействовать между собой;
- насколько большими должны быть функции.

Эти принципы относятся не только к Python, но и к другим языкам программирования.

При проектировании функций важно учитывать три характеристики:

- **coupling** — связанность функций;
- **cohesion** — целостность функции;
- **size** — размер функции.

---

## 1.1. Coupling — связанность

**Coupling** показывает, насколько сильно функция зависит от других частей программы.

Хорошая функция должна быть максимально изолированной и независимой от внешнего состояния.

Функции лучше получать необходимые данные через аргументы и возвращать результат через `return`.

```python
def calculate_total(price, quantity):
    return price * quantity


total = calculate_total(100, 3)

print(f"Общая стоимость: {total}")
```

Результат:

```text
Общая стоимость: 300
```

Функция `calculate_total()`:

- получает все необходимые данные через параметры;
- не зависит от глобальных переменных;
- возвращает результат;
- может использоваться в разных частях программы.

### Изменяемые аргументы

Нужно осторожно работать с изменяемыми объектами:

- списками;
- словарями;
- множествами.

Если функция изменяет полученный объект, это изменение будет видно за пределами функции.

```python
def add_number(numbers):
    numbers.append(4)


values = [1, 2, 3]

add_number(values)

print(values)
```

Результат:

```text
[1, 2, 3, 4]
```

Функция изменила исходный список.

Если изменять оригинальный объект не нужно, можно создать его копию:

```python
def add_number(numbers):
    copied_numbers = numbers.copy()
    copied_numbers.append(4)

    return copied_numbers


values = [1, 2, 3]
new_values = add_number(values)

print(f"Исходный список: {values}")
print(f"Новый список: {new_values}")
```

Результат:

```text
Исходный список: [1, 2, 3]
Новый список: [1, 2, 3, 4]
```

---

## 1.2. Cohesion — целостность

Функция должна выполнять одну конкретную задачу.

Этот принцип часто называют **Single Purpose** или **Single Responsibility** — одна ответственность.

Хороший вариант:

```python
def calculate_rectangle_area(length, width):
    return length * width


def display_result(area):
    print(f"Площадь прямоугольника: {area}")


rectangle_area = calculate_rectangle_area(5, 3)
display_result(rectangle_area)
```

Здесь каждая функция имеет собственную задачу:

- `calculate_rectangle_area()` вычисляет площадь;
- `display_result()` выводит результат.

Плохой вариант — одна функция одновременно:

- получает данные;
- проверяет их;
- выполняет несколько разных вычислений;
- выводит результат;
- сохраняет данные.

Чем больше обязанностей у функции, тем сложнее её:

- читать;
- тестировать;
- изменять;
- повторно использовать.

---

## 1.3. Size — размер функции

Функция должна быть относительно небольшой.

Точного ограничения по количеству строк нет. Главный критерий — функцию должно быть легко понять.

Если функция стала слишком большой, возможно, внутри неё находится несколько отдельных задач. В таком случае её стоит разделить на несколько функций.

Основные признаки слишком большой функции:

- много уровней вложенности;
- длинные цепочки `if`, `elif` и `else`;
- повторяющийся код;
- функция выполняет несколько разных действий;
- сложно подобрать короткое и понятное название.

---

# 2. Декомпозиция задачи

**Декомпозиция** — это разделение большой задачи на несколько небольших подзадач.

Рассмотрим программу, которая вычисляет площадь одной из трёх фигур:

- квадрата;
- прямоугольника;
- круга.

Пользователь должен указать тип фигуры и необходимые значения.

## 2.1. Формулы

| Фигура | Формула | Входные данные |
|---|---|---|
| Квадрат | `S = a ** 2` | `a` — длина стороны |
| Прямоугольник | `S = a * b` | `a`, `b` — длины сторон |
| Круг | `S = π * r ** 2` | `r` — радиус |

Программа должна:

1. Получить тип фигуры через `input()`.
2. Проверить, поддерживается ли такая фигура.
3. Получить необходимые значения.
4. Проверить введённые данные.
5. Рассчитать площадь.
6. Вывести результат.

Без декомпозиции программа может превратиться в большую цепочку условий:

```python
shape_type = input(
    "Введите фигуру: square, rectangle или circle: "
)

if shape_type == "square":
    side = input("Введите длину стороны: ")

    if side.isdigit():
        side = int(side)
        area = side ** 2
        print(f"Площадь квадрата: {area}")
    else:
        print(f"{side} не является числом")

elif shape_type == "rectangle":
    length = input("Введите длину: ")
    width = input("Введите ширину: ")

    if length.isdigit():
        length = int(length)

        if width.isdigit():
            width = int(width)
            area = length * width
            print(f"Площадь прямоугольника: {area}")
        else:
            print(f"{width} не является числом")
    else:
        print(f"{length} не является числом")

elif shape_type == "circle":
    radius = input("Введите радиус: ")

    if radius.isdigit():
        radius = int(radius)
        area = 3.14 * radius ** 2
        print(f"Площадь круга: {area}")
    else:
        print(f"{radius} не является числом")

else:
    print(f"Неизвестная фигура: {shape_type}")
```

Код работает, но одна большая конструкция занимается сразу несколькими задачами.

Её можно декомпозировать:

```python
from math import pi


def calculate_square_area(side):
    return side ** 2


def calculate_rectangle_area(length, width):
    return length * width


def calculate_circle_area(radius):
    return pi * radius ** 2


def read_number(message):
    value = input(message)

    if value.isdigit():
        return int(value)

    print(f"{value} не является числом")
    return None


shape_type = input(
    "Введите фигуру: square, rectangle или circle: "
)

if shape_type == "square":
    side = read_number("Введите длину стороны: ")

    if side is not None:
        area = calculate_square_area(side)
        print(f"Площадь квадрата: {area}")

elif shape_type == "rectangle":
    length = read_number("Введите длину: ")
    width = read_number("Введите ширину: ")

    if length is not None and width is not None:
        area = calculate_rectangle_area(length, width)
        print(f"Площадь прямоугольника: {area}")

elif shape_type == "circle":
    radius = read_number("Введите радиус: ")

    if radius is not None:
        area = calculate_circle_area(radius)
        print(f"Площадь круга: {area}")

else:
    print(f"Неизвестная фигура: {shape_type}")
```

Теперь каждая функция выполняет одну конкретную задачу.

## Вывод по проектированию функций

При декомпозиции программы следует соблюдать три основных правила:

1. Функция должна как можно меньше зависеть от внешнего состояния.
2. Каждая функция должна выполнять одну конкретную задачу.
3. Функция должна быть относительно небольшой и понятной.

---

# 3. Lambda-функции

Иногда в программе нужна небольшая функция:

- состоящая из одного выражения;
- используемая только в одном месте;
- не требующая отдельного определения через `def`.

Для таких случаев в Python существуют **lambda-функции**.

**Lambda-функция** — это анонимная функция, состоящая из одного выражения. Выражение вычисляется при вызове функции, а полученный результат автоматически возвращается.

Lambda называется анонимной, потому что изначально создаётся без имени.

---

## 3.1. Синтаксис lambda

Lambda с аргументами:

```python
lambda argument_1, argument_2: expression
```

Lambda без аргументов:

```python
lambda: expression
```

Основные особенности:

- ключевое слово `def` не используется;
- круглые скобки вокруг аргументов не нужны;
- после аргументов ставится двоеточие;
- тело состоит только из одного выражения;
- `return` писать не нужно;
- результат выражения возвращается автоматически.

---

## 3.2. Обычная функция и lambda

Обычная функция:

```python
def sum_numbers(first_number, second_number):
    return first_number + second_number


result = sum_numbers(1, 3)

print(result)
```

Lambda-функция:

```python
sum_numbers_lambda = lambda first_number, second_number: (
    first_number + second_number
)

result = sum_numbers_lambda(1, 3)

print(result)
```

Результат в обоих случаях:

```text
4
```

Lambda-выражение создаёт объект функции. Этот объект можно сохранить в переменной и затем вызвать.

Однако постоянное присваивание lambda-функции имени обычно не имеет большого смысла. Если функция используется многократно или содержит важную логику, лучше определить обычную функцию через `def`.

Lambda чаще применяется непосредственно там, где другая функция ожидает получить функцию в качестве аргумента.

Например:

- `sort()`;
- `sorted()`;
- `map()`;
- `filter()`;
- `reduce()`.

# 4. Сортировка с помощью lambda

Метод `list.sort()` сортирует исходный список и возвращает `None`.

Общая форма:

```python
list.sort(key=None, reverse=False)
```

Параметры:

- `key` — функция, результат которой используется для сортировки;
- `reverse=False` — сортировка по возрастанию;
- `reverse=True` — сортировка по убыванию.

Метод `sort()` изменяет список на месте — **in-place**.

Также сортировка является стабильной: взаимный порядок элементов с одинаковыми ключами сохраняется.

---

## 4.1. Сортировка кортежей по умолчанию

```python
pairs = [
    (1, "one"),
    (3, "three"),
    (2, "two"),
    (4, "four"),
]

pairs.sort()

print(pairs)
```

Результат:

```text
[(1, 'one'), (2, 'two'), (3, 'three'), (4, 'four')]
```

По умолчанию кортежи сортируются по первому элементу.

---

## 4.2. Сортировка по второму элементу с обычной функцией

```python
def get_text(pair):
    return pair[1]


pairs = [
    (1, "one"),
    (3, "three"),
    (2, "two"),
    (4, "four"),
]

pairs.sort(key=get_text)

print(pairs)
```

Результат:

```text
[(4, 'four'), (1, 'one'), (3, 'three'), (2, 'two')]
```

Функция `get_text()` получает один кортеж и возвращает его второй элемент:

```python
pair[1]
```

Именно этот элемент используется как ключ сортировки.

---

## 4.3. Сортировка по второму элементу с lambda

Отдельную функцию можно заменить lambda-выражением:

```python
pairs = [
    (1, "one"),
    (3, "three"),
    (2, "two"),
    (4, "four"),
]

pairs.sort(key=lambda pair: pair[1])

print(pairs)
```

Результат:

```text
[(4, 'four'), (1, 'one'), (3, 'three'), (2, 'two')]
```

Lambda получает каждый кортеж и возвращает его второй элемент:

```python
lambda pair: pair[1]
```

Метод `sort()` использует полученные строки для сортировки:

```text
four → one → three → two
```

Lambda подходит для этого случая, потому что функция:

- маленькая;
- используется один раз;
- состоит из одного выражения.

# 5. Функция map

Синтаксис:

```python
map(function, iterable)
```

`map()` применяет переданную функцию к каждому элементу итерируемого объекта.

Функция возвращает не готовый список, а специальный объект-итератор `map`.

Чтобы получить список, результат можно передать в `list()`.

---

## 5.1. Возведение всех чисел в квадрат

```python
numbers = [48, 6, 9, 21, 1]

squared_numbers = map(
    lambda number: number ** 2,
    numbers,
)

print(squared_numbers)
print(list(squared_numbers))
```

Результат:

```text
<map object at ...>
[2304, 36, 81, 441, 1]
```

Lambda-функция:

```python
lambda number: number ** 2
```

по очереди получает каждое число:

```text
48 → 2304
6 → 36
9 → 81
21 → 441
1 → 1
```

Похожий результат можно получить через list comprehension:

```python
numbers = [48, 6, 9, 21, 1]

squared_numbers = [
    number ** 2
    for number in numbers
]

print(squared_numbers)
```

# 6. Функция filter

Синтаксис:

```python
filter(function, iterable)
```

`filter()` проверяет каждый элемент итерируемого объекта и оставляет только те элементы, для которых функция вернула `True`.

Функция возвращает специальный объект-итератор `filter`. Чтобы получить список, используется `list()`.

---

## 6.1. Получение чётных чисел

```python
numbers = [48, 6, 9, 21, 1, 35, 16, 12, 0, -1]

even_numbers = filter(
    lambda number: number % 2 == 0,
    numbers,
)

print(list(even_numbers))
```

Результат:

```text
[48, 6, 16, 12, 0]
```

Условие:

```python
number % 2 == 0
```

возвращает `True`, если число является чётным.

Похожий результат через list comprehension:

```python
numbers = [48, 6, 9, 21, 1, 35, 16, 12, 0, -1]

even_numbers = [
    number
    for number in numbers
    if number % 2 == 0
]

print(even_numbers)
```

---

## 6.2. Использование filter с None

Вместо функции в `filter()` можно передать `None`:

```python
filter(None, iterable)
```

В таком случае удаляются все ложные значения.

К ложным значениям относятся:

- `False`;
- `None`;
- `0`;
- `0.0`;
- пустая строка `""`;
- пустой список `[]`;
- пустой словарь `{}`;
- пустое множество `set()`;
- другие пустые коллекции.

Пример:

```python
numbers = [48, 6, 9, 21, 1, 35, 16, 12, 0, -1]

truthy_numbers = filter(None, numbers)

print(list(truthy_numbers))
```

Результат:

```text
[48, 6, 9, 21, 1, 35, 16, 12, -1]
```

Число `0` было удалено, потому что при преобразовании в `bool` оно даёт `False`.

Эти два выражения работают похожим образом:

```python
filter(function, iterable)
```

```python
[
    item
    for item in iterable
    if function(item)
]
```

А эти выражения также эквивалентны:

```python
filter(None, iterable)
```

```python
[
    item
    for item in iterable
    if item
]
```

# 7. Функция reduce

Функция `reduce()` находится в модуле `functools`, поэтому её необходимо импортировать:

```python
from functools import reduce
```

Синтаксис:

```python
reduce(function, iterable)
```

Или с начальным значением:

```python
reduce(function, iterable, initializer)
```

`reduce()` последовательно применяет функцию с двумя аргументами к элементам итерируемого объекта слева направо.

В результате вся последовательность сводится к одному значению.

---

## 7.1. Сумма элементов списка

```python
from functools import reduce


numbers = [1, 2, 3, 4, 5]

result = reduce(
    lambda first_number, second_number: (
        first_number + second_number
    ),
    numbers,
)

print(result)
```

Результат:

```text
15
```

Вычисление выполняется следующим образом:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
10 + 5 = 15
```

Или в виде одного выражения:

```text
((((1 + 2) + 3) + 4) + 5) = 15
```

На первом шаге `reduce()` берёт первые два элемента:

```text
1 и 2
```

Функция складывает их и получает:

```text
3
```

Полученный результат используется на следующем шаге вместе со следующим элементом:

```text
3 и 3
```

Процесс продолжается, пока не останется одно значение.

| Шаг | Аргументы функции | Результат | Оставшиеся значения |
|---:|---|---:|---|
| 0 | — | — | `[1, 2, 3, 4, 5]` |
| 1 | `1, 2` | `3` | `[3, 3, 4, 5]` |
| 2 | `3, 3` | `6` | `[6, 4, 5]` |
| 3 | `6, 4` | `10` | `[10, 5]` |
| 4 | `10, 5` | `15` | `[15]` |

---

## 7.2. Последовательность из одного элемента

Если последовательность содержит только один элемент, он становится результатом:

```python
from functools import reduce


result = reduce(
    lambda first_number, second_number: (
        first_number + second_number
    ),
    [9],
)

print(result)
```

Результат:

```text
9
```

Функцию складывания вызывать не требуется, потому что других элементов нет.

---

## 7.3. Пустая последовательность и initializer

Если последовательность пустая, можно передать начальное значение `initializer`:

```python
from functools import reduce


result = reduce(
    lambda first_number, second_number: (
        first_number + second_number
    ),
    [],
    -1,
)

print(result)
```

Результат:

```text
-1
```

Поскольку список пустой, `reduce()` возвращает значение `initializer`.

Если вызвать `reduce()` с пустой последовательностью без `initializer`, возникнет ошибка:

```python
from functools import reduce


result = reduce(
    lambda first_number, second_number: (
        first_number + second_number
    ),
    [],
)
```

Результат:

```text
TypeError: reduce() of empty iterable with no initial value
```

Дополнительные инструменты для работы с итераторами и функциями находятся в модулях:

- `functools`;
- `itertools`.

## Вывод по lambda, map, filter и reduce

Lambda-функция — это небольшая анонимная функция, которая:

- может принимать несколько аргументов;
- содержит только одно выражение;
- автоматически возвращает результат выражения;
- часто используется как аргумент другой функции.

Чаще всего lambda применяется вместе с:

- `sort()` и `sorted()` — для получения ключа сортировки;
- `map()` — для преобразования каждого элемента;
- `filter()` — для отбора элементов;
- `reduce()` — для сведения последовательности к одному значению.

Lambda удобно применять для короткой одноразовой операции. Если логика становится сложной или используется многократно, лучше создать обычную функцию через `def`.

# 8. Рекурсия

## 8.1. Что такое рекурсия

Функции в Python могут вызывать другие функции. Кроме того, функция может вызывать саму себя.

**Рекурсия** — это способ решения задачи, при котором её решение зависит от решения уменьшенных версий той же задачи.

Функция, которая вызывает саму себя, называется **рекурсивной функцией**.

Простейший пример:

```python
def countdown(number):
    print(number)

    if number == 0:
        return

    countdown(number - 1)


countdown(3)
```

Результат:

```text
3
2
1
0
```

Функция `countdown()` вызывает себя, но каждый раз получает уменьшенное значение:

```text
countdown(3)
countdown(2)
countdown(1)
countdown(0)
```

Когда аргумент становится равен `0`, функция прекращает рекурсивные вызовы.

---

## 8.2. Рекурсия и циклы

Рекурсию часто сравнивают с циклами.

Цикл многократно выполняет блок кода, а рекурсивная функция многократно вызывает саму себя.

Почти любую рекурсивную функцию можно переписать с помощью цикла. Во многих случаях алгоритм с циклом также можно представить рекурсивно.

Обратный отсчёт через цикл:

```python
def countdown(number):
    while number >= 0:
        print(number)
        number -= 1


countdown(3)
```

Результат будет таким же:

```text
3
2
1
0
```

Рекурсия особенно полезна для задач, которые естественным образом разделяются на уменьшенные версии самих себя.

Например:

- обход вложенных структур;
- работа с деревьями;
- поиск файлов во вложенных папках;
- математические алгоритмы;
- последовательности;
- фракталы;
- алгоритмы сортировки и поиска.

Примером рекурсии в математике являются фракталы — фигуры, части которых повторяют форму всей фигуры.

К таким фигурам относятся:

- снежинка Коха;
- треугольник Серпинского.

Бытовой пример рекурсии — два зеркала, расположенные друг напротив друга. В каждом отражении появляется следующее уменьшенное отражение.

---

# 9. Обязательные части рекурсии

Для корректного завершения рекурсии необходимы два условия:

1. **Базовый случай** — условие остановки рекурсии.
2. **Рекурсивный случай** — повторный вызов функции с изменённым аргументом.

Общая структура рекурсивной функции:

```python
def function_name(argument):
    if base_condition:
        return predefined_value

    return function_name(modified_argument)
```

---

## 9.1. Базовый случай

**Базовый случай** — это условие, при котором задача уже имеет известный результат и следующий рекурсивный вызов не требуется.

В примере с обратным отсчётом базовый случай наступает, когда число становится равным нулю:

```python
if number == 0:
    return
```

Без базового случая функция продолжала бы вызывать себя бесконечно.

---

## 9.2. Изменение аргумента

При каждом рекурсивном вызове аргумент должен изменяться таким образом, чтобы функция постепенно приближалась к базовому случаю.

```python
countdown(number - 1)
```

Если снова передавать то же значение:

```python
countdown(number)
```

функция никогда не приблизится к условию остановки.

Правильная логика:

```text
3 → 2 → 1 → 0 → остановка
```

Неправильная логика:

```text
3 → 3 → 3 → 3 → ...
```

---

# 10. Как выполняется рекурсивная функция

Рассмотрим функцию, которая вычисляет сумму чисел от `1` до указанного числа:

```python
def calculate_sum(number):
    if number == 1:
        return 1

    return number + calculate_sum(number - 1)


result = calculate_sum(4)

print(result)
```

Результат:

```text
10
```

Сначала рекурсивные вызовы углубляются:

```text
calculate_sum(4)
4 + calculate_sum(3)
4 + 3 + calculate_sum(2)
4 + 3 + 2 + calculate_sum(1)
```

При `number == 1` срабатывает базовый случай:

```python
return 1
```

После этого функции начинают возвращать результаты в обратном порядке:

```text
calculate_sum(1) → 1
calculate_sum(2) → 2 + 1 = 3
calculate_sum(3) → 3 + 3 = 6
calculate_sum(4) → 4 + 6 = 10
```

Важно понимать, что рекурсивные вызовы сначала накапливаются, а затем завершаются в обратном порядке.

---

# 11. Последовательность Фибоначчи

Классический пример применения рекурсии — вычисление чисел Фибоначчи.

В этой версии последовательность начинается так:

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

Здесь:

- первое число равно `0`;
- второе число равно `1`;
- каждое следующее число равно сумме двух предыдущих.

Формула:

```text
Fib(N) = Fib(N - 2) + Fib(N - 1)
```

Базовые случаи:

```text
Fib(1) = 0
Fib(2) = 1
```

Условия можно представить следующим образом:

| Условие | Результат | Тип случая |
|---|---:|---|
| `N == 1` | `0` | Базовый |
| `N == 2` | `1` | Базовый |
| `N > 2` | `Fib(N - 2) + Fib(N - 1)` | Рекурсивный |

---

# 12. Фибоначчи с помощью цикла

Сначала задачу можно решить обычным циклом:

```python
def get_fibonacci(number):
    fibonacci_number = None

    if number < 1:
        print("Номер элемента должен быть больше 0")

    elif number == 1:
        fibonacci_number = 0

    elif number == 2:
        fibonacci_number = 1

    else:
        previous_two = 0
        previous_one = 1

        for _ in range(2, number):
            fibonacci_number = previous_two + previous_one
            previous_two = previous_one
            previous_one = fibonacci_number

    return fibonacci_number
```

Пример использования:

```python
print(get_fibonacci(5))
print(get_fibonacci(7))
```

Результат:

```text
3
8
```

Разберём переменные:

- `previous_two` — число Фибоначчи на позиции `N - 2`;
- `previous_one` — число Фибоначчи на позиции `N - 1`;
- `fibonacci_number` — новое число Фибоначчи.

Начальные значения:

```python
previous_two = 0
previous_one = 1
```

На каждой итерации вычисляется следующее число:

```python
fibonacci_number = previous_two + previous_one
```

После этого предыдущие значения сдвигаются:

```python
previous_two = previous_one
previous_one = fibonacci_number
```

Для пятого элемента вычисления выглядят так:

```text
0 + 1 = 1
1 + 1 = 2
1 + 2 = 3
```

---

# 13. Фибоначчи с помощью рекурсии

Рекурсивное решение:

```python
def get_fibonacci(number):
    """Возвращает N-й элемент последовательности Фибоначчи."""

    if number == 1:
        return 0

    if number == 2:
        return 1

    return (
        get_fibonacci(number - 2)
        + get_fibonacci(number - 1)
    )
```

Пример использования:

```python
print(get_fibonacci(5))
print(get_fibonacci(7))
```

Результат:

```text
3
8
```

В функции присутствуют два базовых случая:

```python
if number == 1:
    return 0
```

```python
if number == 2:
    return 1
```

Если аргумент больше `2`, функция вызывает себя два раза с уменьшенными аргументами:

```python
get_fibonacci(number - 2)
```

и:

```python
get_fibonacci(number - 1)
```

Результаты этих вызовов складываются.

---

## 13.1. Разбор get_fibonacci(5)

Вызов:

```python
get_fibonacci(5)
```

превращается в:

```text
get_fibonacci(3) + get_fibonacci(4)
```

Левая ветка:

```text
get_fibonacci(3)
= get_fibonacci(1) + get_fibonacci(2)
= 0 + 1
= 1
```

Правая ветка:

```text
get_fibonacci(4)
= get_fibonacci(2) + get_fibonacci(3)
= 1 + get_fibonacci(3)
= 1 + 1
= 2
```

Финальный результат:

```text
get_fibonacci(5)
= get_fibonacci(3) + get_fibonacci(4)
= 1 + 2
= 3
```

Дерево вызовов можно представить так:

```text
get_fibonacci(5)
├── get_fibonacci(3)
│   ├── get_fibonacci(1) → 0
│   └── get_fibonacci(2) → 1
│
└── get_fibonacci(4)
    ├── get_fibonacci(2) → 1
    └── get_fibonacci(3)
        ├── get_fibonacci(1) → 0
        └── get_fibonacci(2) → 1
```

Каждая ветка рекурсии продолжает разделяться, пока не достигнет одного из базовых случаев.

---

# 14. Бесконечная рекурсия

Если в функции отсутствует базовый случай, рекурсия не сможет нормально завершиться.

Неправильный пример:

```python
def get_fibonacci(number):
    return (
        get_fibonacci(number - 2)
        + get_fibonacci(number - 1)
    )
```

При вызове:

```python
get_fibonacci(100)
```

функция будет продолжать создавать новые вызовы.

В результате Python остановит программу и выбросит исключение:

```text
RecursionError: maximum recursion depth exceeded
```

Python ограничивает максимальную глубину рекурсии, чтобы бесконечные рекурсивные вызовы не заняли всю доступную память.

---

## 14.1. Неизменяемый аргумент

Даже если базовый случай существует, функция должна приближаться к нему.

Неправильный пример:

```python
def countdown(number):
    if number == 0:
        return

    print(number)
    countdown(number)
```

Аргумент `number` не изменяется, поэтому функция никогда не достигнет нуля.

Правильный вариант:

```python
def countdown(number):
    if number == 0:
        return

    print(number)
    countdown(number - 1)
```

Теперь каждый вызов приближает выполнение к базовому случаю:

```text
3 → 2 → 1 → 0
```

---

# 15. Стек вызовов

Каждый вызов функции помещается в специальную область памяти — **стек вызовов**.

Стек работает по принципу:

```text
Last In, First Out
```

или:

```text
последним добавлен — первым завершён
```

При рекурсии каждый новый вызов функции добавляется в стек.

Например:

```python
def countdown(number):
    if number == 0:
        return

    countdown(number - 1)
    print(number)


countdown(3)
```

Сначала в стек добавляются вызовы:

```text
countdown(3)
countdown(2)
countdown(1)
countdown(0)
```

Когда `countdown(0)` завершается, стек начинает освобождаться в обратном порядке:

```text
countdown(1)
countdown(2)
countdown(3)
```

Поэтому результат будет таким:

```text
1
2
3
```

Каждый рекурсивный вызов хранит:

- переданные аргументы;
- локальные переменные;
- место, в которое нужно вернуться;
- промежуточные результаты.

Поэтому глубокая рекурсия может использовать много памяти.

---

# 16. Недостаток рекурсивного вычисления Фибоначчи

Рекурсивная реализация Фибоначчи выглядит компактно:

```python
def get_fibonacci(number):
    if number == 1:
        return 0

    if number == 2:
        return 1

    return (
        get_fibonacci(number - 2)
        + get_fibonacci(number - 1)
    )
```

Но она выполняет много повторных вычислений.

При вычислении:

```python
get_fibonacci(5)
```

вызов `get_fibonacci(3)` выполняется несколько раз.

Чем больше `number`, тем больше одинаковых вычислений повторяется. Поэтому такая реализация подходит для изучения рекурсии, но плохо подходит для вычисления больших чисел Фибоначчи.

Циклический вариант в этой задаче эффективнее, потому что:

- не создаёт большое количество вызовов функций;
- не вычисляет одни и те же значения повторно;
- использует меньше памяти;
- работает быстрее.

Повторные вычисления можно уменьшить с помощью сохранения ранее рассчитанных результатов — **мемоизации**:

```python
def get_fibonacci(number, cache=None):
    if cache is None:
        cache = {}

    if number in cache:
        return cache[number]

    if number == 1:
        return 0

    if number == 2:
        return 1

    cache[number] = (
        get_fibonacci(number - 2, cache)
        + get_fibonacci(number - 1, cache)
    )

    return cache[number]
```

Здесь словарь `cache` сохраняет уже рассчитанные значения.

---

# 17. Преимущества рекурсии

Рекурсивные функции имеют следующие преимущества:

- могут делать код более коротким и элегантным;
- позволяют разделить сложную задачу на простые подзадачи;
- хорошо подходят для задач с повторяющейся структурой;
- могут быть понятнее сложных вложенных циклов;
- естественно подходят для работы с деревьями и вложенными данными;
- удобны для некоторых математических задач и алгоритмов.

Например, обход вложенного списка удобно реализовать рекурсивно:

```python
def print_nested_items(items):
    for item in items:
        if isinstance(item, list):
            print_nested_items(item)
        else:
            print(item)


nested_items = [
    1,
    [2, 3],
    [4, [5, 6]],
]

print_nested_items(nested_items)
```

Результат:

```text
1
2
3
4
5
6
```

Заранее неизвестно, сколько уровней вложенности находится внутри списка. Рекурсивная функция может обрабатывать каждый новый вложенный список тем же способом.

---

# 18. Недостатки рекурсии

У рекурсии также есть недостатки:

- каждый вызов занимает место в стеке;
- глубокая рекурсия использует много памяти;
- существует ограничение максимальной глубины рекурсии;
- можно получить `RecursionError`;
- выполнение может быть медленнее цикла;
- некоторые рекурсивные алгоритмы повторяют одинаковые вычисления;
- сложное дерево вызовов бывает трудно отлаживать;
- ошибка в базовом случае может привести к бесконечной рекурсии.

Главный недостаток рекурсии — большое использование памяти, потому что каждый вызов добавляется в стек.

---

# 19. Когда использовать рекурсию

Рекурсию стоит рассматривать, если:

- задача естественно состоит из уменьшенных версий самой себя;
- необходимо обрабатывать данные с неизвестной глубиной вложенности;
- выполняется обход дерева;
- рекурсивное решение заметно понятнее циклического;
- глубина рекурсии ограничена и заранее известна.

Цикл обычно лучше использовать, если:

- задача является обычным последовательным повторением;
- количество итераций легко определить;
- важна производительность;
- возможна большая глубина вызовов;
- рекурсивная версия выполняет много повторных вычислений.

---

# 20. Итог по рекурсии

**Рекурсия** — это процесс, при котором функция вызывает саму себя.

Для правильной рекурсивной функции обязательны две части:

1. **Базовый случай**, который останавливает рекурсию.
2. **Рекурсивный случай**, который вызывает функцию с изменённым аргументом и приближает её к базовому случаю.

Главная схема:

```python
def recursive_function(argument):
    if base_condition:
        return base_result

    return recursive_function(modified_argument)
```

Основные правила:

- всегда определять условие остановки;
- изменять аргумент при каждом вызове;
- проверять, что функция действительно приближается к базовому случаю;
- учитывать использование стека и памяти;
- не использовать рекурсию только ради рекурсии;
- сравнивать рекурсивное решение с циклическим.

Рекурсивные функции могут сделать решение коротким и понятным, особенно при работе с деревьями, вложенными структурами и математическими алгоритмами. Однако для простых повторений цикл часто будет быстрее, экономнее и понятнее.
