# Аргументы функций (Function Arguments)

## Что такое аргументы функции?

**Аргументы** — это значения, которые передаются функции при её вызове. Они записываются внутри круглых скобок после имени функции и разделяются запятыми.

Функция может принимать:

- один аргумент;
- несколько аргументов;
- не принимать аргументы вовсе.

Количество аргументов зависит только от задачи, которую должна решать функция.

Например:

```python
def sum_numbers(a, b):
    print(f"{a} + {b} = {a + b}")
```

Здесь функция принимает два аргумента:

- `a`
- `b`

---

# Способы передачи аргументов

В Python существует несколько способов передачи аргументов в функцию.

Основные из них:

- позиционные (Positional Arguments);
- именованные (Keyword Arguments);
- смешанные (Mixed Arguments).

---

# Позиционные аргументы (Positional Arguments)

При использовании позиционных аргументов **важен порядок**, в котором значения передаются функции.

Первый аргумент попадет в первый параметр, второй — во второй и так далее.

Например:

```python
def subtract(minuend, subtrahend):
    print(f"{minuend} - {subtrahend} = {minuend - subtrahend}")
```

Вызов функции:

```python
subtract(3, 1)
```

Результат:

```text
3 - 1 = 2
```

Если поменять аргументы местами:

```python
subtract(1, 3)
```

получим:

```text
1 - 3 = -2
```

### Почему так произошло?

Python связывает значения с параметрами **по их позиции**.

То есть:

```python
subtract(3, 1)
```

равносильно

```python
minuend = 3
subtrahend = 1
```

А

```python
subtract(1, 3)
```

становится

```python
minuend = 1
subtrahend = 3
```

Из-за этого результат вычислений меняется.

---

# Именованные аргументы (Keyword Arguments)

При использовании именованных аргументов порядок передачи уже **не имеет значения**.

Главное — явно указать, какому параметру принадлежит каждое значение.

Например:

```python
def subtract(minuend, subtrahend):
    print(f"{minuend} - {subtrahend} = {minuend - subtrahend}")
```

Вызов:

```python
subtract(minuend=3, subtrahend=1)
```

или

```python
subtract(subtrahend=1, minuend=3)
```

В обоих случаях результат будет одинаковым:

```text
3 - 1 = 2
```

### Преимущества именованных аргументов

Использование именованных аргументов делает код:

- более понятным;
- более читаемым;
- менее зависимым от порядка передачи значений.

Особенно это полезно, если функция принимает большое количество параметров.

---

# Смешанные аргументы (Mixed Arguments)

Python позволяет одновременно использовать позиционные и именованные аргументы.

Например:

```python
def calculate_value(minuend, subtrahend, degree):
    value = (minuend - subtrahend) ** degree
    print(value)
```

Вызов:

```python
calculate_value(5, degree=2, subtrahend=1)
```

Результат:

```text
16
```

### Главное правило

**Сначала всегда идут позиционные аргументы, затем именованные.**

Правильно:

```python
calculate_value(5, subtrahend=1, degree=2)
```

Неправильно:

```python
calculate_value(subtrahend=1, 5, degree=2)
```

Во втором случае Python выдаст ошибку.

---

# Обязательные аргументы (Required Arguments)

Некоторые параметры функции являются обязательными.

Это означает, что при вызове функции пользователь обязан передать для них значения.

Например:

```python
def sum_numbers(a, b):
    print(a + b)
```

Оба аргумента обязательны.

Правильный вызов:

```python
sum_numbers(2, 3)
```

Если передать только один аргумент:

```python
sum_numbers(2)
```

Python выдаст ошибку:

```text
TypeError:
missing 1 required positional argument: 'b'
```

Потому что функция ожидала два значения, а получила только одно.

---

# Необязательные аргументы (Optional Arguments)

Аргумент можно сделать необязательным, если задать ему **значение по умолчанию**.

Например:

```python
def sum_numbers(a, b=1):
    print(a + b)
```

Теперь:

```python
sum_numbers(2, 3)
```

выведет

```text
5
```

А вызов

```python
sum_numbers(3)
```

использует значение по умолчанию:

```text
4
```

Потому что Python автоматически подставит:

```python
b = 1
```

---

# Правило порядка обязательных и необязательных аргументов

При объявлении функции сначала должны идти **обязательные параметры**, а затем параметры со значениями по умолчанию.

Правильно:

```python
def greet(name, age=18):
    ...
```

Неправильно:

```python
def greet(age=18, name):
    ...
```

Такой код вызовет ошибку синтаксиса.

---

# Когда использовать значения по умолчанию?

Значения по умолчанию удобно использовать, когда в большинстве случаев параметр имеет одно и то же значение.

Например:

```python
def greet(name, language="ru"):
    ...
```

Если язык не указан, функция автоматически будет использовать `"ru"`.

Это делает вызов функции проще и избавляет от необходимости каждый раз передавать одинаковые значения.

---

# Главное запомнить

- Аргументы передаются функции при её вызове.
- Позиционные аргументы зависят от порядка передачи.
- Именованные аргументы связываются по имени параметра.
- Можно использовать одновременно позиционные и именованные аргументы.
- Позиционные аргументы всегда должны идти раньше именованных.
- Обязательные аргументы необходимо передавать при каждом вызове функции.
- Необязательные аргументы имеют значения по умолчанию и могут быть пропущены.
- При объявлении функции сначала идут обязательные параметры, затем параметры со значениями по умолчанию.

# Упаковка и распаковка аргументов

Иногда заранее неизвестно, сколько аргументов будет передано в функцию.

В таких случаях Python позволяет **упаковывать** аргументы в специальные параметры:

- `*args` — для позиционных аргументов;
- `**kwargs` — для именованных аргументов.

---

# *args — упаковка позиционных аргументов

Если перед параметром поставить одну звездочку `*`, то все дополнительные позиционные аргументы будут автоматически собраны в **кортеж**.

Например:

```python
def show_arguments(*args):
    print(args)
```

Вызов:

```python
show_arguments(1, "name", 3.14)
```

Результат:

```text
(1, 'name', 3.14)
```

Тип данных:

```python
type(args)
```

вернет

```python
tuple
```

---

# **kwargs — упаковка именованных аргументов

Если перед параметром поставить две звездочки `**`, то все именованные аргументы будут собраны в **словарь**.

Например:

```python
def show_arguments(**kwargs):
    print(kwargs)
```

Вызов:

```python
show_arguments(name="Roman", age=29)
```

Результат:

```python
{
    "name": "Roman",
    "age": 29
}
```

Тип данных:

```python
type(kwargs)
```

вернет

```python
dict
```

---

# Одновременное использование *args и **kwargs

Обе конструкции можно использовать вместе.

```python
def show_arguments(*args, **kwargs):
    print(args)
    print(kwargs)
```

Вызов:

```python
show_arguments(
    1,
    "name",
    arg1=[1, 2, 3],
    arg2="value"
)
```

Результат:

```text
(1, 'name')

{
    'arg1': [1, 2, 3],
    'arg2': 'value'
}
```

---

# Работа с args и kwargs

После упаковки они становятся обычными объектами Python.

С ними можно работать так же, как с кортежами и словарями.

Например:

```python
def show_arguments(*args, **kwargs):
    print(args[1:])
    print(kwargs["name"])
```

Вызов:

```python
show_arguments(
    1,
    "Python",
    "Functions",
    name="Roman"
)
```

Результат:

```text
('Python', 'Functions')

Roman
```

---

# Распаковка аргументов

Звездочки используются не только при объявлении функции, но и при её вызове.

---

## Распаковка списка или кортежа

Пусть имеется функция:

```python
def show(a, b, c):
    print(a, b, c)
```

Есть список:

```python
values = [1, 2, 3]
```

Можно передать элементы списка по отдельности:

```python
show(*values)
```

Python автоматически выполнит:

```python
show(1, 2, 3)
```

---

## Распаковка словаря

Пусть есть функция:

```python
def person(name, age):
    print(name, age)
```

Словарь:

```python
data = {
    "name": "Roman",
    "age": 29
}
```

Вызов:

```python
person(**data)
```

равносилен

```python
person(name="Roman", age=29)
```

---

# Когда использовать распаковку?

Она полезна, когда:

- данные уже находятся в списке;
- данные уже находятся в словаре;
- нужно передать большое количество параметров;
- параметры получены из другой функции.

---

# Позиционные-only параметры (/)

Начиная с Python 3.8 можно явно указать, что некоторые параметры разрешено передавать **только позиционно**.

Для этого используется символ `/`.

Например:

```python
def func(a, b, /):
    ...
```

Теперь допустимо:

```python
func(1, 2)
```

Но нельзя:

```python
func(a=1, b=2)
```

Python выдаст ошибку.

---

# Keyword-only параметры (*)

Символ `*` позволяет сделать параметры доступными **только по имени**.

Например:

```python
def func(a, *, language):
    ...
```

Теперь правильно:

```python
func(1, language="ru")
```

Нельзя:

```python
func(1, "ru")
```

Такой вызов завершится ошибкой.

---

# Виды параметров функции

В Python можно встретить следующие типы параметров:

- обычные позиционные;
- только позиционные (`/`);
- позиционные со значением по умолчанию;
- обычные именованные;
- только именованные (`*`);
- именованные со значением по умолчанию;
- `*args`;
- `**kwargs`.

---

# Передача аргументов в Python

Во многих языках программирования говорят о передаче:

- по значению (by value);
- по ссылке (by reference).

В Python всё немного сложнее.

На практике поведение зависит от типа объекта.

---

# Неизменяемые объекты (Immutable)

К неизменяемым относятся:

- `int`;
- `float`;
- `str`;
- `bool`;
- `tuple`.

Пример:

```python
def multiply(text, number):
    text = text * number
    print(text)
```

Вызов:

```python
text = "Hello"

multiply(text, 3)

print(text)
```

Результат:

```text
HelloHelloHello

Hello
```

Почему?

Строки являются неизменяемыми.

Внутри функции создается новый объект строки, а исходная строка остается без изменений.

---

# Изменяемые объекты (Mutable)

К изменяемым относятся:

- `list`;
- `dict`;
- `set`.

Пример:

```python
def add_student(students):
    students["Alan"] = 30
```

Вызов:

```python
students = {
    "Tom": 28,
    "John": 25
}

add_student(students)

print(students)
```

Результат:

```python
{
    "Tom": 28,
    "John": 25,
    "Alan": 30
}
```

Изменения произошли и внутри функции, и снаружи.

Это связано с тем, что изменяемые объекты можно менять "на месте".

---

# Осторожно со значениями по умолчанию

Одна из самых распространенных ошибок новичков — использовать изменяемые объекты как значения по умолчанию.

Плохой пример:

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

Вызов:

```python
print(add_item(1))
print(add_item(2))
```

Результат:

```text
[1]

[1, 2]
```

Хотя кажется, что каждый раз должен создаваться новый список.

---

# Почему так происходит?

Значения по умолчанию создаются **один раз** — в момент объявления функции.

Поэтому список `items` используется повторно при каждом вызове функции.

---

# Правильный способ

Вместо изменяемого объекта используют `None`.

```python
def add_item(item, items=None):

    if items is None:
        items = []

    items.append(item)

    return items
```

Теперь каждый вызов функции будет получать новый список.

---

# Главное запомнить

- `*args` собирает дополнительные позиционные аргументы в кортеж.
- `**kwargs` собирает именованные аргументы в словарь.
- `*` и `**` используются как для упаковки, так и для распаковки аргументов.
- Символ `/` делает параметры только позиционными.
- Символ `*` делает параметры только именованными.
- Неизменяемые объекты не изменяются внутри функции.
- Изменяемые объекты могут изменяться внутри функции.
- Не используйте изменяемые объекты (`[]`, `{}`, `set()`) как значения по умолчанию.
- Вместо этого используйте `None` и создавайте новый объект внутри функции.
