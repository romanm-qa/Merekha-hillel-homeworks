# Функции (Functions)

## Что такое функция?

**Функция** — это именованный блок кода, который выполняет определенную задачу. Она может принимать входные данные (аргументы), выполнять какие-либо действия и при необходимости возвращать результат.

Главная идея использования функций — **не писать один и тот же код несколько раз**. Вместо копирования кода достаточно один раз создать функцию и затем вызывать ее в нужных местах программы.

---

## Зачем нужны функции?

Использование функций позволяет:

- избежать дублирования кода;
- сделать программу более понятной;
- упростить поддержку проекта;
- изменять логику только в одном месте;
- повторно использовать уже написанный код.

Например, если вычисление понадобится изменить, достаточно изменить код внутри одной функции, а не искать одинаковые участки по всей программе.

---

# Общий шаблон функции

В Python функция обычно выглядит следующим образом:

```python
def function_name(arg1, arg2, ..., argN):
    # тело функции
```

где:

- `def` — ключевое слово для создания функции;
- `function_name` — имя функции;
- `arg1, arg2...` — параметры (необязательно);
- после заголовка обязательно ставится двоеточие `:`;
- тело функции записывается с отступом.

---

## Пример функции с возвратом значения

```python
def power(num_1, num_2):
    result = num_1 ** num_2
    return result
```

В данном примере:

- функция принимает два числа;
- вычисляет степень;
- возвращает результат при помощи `return`.

---

## Пример функции без `return`

Не каждая функция обязана что-либо возвращать.

Иногда функция просто выполняет действие.

```python
def welcome(name):
    print(f"Hello, {name}!")
```

Такая функция ничего не возвращает, а только выводит текст на экран.

Если явно не написать `return`, Python автоматически вернет специальное значение `None`.

---

# Как создается функция

Когда интерпретатор встречает конструкцию

```python
def greet():
    print("Hello")
```

он:

1. создает объект функции;
2. сохраняет его в памяти;
3. связывает его с именем `greet`.

Важно понимать:

Пока интерпретатор не дошел до строки с `def`, такой функции еще не существует.

---

# Структура функции

Обычно функция состоит из следующих частей:

```python
def function_name(arguments):
    """Документация (необязательно)"""

    # тело функции

    return result
```

Возможные элементы:

- имя функции;
- параметры;
- docstring (описание функции);
- тело функции;
- `return`.

---

# Обязательные части функции

Минимально функция должна содержать:

- ключевое слово `def`;
- имя функции;
- тело функции (хотя бы одну инструкцию).

Например:

```python
def hello():
    print("Hello")
```

---

## Пустая функция

Если реализация еще не готова, используется ключевое слово `pass`.

```python
def future_function():
    pass
```

Без `pass` Python выдаст ошибку.

---

# Оператор return

`return` завершает выполнение функции и возвращает результат вызывающему коду.

Например:

```python
def square(number):
    return number ** 2
```

После выполнения `return` дальнейший код внутри функции уже не выполняется.

---

## Можно ли не использовать return?

Да.

Если `return` отсутствует, функция автоматически возвращает:

```python
None
```

---

## Функция может вернуть несколько значений

Python позволяет вернуть сразу несколько значений.

На самом деле они будут упакованы в кортеж.

```python
def person():
    return "Roman", 29
```

---

# Вызов функции

После создания функцию можно вызвать по имени.

```python
def greet():
    print("Hello")

greet()
```

При каждом вызове тело функции выполняется заново.

---

# Имена функций

При выборе имени рекомендуется соблюдать несколько правил.

Хорошее имя:

- отражает назначение функции;
- начинается с буквы;
- записывается в стиле `snake_case`.

Например:

```python
calculate_salary()
send_email()
find_user()
```

Не рекомендуется:

- использовать ключевые слова Python;
- использовать имена встроенных функций (`list`, `sum`, `print` и т.д.);
- давать непонятные названия.

Плохие примеры:

```python
def list():
    ...

def sum():
    ...
```

Это может привести к трудноуловимым ошибкам.

---

# Функции — объекты первого класса (First-Class Functions)

В Python функции являются обычными объектами.

Это означает, что с ними можно работать так же, как и с числами, строками или списками.

Функции можно:

- сохранить в переменной;
- передать другой функции;
- сохранить в коллекции;
- вернуть из функции.

Именно поэтому говорят, что функции являются **объектами первого класса**.

---

## 1. Сохранение функции в переменную

Функцию можно присвоить другой переменной.

```python
def square(x):
    return x ** 2

my_func = square

print(my_func(7))
```

Функция не копируется.

`my_func` становится еще одним именем для той же самой функции.

---

## 2. Передача функции как аргумента

Функции можно передавать другим функциям.

```python
def square(x):
    return x ** 2


def apply(func, value):
    return func(value)


print(apply(square, 5))
```

Это широко используется в:

- `map()`;
- `filter()`;
- `sorted()`;
- декораторах.

---

## 3. Хранение функций в коллекциях

Функции можно помещать в словари, списки и другие структуры данных.

```python
def square(x):
    return x ** 2

def cube(x):
    return x ** 3


operations = {
    "square": square,
    "cube": cube
}

print(operations["square"](6))
```

Подобный подход часто применяется вместо длинных конструкций `if...elif`.

---

## 4. Возврат функции из другой функции

Функция может вернуть другую функцию.

```python
def get_operation():
    return abs

operation = get_operation()

print(operation(-10))
```

Эта возможность активно используется при создании декораторов.

---

Большинство встроенных функций мы будем подробно изучать по мере прохождения курса.

---

# Функция all()

```python
all(iterable)
```

Возвращает:

- `True`, если **все** элементы являются истинными;
- `False`, если найден хотя бы один ложный элемент.

Пример:

```python
all([1, True, "Python"])
```

Результат:

```text
True
```

Пример:

```python
all([1, "", 3])
```

Результат:

```text
False
```

Пустая коллекция считается истинной:

```python
all([])
```

вернет

```text
True
```

---

# Функция any()

```python
any(iterable)
```

Возвращает:

- `True`, если найден хотя бы один истинный элемент;
- `False`, если все элементы ложные.

Например:

```python
any([0, "", None, 10])
```

Результат:

```text
True
```

А здесь:

```python
any([0, "", None])
```

Результат:

```text
False
```
