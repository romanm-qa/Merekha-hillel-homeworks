# Interview Questions: Strings (`str`)

## Основы

### 1. Что такое строка в Python?

Строка — объект типа `str`: неизменяемая упорядоченная последовательность символов Unicode. Она поддерживает `len()`, перебор, `in`, индексацию и срезы.

### 2. Есть ли отдельный тип для одного символа?

Нет. Типа `char` в Python нет. Один символ — это строка длиной `1`.

```python
letter = "A"
print(type(letter))  # <class 'str'>
```

### 3. Что означает неизменяемость строки?

Содержимое созданного строкового объекта изменить нельзя. Методы, преобразующие строку, возвращают результат; исходная строка остаётся прежней. Не стоит проверять, создался ли при этом новый объект: это не гарантируется для каждого вызова.

```python
text = "Hello"
text[0] = "Y"  # TypeError

new_text = text.replace("H", "Y")
```

### 4. Изменяют ли строковые методы исходную строку?

Нет. Если нужен результат преобразования, его нужно сохранить в переменной или сразу использовать.

```python
text = "hello"
text.upper()
print(text)  # hello

text = text.upper()
print(text)  # HELLO
```

### 5. Что вернёт `input()`?

Всегда строку, даже если пользователь ввёл число. Для получения числа потребуется явное преобразование, например `int(value)`.

## Индексация и срезы

### 6. Как работают положительные и отрицательные индексы?

Положительные идут слева от `0`, отрицательные — справа от `-1`.

```python
text = "Python"
print(text[0])   # P
print(text[-1])  # n
```

### 7. Как работает срез?

Синтаксис: `string[start:stop:step]`. `start` включается, `stop` не включается, стандартный шаг равен `1`.

```python
print("Python"[1:5:2])  # yh
```

### 8. Чем индекс отличается от среза при выходе за границы?

Несуществующий индекс вызывает `IndexError`, а границы среза безопасно ограничиваются длиной строки.

```python
text = "abc"
print(text[10])   # IndexError
print(text[:10])  # abc
```

### 9. Как развернуть строку?

```python
reversed_text = "Python"[::-1]
```

Также можно использовать `"".join(reversed("Python"))`, потому что `reversed()` возвращает итератор, а не строку.

### 10. Что произойдёт при шаге среза `0`?

Возникнет `ValueError`, поскольку двигаться по последовательности с нулевым шагом невозможно.

## Поиск и сравнение

### 11. Как проверить наличие подстроки?

Обычно используют `in`, который возвращает `bool`:

```python
print("thon" in "Python")  # True
```

### 12. Чем `find()` отличается от `index()`?

Оба возвращают индекс первого вхождения. Если совпадения нет, `find()` возвращает `-1`, а `index()` вызывает `ValueError`.

Для простой проверки наличия понятнее использовать `in`.

### 13. Чем `find()` отличается от `rfind()`?

`find()` возвращает индекс первого вхождения, `rfind()` — последнего. Оба возвращают `-1`, если совпадения нет.

### 14. Что возвращает `count()`?

Количество неперекрывающихся вхождений:

```python
print("aaaa".count("aa"))  # 2
```

### 15. Чем `==` отличается от `is`?

`==` сравнивает значения, `is` — идентичность объектов. Содержимое строк сравнивают через `==`.

Результат `is` может зависеть от интернирования строк, поэтому использовать его для сравнения значений нельзя.

### 16. Что такое интернирование строк?

Оптимизация, при которой Python может повторно использовать один объект для некоторых одинаковых строк. Полагаться на неё в логике программы нельзя.

### 17. Как сравниваются строки через `<` и `>`?

Лексикографически: символы последовательно сравниваются по кодовым точкам Unicode. Сравнение чувствительно к регистру.

```python
print("apple" < "banana")  # True
print("Z" < "a")           # True
```

### 18. Как сравнить строки без учёта регистра?

Для Unicode-текста предпочтительно сравнить результаты `casefold()`:

```python
actual.casefold() == expected.casefold()
```

`casefold()` сильнее преобразует регистр, чем `lower()`. Например, `"Straße".casefold() == "STRASSE".casefold()` вернёт `True`, а сравнение после `lower()` — `False`.

## Методы строк

### 19. Чем `split()` отличается от `join()`?

`split()` разбивает строку и возвращает список строк. `join()` объединяет строки из итерируемого объекта.

```python
parts = "Python,Java,Go".split(",")
result = " | ".join(parts)
```

### 20. Чем `split()` без аргумента отличается от `split(" ")`?

`split()` делит по группам любых пробельных символов и игнорирует их по краям. `split(" ")` делит только по обычному пробелу, а повторные пробелы создают пустые элементы.

```python
print(" a   b ".split())    # ['a', 'b']
print("a  b".split(" "))   # ['a', '', 'b']
```

### 21. Почему `join()` вызывается у разделителя?

Именно строка-разделитель определяет, как соединить элементы:

```python
", ".join(["one", "two"])
```

Все объединяемые элементы должны быть строками, иначе возникнет `TypeError`.

### 22. Чем отличаются `strip()`, `lstrip()` и `rstrip()`?

- `strip()` очищает оба края;
- `lstrip()` — левый;
- `rstrip()` — правый.

Без аргумента они удаляют пробельные символы.

### 23. Удаляет ли `strip("abc")` точную подстроку `abc`?

Нет. Метод удаляет с краёв любые символы из переданного набора. Для точного префикса или суффикса используют `removeprefix()` и `removesuffix()`.

### 24. Что делает третий аргумент `replace()`?

Ограничивает количество замен:

```python
print("one one".replace("one", "two", 1))  # two one
```

### 25. Чем `isdigit()`, `isdecimal()` и `isnumeric()` отличаются?

- `isdecimal()` принимает десятичные Unicode-цифры;
- `isdigit()` дополнительно принимает некоторые символы цифр, например надстрочные;
- `isnumeric()` охватывает ещё более широкий набор числовых символов.

`"-123".isdigit()` и `"12.5".isdigit()` вернут `False`. Даже если `"²".isdigit()` вернёт `True`, `int("²")` вызовет `ValueError`: `isdigit()` не проверяет, можно ли преобразовать строку в `int`.

### 26. Что методы проверки вернут для пустой строки?

`"".isalpha()`, `isdigit()`, `isalnum()` и `isspace()` вернут `False`: для положительного результата должен существовать хотя бы один подходящий символ, и **каждый** символ должен отвечать условию. Поэтому `"Python QA".isalnum()` — `False` из-за пробела, а `"Hello World".isspace()` — `False` из-за букв.

## Форматирование и эффективность

### 27. Какие способы форматирования строк существуют?

- конкатенация через `+`;
- `str.format()`;
- f-строки.

В современном коде обычно используют читаемые f-строки:

```python
name = "Roman"
score = 95.5

print(f"{name}: {score:.2f}")
```

### 28. Можно ли выполнять выражения внутри f-строк?

Да:

```python
passed = 8
failed = 2
print(f"Total: {passed + failed}")
```

### 29. Почему множество строк лучше объединять через `join()`, а не `+` в цикле?

Строки неизменяемы, поэтому повторная конкатенация может создавать новые объекты и копировать уже накопленные данные. `join()` обычно эффективнее и понятнее выражает намерение.

### 30. Что такое raw string?

Строка с префиксом `r`, в которой обратные косые черты обычно воспринимаются буквально. Она удобна для regex и Windows-путей.

```python
pattern = r"\d+"
```

Raw string не может заканчиваться нечётным количеством обратных косых черт.

## Задачи «Что выведет код?»

### 31. Что выведет этот код?

```python
text = "automation"
print(text[-4:])
```

Ответ: `tion`.

### 32. Что выведет этот код?

```python
text = "hello"
text.upper()
print(text)
```

Ответ: `hello`. Результат `upper()` не присвоен переменной.

### 33. Что выведет этот код?

```python
print("a,,b".split(","))
```

Ответ: `['a', '', 'b']`. Между двумя разделителями находится пустая строка.

### 34. Что может произойти здесь?

```python
status_code, message = response.split(maxsplit=1)
```

Если после разделения получится меньше двух частей, распаковка вызовет `ValueError`. Например, для `"200"` получится `["200"]`, а для пустой строки — `[]`. Если есть хотя бы две части, всё после первого разделения окажется в `message`: `"200 OK done"` даст `status_code = "200"`, `message = "OK done"`. Благодаря `maxsplit=1` больше двух частей получиться не может.
