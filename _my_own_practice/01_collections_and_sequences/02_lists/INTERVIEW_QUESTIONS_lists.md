# Вопросы для собеседования: списки Python

Для самопроверки сначала ответь на вопрос своими словами, затем прочитай ответ. В мини-собеседовании будем идти по одному вопросу.

## Основы

### 1. Что такое список в Python?

**Ответ:** `list` — упорядоченная изменяемая коллекция. Она допускает повторения, может менять длину и хранить значения разных типов.

### 2. Чем список отличается от строки?

**Ответ:** Оба поддерживают индексы, срезы и перебор. Список изменяемый: можно заменить элемент по индексу и добавить или удалить элементы. Строка неизменяемая.

### 3. Что произойдёт при обращении к несуществующему индексу? А при срезе за границами списка?

**Ответ:** Обращение по индексу вызовет `IndexError`. Срез не вызовет эту ошибку: он вернёт доступные элементы либо пустой список.

### 4. Что означают `start`, `stop`, `step` в `items[start:stop:step]`?

**Ответ:** Это начальный индекс, конечная граница и шаг. `start` включается, `stop` не включается. Отрицательный шаг позволяет идти справа налево.

### 5. Что даёт `items[:]`? Чем это отличается от `other = items`?

**Ответ:** `items[:]` создаёт новый внешний список с теми же элементами. `other = items` создаёт ещё одно имя для того же списка. Срез даёт поверхностную копию.

## Изменение и копирование

### 6. Чем `==` отличается от `is` при сравнении списков?

**Ответ:** `==` сравнивает содержимое, `is` проверяет, являются ли переменные ссылками на один и тот же объект. У копии обычно `copy == original` истинно, а `copy is original` ложно.

### 7. Что такое поверхностная копия и когда это важно?

**Ответ:** Создаётся новый внешний список, но вложенные изменяемые объекты остаются общими. Например, изменение вложенного списка через копию будет видно и через исходный список. `items.copy()` и `items[:]` делают поверхностную копию.

### 8. Какие способы добавить элементы в список ты знаешь? Чем `append()` отличается от `extend()`?

**Ответ:** `append(value)` добавляет один объект, даже если он сам список. `extend(iterable)` добавляет элементы итерируемого объекта по отдельности. `insert(index, value)` вставляет один объект перед указанной позицией.

### 9. Чем отличаются `remove()`, `pop()` и `del`?

**Ответ:** `remove(value)` удаляет первое совпадение **по значению** и возвращает `None`. `pop(index)` удаляет **по индексу** и возвращает удалённый элемент; без индекса берёт последний. `del items[index]` удаляет по индексу или срезу и не является методом, который возвращает значение.

### 10. Когда полезен `pop()` вместо `del`?

**Ответ:** Когда удалённый элемент нужно использовать дальше: `task = tasks.pop(0)`. После `del tasks[0]` значение из списка удалится, но отдельно не сохранится.

### 11. Что возвращают `append()`, `extend()`, `remove()`, `clear()`, `sort()` и `reverse()`?

**Ответ:** Все эти методы меняют исходный список и возвращают `None`. Поэтому `result = items.sort()` запишет в `result` значение `None`, хотя `items` отсортируется.

## Поиск и сортировка

### 12. Чем отличаются `in`, `index()` и `count()`?

**Ответ:** `in` проверяет наличие целого элемента и возвращает `bool`; `index(value)` возвращает индекс первого совпадения или вызывает `ValueError`; `count(value)` возвращает число совпадений, включая `0`.

### 13. Где происходит поиск в `items.index(value, start, stop)` и какой индекс возвращается?

**Ответ:** Поиск ограничен частью от `start` до `stop` без включения `stop`. Результат — позиция в исходном списке, а не в выделенной части.

### 14. Чем отличаются `sort()` и `sorted()`?

**Ответ:** `items.sort()` сортирует сам список и возвращает `None`. `sorted(items)` возвращает новый отсортированный список и не меняет исходную коллекцию. У обоих есть параметры `reverse` и `key`.

### 15. Чем `reverse()` отличается от `sort(reverse=True)`?

**Ответ:** `reverse()` просто меняет порядок элементов на обратный. `sort(reverse=True)` сортирует значения по убыванию. Оба метода меняют список и возвращают `None`.

### 16. Что возвращает `reversed(items)`? Зачем иногда пишут `list(reversed(items))`?

**Ответ:** `reversed(items)` возвращает итератор для прохода с конца и не меняет исходный список. `list(...)` собирает его элементы в новый список. Для цикла `for` собирать список не обязательно.

### 17. Для чего нужен `key` при сортировке?

**Ответ:** `key` задаёт значение, по которому сравнивают элементы. Например, `sorted(words, key=len)` сортирует строки по их длине, возвращая исходные строки в новом порядке.

## Создание нового списка и распаковка

### 18. Как прочитать `[n * 2 for n in numbers if n > 0]`?

**Ответ:** «Для каждого `n` из `numbers`: если `n > 0`, запиши `n * 2` в новый список». `if` после `for` фильтрует элементы, выражение слева задаёт результат.

### 19. В чём разница между `if` после `for` и `if/else` перед `for` в list comprehension?

**Ответ:** `[n for n in numbers if n > 0]` отбрасывает неподходящие элементы. `[n if n > 0 else 0 for n in numbers]` записывает значение для **каждого** элемента, заменяя неподходящие нулём.

### 20. Что происходит при `first, *middle, last = items`?

**Ответ:** Первый и последний элементы попадают в `first` и `last`. Остальные собираются в **новый список** `middle`. Если между ними нет элементов, `middle == []`. Без звёздочки несовпадение числа элементов и переменных вызывает `ValueError`.

### 21. Что означает `_` в `first, _, last = items`?

**Ответ:** Это обычное имя переменной. По соглашению оно сообщает читателю, что полученное значение дальше не нужно. Присваивание всё равно происходит.

## Быстрые задачи на чтение кода

Сначала скажи результат вслух и объясни почему. Затем проверь себя по ответу.

### 22. Какой будет вывод?

```python
a = [1, 2]
b = a
b.append(3)
print(a)
```

**Ответ:** `[1, 2, 3]`: `a` и `b` указывают на один список.

### 23. Какой будет вывод?

```python
a = [[1], [2]]
b = a.copy()
b[0].append(3)
print(a)
```

**Ответ:** `[[1, 3], [2]]`: копия внешнего списка новая, но первый вложенный список общий.

### 24. Какой будет вывод?

```python
numbers = [10, 30, 20]
print(numbers.reverse())
print(numbers)
```

**Ответ:** Сначала `None`, затем `[20, 30, 10]`. Метод возвращает `None`, но меняет исходный список.

### 25. Какой будет вывод?

```python
items = [1, 2, 3, 4]
print(items[1:4:2])
print(items[-1])
```

**Ответ:** `[2, 4]`, затем `4`: срез берёт индексы 1 и 3, а `-1` означает последний элемент.
