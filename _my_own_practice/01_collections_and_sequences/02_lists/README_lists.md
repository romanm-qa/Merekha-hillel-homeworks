# Списки в Python (`list`)

Список хранит элементы **в порядке добавления**. Он изменяемый: можно заменить, добавить или удалить элементы. В одном списке могут лежать значения разных типов.

```python
numbers = [10, 20, 30]
mixed = [1, "Python", True]
empty = []
print(type(numbers))  # <class 'list'>
print(len(numbers))   # 3
```

`len()` — функция, которая возвращает число элементов; это не метод списка.

## Индексы и срезы

Индексы начинаются с нуля. Отрицательные индексы считают с конца:

```python
fruits = ["apple", "banana", "orange", "kiwi"]
print(fruits[0])   # 'apple'
print(fruits[-1])  # 'kiwi'
```

Несуществующий индекс вызывает `IndexError`. Срез записывают как `[start:stop:step]`: `start` включается, `stop` не включается.

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[1:4])  # [20, 30, 40]
print(numbers[::2])  # [10, 30, 50]
print(numbers[::-1]) # [50, 40, 30, 20, 10]
```

Срез создаёт **новый список**. Как и `copy()`, это поверхностная копия: вложенные изменяемые элементы остаются общими с исходным списком.

## Изменение, присваивание и копирование

```python
fruits = ["apple", "banana"]
fruits[1] = "pear"
print(fruits)  # ['apple', 'pear']
```

Присваивание `other = fruits` не копирует список: обе переменные указывают на один объект. `fruits.copy()` и `fruits[:]` создают другой список. Для списка с обычными числами изменение копии не затронет исходный:

```python
original = [1, 2, 3]
copied = original.copy()
copied.append(4)
print(original)            # [1, 2, 3]
print(copied)              # [1, 2, 3, 4]
print(copied is original)  # False
```

При вложенных списках `copy()` копирует внешний список, но не вложенные:

```python
original = [[1], [2]]
copied = original.copy()
copied[0].append(9)
print(original)  # [[1, 9], [2]]
```

Здесь `is` проверяет, один ли это объект; `==` сравнивает содержимое.

## Добавление и удаление

| Операция | Что делает | Возвращает |
| --- | --- | --- |
| `items.append(value)` | Добавляет один объект в конец | `None` |
| `items.extend(iterable)` | Добавляет элементы итерируемого объекта по одному | `None` |
| `items.insert(index, value)` | Вставляет значение перед указанным индексом | `None` |
| `items.remove(value)` | Удаляет первое совпадение по значению | `None` |
| `items.pop()` | Удаляет последний элемент | Удалённый элемент |
| `items.pop(index)` | Удаляет элемент по индексу | Удалённый элемент |
| `items.clear()` | Удаляет все элементы | `None` |
| `del items[index]` | Удаляет по индексу или срезу | Оператор, значения не возвращает |

```python
items = [1, 2]
items.append([3, 4])
print(items)  # [1, 2, [3, 4]]

items = [1, 2]
items.extend([3, 4])
print(items)  # [1, 2, 3, 4]
```

`remove(2)` ищет **значение**, а `pop(2)` и `del items[2]` используют **индекс**. `remove()` вызывает `ValueError`, если значения нет. `pop()` у пустого списка и `pop(index)` с неверным индексом вызывают `IndexError`.

`pop()` полезен, когда удалённый элемент нужен дальше:

```python
tasks = ["написать тест", "проверить отчёт"]
task = tasks.pop(0)
print(task)   # 'написать тест'
print(tasks)  # ['проверить отчёт']
```

## Поиск и подсчёт

```python
fruits = ["apple", "banana", "orange", "banana"]
print("banana" in fruits)       # True: проверяет целый элемент списка
print("kiwi" not in fruits)     # True
print(fruits.index("banana"))  # 1: первое совпадение
print(fruits.index("banana", 2))  # 3: поиск начиная с индекса 2
print(fruits.count("banana"))  # 2
print(fruits.count("kiwi"))    # 0
```

`index()` вызывает `ValueError`, если элемента нет. Форма `index(value, start, stop)` ищет в указанной части списка и возвращает индекс **в исходном списке**; `stop` не включается. `in` возвращает `True` или `False` и не ищет подстроку внутри каждого элемента списка.

## Сортировка и разворот

| Операция | Результат | Меняет исходный список? |
| --- | --- | --- |
| `items.sort()` | Сортирует список; возвращает `None` | Да |
| `sorted(items)` | Новый отсортированный список | Нет |
| `items.reverse()` | Переворачивает текущий порядок; возвращает `None` | Да |
| `reversed(items)` | Итератор для прохода с конца | Нет |
| `items[::-1]` | Новый список в обратном порядке | Нет |

```python
numbers = [10, 30, 20, 40]
result = numbers.reverse()
print(numbers)  # [40, 20, 30, 10]
print(result)   # None
```

`reverse()` **не сортирует**. `sort(reverse=True)` сортирует по убыванию и тоже возвращает `None`. `sorted(numbers, reverse=True)` создаёт новый отсортированный список. Аргумент `key` задаёт правило сортировки, например `sorted(["banana", "kiwi", "apple"], key=len)` выдаст `["kiwi", "apple", "banana"]`.

Чтобы собрать значения `reversed()` в новый список, применяют `list(reversed(numbers))`. Для прохода в цикле `list()` не нужен.

## List comprehension

Краткая запись для создания **нового** списка:

```python
numbers = [1, 2, 3, 4]
squares = [number ** 2 for number in numbers]
evens = [number for number in numbers if number % 2 == 0]

print(squares)  # [1, 4, 9, 16]
print(evens)    # [2, 4]
```

Читайте `[number for number in numbers if ...]` так: «для каждого числа из `numbers`, если условие верно, добавь число в новый список». `if` **после `for`** отфильтровывает элементы. `if/else` **перед `for`** выбирает, что записать для каждого элемента:

```python
labels = ["чётное" if n % 2 == 0 else "нечётное" for n in numbers]
print(labels)  # ['нечётное', 'чётное', 'нечётное', 'чётное']
```

Если выражение трудно прочитать, используйте обычный цикл `for`.

## Распаковка

```python
numbers = [10, 20, 30]
first, second, third = numbers
print(first, second, third)  # 10 20 30

a, b = 5, 17
a, b = b, a                 # обмен значениями
```

Без звёздочки количество переменных должно совпадать с количеством элементов, иначе возникает `ValueError`. Одна переменная со `*` собирает остаток в **список**, иногда пустой:

```python
numbers = [10, 20, 30, 40]
first, *middle, last = numbers
print(middle)  # [20, 30]

first, *middle, last = [10, 20]
print(middle)  # []
```

`first, _, last = [10, 20, 30]`: имя `_` по соглашению означает «значение дальше не понадобится», но присваивание ему всё равно происходит.

## Что держать в голове на собеседовании

- Список упорядочен и изменяем; индекс и срез работают как у строки.
- Срез, `copy()` и `sorted()` дают новый список; `sort()` и `reverse()` меняют исходный.
- `append()` добавляет один объект; `extend()` добавляет элементы по отдельности.
- `remove()` удаляет по значению; `pop()` удаляет по индексу и возвращает элемент; `del` удаляет по индексу или срезу.
- `in`, `index()` и `count()` отвечают на разные вопросы: есть ли значение, где первое совпадение, сколько совпадений.
