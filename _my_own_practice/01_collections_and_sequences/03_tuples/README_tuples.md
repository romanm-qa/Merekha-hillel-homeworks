# Кортежи (`tuple`)

Кортеж — упорядоченная последовательность элементов. Он похож на список: поддерживает индексы, срезы и перебор в цикле. Главное отличие — **после создания нельзя заменить, добавить или удалить элемент кортежа**.

```python
numbers = (10, 20, 30)

print(numbers[0])    # 10
print(numbers[1:])   # (20, 30)
```

В кортеже могут находиться значения разных типов, в том числе другие коллекции.

## Создание кортежа

```python
numbers = (10, 20, 30)
coordinates = 10, 20
empty = ()
also_empty = tuple()
```

В записи `coordinates = 10, 20` скобки опущены, но результат всё равно имеет тип `tuple`. Несколько значений объединяются в кортеж с помощью запятых — это **упаковка**.

Из другой последовательности кортеж можно получить с помощью `tuple()`:

```python
tuple([10, 20])   # (10, 20)
tuple("Hi")       # ('H', 'i')
tuple(range(3))   # (0, 1, 2)
```

### Кортеж из одного элемента

Здесь нужна запятая:

```python
type((5,))   # <class 'tuple'>
type((5))    # <class 'int'>
```

Скобки вокруг `5` сами по себе не создают кортеж.

## Индексы и срезы

Индексы начинаются с `0`. Отрицательные индексы отсчитываются с конца:

```python
fruits = ("apple", "banana", "orange")

fruits[0]    # 'apple'
fruits[-1]   # 'orange'
```

Срез записывается как `[start:stop:step]`. Элемент с индексом `stop` **не включается**:

```python
numbers = (10, 20, 30, 40, 50)

numbers[1:4]    # (20, 30, 40)
numbers[::2]    # (10, 30, 50)
numbers[::-1]   # (50, 40, 30, 20, 10)
```

К элементу вложенного кортежа можно обратиться двумя индексами:

```python
coordinates = ((8, 3), (2, 8))

coordinates[0]     # (8, 3)
coordinates[0][1]  # 3
```

## Методы и встроенные функции

У кортежа есть два метода:

```python
numbers = (10, 20, 10, 30)

numbers.count(10)  # 2 — сколько раз встречается значение
numbers.index(10)  # 0 — индекс первого совпадения
```

`index()` также принимает необязательные границы поиска `start` и `stop`. Если значение не найдено, возникает `ValueError`.

С кортежами работают и встроенные функции Python:

```python
values = (4, 8, 2, 6)

len(values)     # 4
min(values)     # 2
max(values)     # 8
sum(values)     # 20
sorted(values)  # [2, 4, 6, 8]
```

`sorted()` возвращает **список** и не меняет исходный кортеж. `sum()`, `min()` и `max()` требуют элементов, с которыми соответствующая операция допустима.

## Неизменяемость

Заменить элемент кортежа нельзя:

```python
numbers = (10, 20, 30)
numbers[1] = 99  # TypeError
```

При сложении создаётся новый кортеж:

```python
numbers = (10, 20, 30)
extended = numbers + (40,)

print(numbers)   # (10, 20, 30)
print(extended)  # (10, 20, 30, 40)
```

Если внутри кортежа находится **изменяемый объект**, например список, содержимое этого объекта менять можно:

```python
data = ("Roman", ["Python", "SQL"])
data[1].append("Docker")

print(data)  # ('Roman', ['Python', 'SQL', 'Docker'])
```

Сам элемент кортежа при этом не заменяется: кортеж по-прежнему содержит ссылку на тот же список. Запись `data[1] = ["Git"]` вызовет `TypeError`.

По этой же причине **не каждый кортеж подходит в качестве ключа словаря**: кортеж со списком внутри не хешируется.

## Распаковка

Распаковка распределяет элементы по переменным:

```python
user = ("Roman", 29, "QA Engineer")
name, age, profession = user
```

Без звёздочки количество переменных должно совпадать с количеством элементов. Иначе возникнет `ValueError`.

Если часть значений не нужна, часто используют `_`:

```python
coordinates = (10, 20, 30)
x, _, z = coordinates
```

Переменная со звёздочкой собирает оставшиеся значения **в список**:

```python
numbers = (10, 20, 30, 40)
first, *middle, last = numbers

print(first)   # 10
print(middle)  # [20, 30]
print(last)    # 40
```

Можно распаковывать и вложенные данные:

```python
person = ("Roman", (29, "QA Engineer"))
name, (age, profession) = person
```

Запись `a, b = b, a` позволяет обменять значения переменных местами.

## Распаковка в цикле и `zip()`

Если каждый элемент последовательности содержит два значения, их можно распаковывать на каждом шаге цикла:

```python
users = (("Roman", 29), ("Anna", 25))

for name, age in users:
    print(name, age)
```

Если количество элементов в одном из вложенных кортежей не совпадёт с количеством переменных, возникнет `ValueError`. Звёздочка позволяет собрать значения, которые остались:

```python
users = (
    ("Roman", 29, "QA Engineer"),
    ("Anna", 25),
)

for name, *details in users:
    print(name, details)
```

`zip()` соединяет элементы нескольких последовательностей по позициям. Каждую полученную пару удобно распаковать в цикле:

```python
names = ("Roman", "Anna", "Oleg")
ages = (29, 25)

for name, age in zip(names, ages):
    print(name, age)
```

Обычный `zip()` остановится после пары `("Anna", 25)`: для `"Oleg"` нет соответствующего возраста.

## Равенство и идентичность

`==` проверяет равенство значений. `is` проверяет, ссылаются ли переменные на **один и тот же объект**:

```python
x = (10, 20)
y = x

print(x == y)  # True
print(x is y)  # True
```

Для сравнения значений используй `==`. Обычно `is` нужен для проверки на `None`:

```python
value = None
print(value is None)  # True
```

## Когда использовать кортеж

Кортеж удобен, когда набор элементов имеет фиксированную структуру и его не планируется менять: например, координаты `(10, 20)` или запись с именем и возрастом `("Roman", 29)`.

Если элементы нужно добавлять, удалять или заменять, обычно удобнее список.

## Главное запомнить

- Кортеж упорядочен и поддерживает индексы, срезы и цикл `for`.
- Элемент кортежа нельзя заменить после создания.
- Для кортежа из одного элемента нужна запятая: `(5,)`.
- Вложенный список можно менять, хотя заменить его как элемент кортежа нельзя.
- Методы кортежа — `count()` и `index()`.
- Распаковка распределяет значения по переменным; `*` собирает оставшиеся значения в список.
- `zip()` соединяет элементы по позициям и обычно останавливается на кратчайшей последовательности.
