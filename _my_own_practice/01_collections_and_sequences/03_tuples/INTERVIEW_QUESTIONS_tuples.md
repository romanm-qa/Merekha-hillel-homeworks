# Вопросы для собеседования: кортежи в Python

## Основы

### 1. Что такое кортеж?

Кортеж (`tuple`) — упорядоченная последовательность. Его элементы доступны по индексам, но заменить, добавить или удалить элемент после создания нельзя.

### 2. Чем кортеж отличается от списка?

Список изменяемый: можно вызвать `append()` или заменить элемент по индексу. Кортеж неизменяемый, поэтому таких операций у него нет. Оба типа поддерживают индексы, срезы и цикл `for`.

### 3. Как создать пустой кортеж и кортеж из одного элемента?

Пустой: `()` или `tuple()`. Один элемент: `(5,)` или `5,`. Запятая обязательна: `(5)` — обычное число в скобках.

### 4. Обязательны ли круглые скобки при создании кортежа?

Нет. `point = 10, 20` создаст кортеж `(10, 20)`. Скобки помогают читать код и бывают необходимы в определённом синтаксическом контексте.

### 5. Что делает `tuple()`?

Создаёт кортеж из итерируемого объекта: `tuple([1, 2])` даст `(1, 2)`, а `tuple("Hi")` даст `('H', 'i')`. Без аргумента создаёт пустой кортеж.

## Индексы, методы и функции

### 6. Работают ли с кортежами отрицательные индексы и срезы?

Да. Для `values = (10, 20, 30)` выражение `values[-1]` даст `30`, а `values[::-1]` — `(30, 20, 10)`. В срезе `stop` не включается.

### 7. Какие методы есть у кортежа?

`count(value)` считает совпадения, `index(value)` возвращает индекс первого совпадения. Если `index()` ничего не найдёт, возникнет `ValueError`.

### 8. Чем методы кортежа отличаются от `len()`, `sum()` и `sorted()`?

Метод вызывают через точку: `values.count(10)`. Встроенную функцию вызывают отдельно: `len(values)`. `sorted(values)` возвращает список и не меняет кортеж.

### 9. Что вернёт `numbers.index(10, 1)` для `(10, 20, 10)`?

`2`: поиск начинается с индекса `1`, поэтому находится второе число `10`.

## Неизменяемость

### 10. Что произойдёт при `values[0] = 99`?

Возникнет `TypeError`: присваивать новое значение элементу кортежа нельзя.

### 11. Можно ли изменить список внутри кортежа?

Да. Например, после `data = ("Roman", ["Python"])` вызов `data[1].append("SQL")` изменит внутренний список. Сам кортеж по-прежнему содержит ссылку на тот же список. `data[1] = ["SQL"]` вызовет `TypeError`.

### 12. Что происходит при `values + (40,)`?

Создаётся новый кортеж. Исходный `values` не меняется. Запятая в `(40,)` нужна для кортежа из одного элемента.

### 13. Можно ли использовать кортеж как ключ словаря?

Можно, если все его элементы хешируемы: например, `(1, "A")`. Кортеж с вложенным списком, например `([1, 2],)`, не хешируется и не подойдёт в качестве ключа.

## Распаковка и перебор

### 14. Что такое упаковка и распаковка?

Упаковка собирает значения в кортеж: `values = 1, 2`. Распаковка распределяет элементы по переменным: `a, b = values`.

### 15. Что будет, если количество переменных и элементов не совпадёт?

Без `*` возникнет `ValueError`: например, `a, b = (1, 2, 3)`. Переменная со звёздочкой может собрать лишние значения.

### 16. Какой тип получит `middle` в `first, *middle, last = (1, 2, 3, 4)`?

Список `[2, 3]`. При распаковке переменная со звёздочкой всегда собирает значения в список.

### 17. Как распаковать вложенный кортеж?

Например: `name, (age, job) = ("Roman", (29, "QA"))`. Получим имя, возраст и профессию в отдельных переменных.

### 18. Как работает распаковка в цикле?

При `for name, age in (("Roman", 29), ("Anna", 25)):` каждый вложенный кортеж распаковывается на очередной итерации. Если число значений не совпадёт с числом переменных, возникнет `ValueError`.

### 19. Что делает `zip()` и что будет при разной длине последовательностей?

`zip(names, ages)` объединяет элементы по позициям в пары, которые можно распаковать через `for name, age in zip(names, ages)`. Обычный `zip()` прекращает работу, когда закончится кратчайшая последовательность.

### 20. Чем отличаются `==` и `is` для кортежей?

`==` сравнивает значения элементов. `is` проверяет, ссылаются ли две переменные на один объект. Для сравнения содержимого используют `==`; результат `is` для отдельно записанных одинаковых литералов не следует считать гарантированным.
