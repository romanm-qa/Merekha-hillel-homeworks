# Множества — set и frozenset

## 1. Основные свойства set

**`set` — изменяемая коллекция уникальных хешируемых элементов.**

- Повторы не сохраняются.
- Порядок элементов не гарантирован, в том числе порядок добавления.
- Индексов и срезов нет.
- Можно добавлять и удалять элементы: `set` мутабельный.
- Можно перебирать элементы циклом `for`: `set` итерируемый.
- Сам `set` не хешируется, поэтому не может быть элементом другого `set`.

```python
numbers = {10, 20, 30, 20, 10}

print(f"Исходное множество: {numbers!r}")
print(f"len(numbers) -> {len(numbers)!r}")  # 3
```

В примерах ниже порядок записи элементов в результате условный. Важны сами элементы, а не их позиции.

### Создание

```python
numbers = {10, 20, 30}
empty_set = set()
empty_dict = {}  # Пустой словарь.

fruits = ["apple", "banana", "apple", "orange"]
print(f"Исходный список: {fruits!r}")
print(f"set(fruits) -> {set(fruits)!r}")
# {'apple', 'banana', 'orange'}
```

`set(iterable)` перебирает источник и добавляет его элементы в новое множество. Источник должен быть итерируемым, а его элементы — хешируемыми. Без аргумента `set()` создаёт пустое множество.

```python
set("hello")     # {'h', 'e', 'l', 'o'}
set((1, 2, 2))   # {1, 2}
set([1, 2, 2])   # {1, 2}
```

Число не итерируемо, поэтому `set(123)` вызывает `TypeError`. Но число можно хранить как элемент: `{123}`.

### Перебор, индексы и срезы

```python
numbers = {10, 20, 30}

for number in numbers:
    print(f"Элемент: {number!r}")

try:
    print(numbers[0])
except TypeError as error:
    print(f"{type(error).__name__}: {error}")
```

Обращение `numbers[0]` и срез `numbers[:2]` не поддерживаются.

### Сортировка и встроенные функции

У `set` нет метода `.sort()`. **`sorted()` возвращает новый отсортированный список**, а исходное множество не меняется.

```python
numbers = {30, 10, 20}

print(f"Исходное множество: {numbers!r}")
print(f"sorted(numbers) -> {sorted(numbers)!r}")  # [10, 20, 30]
print(f"sorted(numbers, reverse=True) -> {sorted(numbers, reverse=True)!r}")
# [30, 20, 10]
print(f"Множество после сортировки: {numbers!r}")
```

Если преобразовать отсортированный список обратно в `set`, порядок снова не будет гарантирован. Для сортировки элементы должны быть сравнимы между собой либо нужно задать подходящий `key`.

| Функция | Для `numbers = {10, 20, 30}` | Результат |
| --- | --- | --- |
| `len()` | `len(numbers)` | `3` |
| `sum()` | `sum(numbers)` | `60` |
| `min()` | `min(numbers)` | `10` |
| `max()` | `max(numbers)` | `30` |
| `sorted()` | `sorted(numbers)` | `[10, 20, 30]` |

`sum()` подходит для чисел. `min()` и `max()` требуют сравнимых элементов; для пустого множества без `default` они вызывают `ValueError`.

## 2. Добавление и удаление элементов

Эти методы изменяют существующее множество.

| Метод | Что делает | Возвращает | Если элемента нет |
| --- | --- | --- | --- |
| `add(value)` | Добавляет один хешируемый элемент | `None` | Добавляет его |
| `update(iterable)` | Добавляет элементы источника | `None` | Добавляет их |
| `remove(value)` | Удаляет указанный элемент | `None` | `KeyError` |
| `discard(value)` | Удаляет указанный элемент, если он есть | `None` | Ничего не делает |
| `pop()` | Удаляет произвольный элемент | Удалённый элемент | Для пустого множества — `KeyError` |
| `clear()` | Удаляет все элементы | `None` | Пустое множество остаётся пустым |

### add() и update()

```python
numbers = {10, 20, 30}

print(f"Исходное множество: {numbers!r}")
numbers.add(40)
print(f"После add(40): {numbers!r}")  # {10, 20, 30, 40}
numbers.add(20)
print(f"После add(20): {numbers!r}")  # Повтор не добавляется.
numbers.update([30, 50, 60])
print(f"После update([30, 50, 60]): {numbers!r}")
# {10, 20, 30, 40, 50, 60}
```

**`add()` добавляет объект целиком, `update()` перебирает переданный объект.**

```python
words = set()
words.add("cat")     # {'cat'}
words.update("dog")  # {'cat', 'd', 'o', 'g'}
```

`update()` может принимать несколько источников: `numbers.update([70, 80], (90, 100))`.

### remove() и discard()

```python
numbers = {10, 20, 30}

print(f"Исходное множество: {numbers!r}")
numbers.remove(20)
print(f"После remove(20): {numbers!r}")
numbers.discard(99)  # Ошибки нет.

try:
    numbers.remove(99)
except KeyError as error:
    print(f"{type(error).__name__}: {error}")
```

### pop() и clear()

```python
numbers = {10, 20, 30}

print(f"Исходное множество: {numbers!r}")
removed = numbers.pop()
print(f"Удалённый элемент: {removed!r}")
print(f"После pop(): {numbers!r}")
numbers.clear()
print(f"После clear(): {numbers!r}")  # set()
```

`pop()` удаляет **произвольный**, а не гарантированно первый, последний или случайный элемент. Метод не принимает индекс.

Не присваивай результат `add()` или `update()` обратно переменной множества: они возвращают `None`.

## 3. Операции над множествами

Для примеров: `left = {1, 2, 3}`, `right = {3, 4, 5}`.

| Операция | Метод | Оператор | Результат |
| --- | --- | --- | --- |
| Объединение: все элементы без повторов | `left.union(right)` | `left \| right` | `{1, 2, 3, 4, 5}` |
| Пересечение: общие элементы | `left.intersection(right)` | `left & right` | `{3}` |
| Разность: элементы слева, которых нет справа | `left.difference(right)` | `left - right` | `{1, 2}` |
| Симметрическая разность: элементы только одного из множеств | `left.symmetric_difference(right)` | `left ^ right` | `{1, 2, 4, 5}` |

Эти операции **создают новое множество**, исходные множества не меняются.

```python
left = {1, 2, 3}
right = {3, 4, 5}

print(f"Первое множество: {left!r}")
print(f"Второе множество: {right!r}")
print(f"left - right -> {left - right!r}")  # {1, 2}
print(f"right - left -> {right - left!r}")  # {4, 5}
print(f"left ^ right -> {left ^ right!r}")  # {1, 2, 4, 5}
```

В разности порядок множеств важен. Симметрическая разность объединяет обе разности: `(left - right) | (right - left)`. Общий элемент `3` в неё не входит.

### Методы и операторы

Операторы `|`, `&`, `-`, `^` требуют множества (`set` или `frozenset`). Соответствующие методы принимают и другие итерируемые объекты с хешируемыми элементами.

```python
numbers = {1, 2, 3}
print(f"Исходное множество: {numbers!r}")
print(f"numbers.union([3, 4]) -> {numbers.union([3, 4])!r}")
# {1, 2, 3, 4}

try:
    print(numbers | [3, 4])
except TypeError as error:
    print(f"{type(error).__name__}: {error}")
```

`union()`, `intersection()` и `difference()` принимают несколько источников. `symmetric_difference()` принимает один.

### Операции с изменением исходного set

| Метод | Оператор | Что остаётся в исходном множестве |
| --- | --- | --- |
| `update()` | `\|=` | Все элементы обоих множеств |
| `intersection_update()` | `&=` | Только общие элементы |
| `difference_update()` | `-=` | Элементы исходного множества, которых нет во втором |
| `symmetric_difference_update()` | `^=` | Элементы, которые были только в одном множестве |

Все четыре метода возвращают `None`. Для операторов справа используй `set` или `frozenset`; методы также принимают другие итерируемые источники.

```python
left = {1, 2, 3}
right = {3, 4, 5}

print(f"Первое множество: {left!r}")
print(f"Второе множество: {right!r}")
left.intersection_update(right)
print(f"После intersection_update(right): {left!r}")  # {3}
```

## 4. Проверка наличия и сравнения

### in и not in

Проверяют наличие **отдельного элемента**.

```python
numbers = {10, 20, 30}

print(f"Исходное множество: {numbers!r}")
print(f"20 in numbers -> {20 in numbers!r}")  # True
print(f"40 not in numbers -> {40 not in numbers!r}")  # True
```

### Равенство, подмножества и надмножества

Для примеров: `small = {1, 2}`, `large = {1, 2, 3}`.

| Проверка | Смысл | Результат |
| --- | --- | --- |
| `{1, 2} == {2, 1}` | Одинаковые элементы | `True` |
| `small != large` | Наборы элементов различаются | `True` |
| `small.issubset(large)` или `small <= large` | Все элементы small входят в large | `True` |
| `large.issuperset(small)` или `large >= small` | large содержит все элементы small | `True` |
| `small < large` | Подмножество, но не равное множество | `True` |
| `large > small` | Надмножество, но не равное множество | `True` |
| `small <= small` | Равенство допустимо | `True` |
| `small < small` | Строгое сравнение исключает равенство | `False` |

`<` и `>` сравнивают включение элементов, а не просто количество элементов. Например, `{1} < {2, 3}` — `False`: элемента `1` нет справа.

### isdisjoint()

Возвращает `True`, если общих элементов нет.

```python
evens = {2, 4, 6}
odds = {1, 3, 5}

print(f"Первое множество: {evens!r}")
print(f"Второе множество: {odds!r}")
print(f"evens.isdisjoint(odds) -> {evens.isdisjoint(odds)!r}")  # True
```

`issubset()`, `issuperset()` и `isdisjoint()` также принимают другие итерируемые объекты.

## 5. Set comprehensions

Создают новое множество с помощью перебора, преобразования и необязательного условия.

```python
{выражение for элемент in источник if условие}
```

### Преобразование

```python
numbers = [1, 2, 2, 3, 4]
squares = {number ** 2 for number in numbers}

print(f"Исходный список: {numbers!r}")
print(f"Квадраты без повторов: {squares!r}")  # {1, 4, 9, 16}
```

### Фильтрация

```python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = {number for number in numbers if number % 2 == 0}

print(f"Исходный список: {numbers!r}")
print(f"Чётные числа: {even_numbers!r}")  # {2, 4, 6}
```

### Удаление повторов после преобразования

```python
words = ["Cat", "cat", "DOG", "dog"]
lowercase_words = {word.lower() for word in words}

print(f"Исходный список: {words!r}")
print(f"Слова в нижнем регистре: {lowercase_words!r}")  # {'cat', 'dog'}
```

Если нужно только убрать повторы без преобразования и фильтрации, достаточно `set(words)`.

## 6. Хешируемость и frozenset

### Что означает «хешируемый»

Хешируемый объект имеет хеш — целое число, которое не меняется за время жизни объекта. Равные хешируемые объекты должны иметь одинаковый хеш.

Хеш помогает быстро искать элементы. **Это не уникальный идентификатор:** разные объекты могут иметь одинаковый хеш, поэтому при поиске учитывается и равенство.

Для обычных встроенных типов удобно помнить следующую таблицу:

| Тип | Итерируемый? | Хешируемый? | Можно хранить как элемент set? |
| --- | --- | --- | --- |
| `int`, `float`, `bool` | Нет | Да | Да |
| `str` | Да | Да | Да |
| `tuple` | Да | Если все его элементы хешируемые | При этом условии |
| `list` | Да | Нет | Нет |
| `set` | Да | Нет | Нет |
| `dict` | Да, перебираются ключи | Нет | Нет |
| `frozenset` | Да | Да | Да |

**Итерируемость и хешируемость — разные свойства.** Список можно перебрать, но нельзя хранить как элемент множества. Число нельзя перебрать, но можно хранить в множестве.

### Источник элементов и отдельный элемент

```python
set([1, 2, 2])  # Можно: список — источник, числа — элементы.
```

Но `items.add([1, 2])` и `{[1, 2]}` вызывают `TypeError`: здесь сам список должен стать элементом.

```python
items = {10, "apple", (1, 2)}

print(f"Исходное множество: {items!r}")
try:
    items.add([1, 2])
except TypeError as error:
    print(f"{type(error).__name__}: {error}")
```

### Не каждый кортеж хешируется

Неизменяемость сама по себе не гарантирует хешируемость.

```python
valid_tuple = (1, 2, "cat")
invalid_tuple = (1, [2, 3])

print(f"Хешируемый кортеж: {valid_tuple!r}")
print(f"hash(valid_tuple) -> {hash(valid_tuple)!r}")
print(f"Кортеж со списком: {invalid_tuple!r}")
try:
    print(hash(invalid_tuple))
except TypeError as error:
    print(f"{type(error).__name__}: {error}")
```

Кортеж со списком внутри не может быть элементом `set`. Хеши некоторых типов, например строк, могут отличаться между запусками Python; запоминать конкретное число не нужно.

Также `1`, `1.0` и `True` равны и имеют одинаковый хеш, поэтому `len({1, 1.0, True})` равно `1`.

### frozenset — неизменяемое множество

```python
numbers = frozenset([1, 2, 2, 3])

print(f"Исходный frozenset: {numbers!r}")
print(f"2 in numbers -> {2 in numbers!r}")  # True
```

`frozenset` хранит уникальные хешируемые элементы и не гарантирует порядок. Поддерживает перебор, проверки наличия, сравнения и операции, создающие новые множества.

У него нет изменяющих методов: `add()`, `remove()`, `update()`, `clear()` и других. Сам `frozenset` хешируется, поэтому может быть элементом множества:

```python
groups = {frozenset({1, 2}), frozenset({3, 4})}

print(f"Множество групп: {groups!r}")
print(f"frozenset({{1, 2}}) in groups -> {frozenset({1, 2}) in groups!r}")
# True
```

## 7. Копирование множества

Присваивание не создаёт копию. Две переменные могут ссылаться на одно множество.

```python
original = {1, 2, 3}
alias = original
copied = original.copy()

print(f"Исходное множество: {original!r}")
alias.add(4)
print(f"original после alias.add(4): {original!r}")  # {1, 2, 3, 4}
print(f"Независимая копия: {copied!r}")  # {1, 2, 3}
print(f"alias is original -> {alias is original!r}")  # True
print(f"copied is original -> {copied is original!r}")  # False
```

`copy()` создаёт поверхностную копию: новое множество с теми же элементами.

## 8. Когда использовать set

- Удалить повторы, если порядок не важен.
- Многократно проверять наличие значения.
- Найти общие элементы двух коллекций.
- Найти элементы, которые есть только в одной коллекции.
- Сравнить наборы разрешений, тегов, идентификаторов или участников.

Для хешируемых значений проверка через `in` обычно быстрая: в среднем O(1), а у списка — O(n). Это средняя оценка, а не гарантия для каждого случая.

Если нужны индексы, сохранение порядка или повторяющиеся элементы, выбирай другую коллекцию, например список.
