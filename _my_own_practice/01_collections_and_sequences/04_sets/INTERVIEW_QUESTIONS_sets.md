# Множества Python — вопросы для собеседования

Сначала попробуй ответить самостоятельно, затем сверься с ответом. Примеры на вывод разбирай без запуска.

## Основы и создание

### 1. Что такое set?

Изменяемая коллекция уникальных хешируемых элементов. Порядок добавления не гарантируется.

### 2. Как создать пустое множество?

Через `set()`. Запись `{}` создаёт пустой словарь.

### 3. Как создать непустое множество?

```python
numbers = {1, 2, 3}
numbers = set([1, 2, 2, 3])
```

В обоих случаях множество содержит элементы `1`, `2`, `3`.

### 4. Что происходит с повторяющимися элементами?

Они не создают дополнительные элементы множества.

```python
print(len({1, 1, 2, 2, 3}))  # 3
```

### 5. Сохраняет ли set порядок добавления?

Нет. На порядок вывода и перебора нельзя полагаться. Даже если числа выводятся по возрастанию, это не означает, что множество отсортировано.

### 6. Есть ли у множества индексы и срезы?

Нет. Обращение `numbers[0]` вызывает `TypeError`. Для индексов можно создать список, но его порядок будет соответствовать текущему перебору множества.

### 7. Изменяемо ли множество?

Да. Можно добавлять и удалять элементы. При этом сами элементы должны быть хешируемыми.

### 8. Что возвращает len()?

Количество элементов множества.

### 9. Что принимает set()?

Без аргументов создаёт пустое множество. С аргументом принимает итерируемый объект, элементы которого должны быть хешируемыми.

```python
numbers = set([1, 2, 2])
letters = set("hello")
keys = set({"name": "Roman", "age": 25})
```

В последнем случае получаем ключи словаря: `'name'` и `'age'`.

### 10. Почему set([1, 2]) работает, а {[1, 2]} — нет?

В `set([1, 2])` список служит источником: в множество попадают числа. В `{[1, 2]}` сам список пытаются поместить как один элемент. Список не хешируется, поэтому возникает `TypeError`.

### 11. Можно ли вызвать set(123)?

Нет. Число не является итерируемым объектом. Можно написать `{123}` или `set([123])`.

## Добавление и удаление

### 12. Чем add() отличается от update()?

`add()` добавляет один хешируемый объект. `update()` перебирает один или несколько источников и добавляет их элементы.

```python
letters = {"a"}
letters.add("bc")     # Добавляет строку 'bc' целиком
letters.update("de")  # Добавляет отдельные символы 'd' и 'e'
```

### 13. Что произойдёт при добавлении существующего элемента?

Множество не изменится, ошибка не возникнет.

### 14. Что возвращают add() и update()?

`None`. Они изменяют исходное множество.

### 15. Чем remove() отличается от discard()?

Оба удаляют указанный элемент. Если элемента нет, `remove()` вызывает `KeyError`, а `discard()` ничего не делает. Оба возвращают `None` при успешном завершении.

### 16. Что делает pop()?

Удаляет и возвращает произвольный элемент. Нельзя рассчитывать, что это первый, последний или случайно выбранный элемент. Для пустого множества вызывает `KeyError`.

### 17. Можно ли передать элемент в set.pop()?

Нет. `set.pop()` не принимает аргументов. Для удаления конкретного элемента используют `remove()` или `discard()`.

### 18. Что делает clear()?

Удаляет все элементы существующего множества и возвращает `None`.

### 19. Что не так с numbers = numbers.add(4)?

Элемент добавится в исходное множество, но `add()` вернёт `None`. После присваивания переменная `numbers` будет ссылаться на `None`.

## Операции над множествами

Для примеров: `a = {1, 2, 3}`, `b = {3, 4}`.

### 20. Что такое объединение?

Все элементы обоих множеств без повторов: `a | b` или `a.union(b)` → `{1, 2, 3, 4}`.

### 21. Что такое пересечение?

Только общие элементы: `a & b` или `a.intersection(b)` → `{3}`.

### 22. Что такое разность?

Элементы левого множества, которых нет в правом: `a - b` или `a.difference(b)` → `{1, 2}`. Порядок операндов важен: `b - a` → `{4}`.

### 23. Что такое симметрическая разность?

Элементы, которые есть только в одном из двух множеств. Общие элементы исключаются: `a ^ b` или `a.symmetric_difference(b)` → `{1, 2, 4}`.

Её можно представить как `(a | b) - (a & b)`.

### 24. Какие операции создают новый set, а какие меняют исходный?

| Новый set | Изменение исходного set | Оператор изменения |
| --- | --- | --- |
| `a.union(b)` или `a \| b` | `a.update(b)` | `a \|= b` |
| `a.intersection(b)` или `a & b` | `a.intersection_update(b)` | `a &= b` |
| `a.difference(b)` или `a - b` | `a.difference_update(b)` | `a -= b` |
| `a.symmetric_difference(b)` или `a ^ b` | `a.symmetric_difference_update(b)` | `a ^= b` |

Перечисленные методы, изменяющие исходное множество, возвращают `None`.

### 25. Чем методы операций отличаются от операторов по допустимым аргументам?

Методы вроде `union()` принимают итерируемые источники. Операторы множеств требуют множества: `set` или `frozenset`.

```python
a = {1, 2}
print(a.union([2, 3]) == {1, 2, 3})  # True
# a | [2, 3] вызовет TypeError
```

### 26. Имеет ли значение порядок операндов?

Для объединения, пересечения и симметрической разности состав результата одинаков при перестановке двух множеств. Для разности порядок важен.

## Сравнение и наличие

### 27. Что проверяют in и not in?

Наличие или отсутствие элемента.

```python
numbers = {1, 2, 3}
print(2 in numbers)      # True
print(4 not in numbers)  # True
```

### 28. Что такое подмножество?

Все элементы `a` содержатся в `b`. Проверяется через `a.issubset(b)` или `a <= b`. Равные множества тоже являются подмножествами друг друга.

### 29. Что такое строгое подмножество?

Все элементы `a` есть в `b`, но множества не равны. Проверяется через `a < b`.

### 30. Что такое надмножество?

`a` содержит все элементы `b`: `a.issuperset(b)` или `a >= b`. Для строгого надмножества используют `a > b`.

### 31. Сравнивают ли < и > количество элементов?

Нет. Они проверяют отношение строгого подмножества или надмножества. Одной разницы в количестве недостаточно.

```python
print({1} < {2, 3})  # False: элемент 1 отсутствует справа
```

### 32. Что делает isdisjoint()?

Возвращает `True`, если общих элементов нет. Если есть хотя бы один общий элемент — `False`.

### 33. Зависит ли равенство множеств от порядка?

Нет. Равные множества содержат одинаковые элементы.

### 34. Является ли пустое множество подмножеством любого множества?

Да. У него нет элементов, которые могли бы отсутствовать в другом множестве. Оно строгое подмножество любого непустого множества.

## Хешируемость и frozenset

### 35. Какие объекты могут быть элементами множества?

Хешируемые: например, строки, числа, `frozenset`, кортежи из хешируемых элементов. Обычные `list`, `set`, `dict` не подходят.

### 36. Что означает хешируемость?

У объекта есть хеш, который остаётся неизменным за время его жизни; равные хешируемые объекты должны иметь одинаковый хеш. Одинаковый хеш сам по себе не доказывает равенство объектов.

### 37. Любой ли кортеж хешируется?

Нет. Только кортеж из хешируемых элементов. `(1, 2)` подходит для множества, `(1, [2, 3])` — нет.

### 38. Можно ли создать множество множеств?

Обычный `set` не хешируется, поэтому элементом другого множества быть не может. Можно использовать `frozenset`.

```python
groups = {frozenset({1, 2}), frozenset({3, 4})}
```

### 39. Чем frozenset отличается от set?

`frozenset` неизменяем и хешируется. У него нет методов добавления и удаления элементов. Операции вроде объединения и пересечения доступны и создают новый результат.

### 40. Чем хешируемость отличается от итерируемости?

Итерируемый объект можно перебрать. Хешируемый объект можно использовать как элемент множества или ключ словаря. Это разные свойства: список перебирается, но не хешируется; число хешируется, но не перебирается.

## Копирование, преобразование и comprehension

### 41. Создаёт ли other = numbers копию?

Нет. Переменные ссылаются на одно множество. Для нового множества используют `numbers.copy()` или `set(numbers)`.

### 42. Чем == отличается от is?

`==` сравнивает элементы множеств, `is` проверяет, один ли это объект.

### 43. Как создать множество через comprehension?

```python
numbers = [1, 2, 2, 3, 4]
even_squares = {number ** 2 for number in numbers if number % 2 == 0}
print(even_squares == {4, 16})  # True
```

Общая запись: `{выражение for элемент in источник if условие}`. Условие необязательно. Повторяющиеся результаты объединяются в один элемент.

### 44. Чем set comprehension отличается от dict comprehension?

В set comprehension записано одно выражение элемента: `{x for x in source}`. В dict comprehension — пара через двоеточие: `{x: value for x in source}`.

### 45. Можно ли удалить повторы через set(), сохранив порядок?

`set()` убирает повторы, но порядок исходного источника не сохраняет как гарантию. Если порядок важен, нужен другой способ, например цикл с добавлением первого вхождения в результирующий список.

### 46. Что возвращает sorted() для множества?

Новый отсортированный список. Исходное множество не меняется. Элементы должны поддерживать нужное сравнение либо нужно передать подходящий `key`.

```python
numbers = {3, 1, 2}
print(sorted(numbers))  # [1, 2, 3]
```

### 47. Можно ли добавлять и удалять элементы во время прямого перебора set?

Не следует: изменение размера множества во время перебора может вызвать `RuntimeError`. Можно перебирать копию или создать новое множество через comprehension.

## Что выведет код?

### 48. Строка в add() и update()

```python
data = set()
data.add("ab")
data.update("ab")
print(len(data))
print("ab" in data)
print("a" in data)
```

Ответ:

```text
3
True
True
```

Элементы: `'ab'`, `'a'`, `'b'`. Порядок их вывода не гарантируется.

### 49. Результат метода изменения

```python
numbers = {1, 2}
result = numbers.add(3)
print(numbers == {1, 2, 3})
print(result)
```

Ответ:

```text
True
None
```

### 50. Равные числовые элементы

```python
numbers = {1, 1.0, True}
print(len(numbers))
```

Ответ: `1`. Значения равны и имеют одинаковый хеш, поэтому не создают три разных элемента.

### 51. Подмножество и строгое подмножество

```python
a = {1, 2}
b = {2, 1}
print(a <= b)
print(a < b)
print(a.isdisjoint(b))
```

Ответ:

```text
True
False
False
```

Множества равны, поэтому отношение строгого подмножества не выполняется. Общие элементы есть.

### 52. Симметрическая разность

```python
a = {1, 2, 3}
b = {3, 4}
result = a ^ b
print(result == {1, 2, 4})
print(a == {1, 2, 3})
```

Ответ:

```text
True
True
```

Общий элемент `3` исключён. Исходное множество `a` не изменилось.
