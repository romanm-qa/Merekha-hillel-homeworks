# Шпаргалка: перебираемость, хешируемость и преобразование типов Python

## Два разных свойства

- **Перебираемый объект**: из него можно получать элементы по одному, например в `for`. Это нужно для `list(x)`, `tuple(x)` и `set(x)`.
- **Хешируемый объект**: его можно использовать как элемент множества или ключ словаря. Для `set(x)` хешируемым должен быть **каждый извлечённый элемент**, а не обязательно сам `x`.

| Тип и пример | Перебирается? | Хешируется? | Что извлекается при переборе |
|---|---|---|---|
| `int`: `123` | Нет | Да | — |
| `float`: `1.5` | Нет | Да | — |
| `bool`: `True` | Нет | Да | — |
| `None` | Нет | Да | — |
| `str`: `"abc"` | Да | Да | Символы: `"a"`, `"b"`, `"c"` |
| `bytes`: `b"abc"` | Да | Да | Числа: `97`, `98`, `99` |
| `list`: `[1, 2]` | Да | Нет | Элементы списка |
| `tuple`: `(1, 2)` | Да | Да, если все элементы хешируемы | Элементы кортежа |
| `set`: `{1, 2}` | Да | Нет | Элементы множества, без гарантии порядка |
| `frozenset`: `frozenset({1, 2})` | Да | Да, если все элементы хешируемы | Элементы без гарантии порядка |
| `dict`: `{"a": 1}` | Да | Нет | **Ключи**, не значения |
| `range`: `range(3)` | Да | Да | `0`, `1`, `2` |

`tuple((1, [2]))` создать можно, но такой кортеж **не хешируется** из-за списка внутри. `frozenset` уже по определению содержит только хешируемые элементы.

## Преобразование через конструкторы

В таблице `x` — объект из левого столбца. Конструкторы **создают новый объект**; исходный объект не меняется.

| Исходный `x` | `list(x)` | `tuple(x)` | `set(x)` | `dict(x)` |
|---|---|---|---|---|
| Число `123` | Ошибка: не перебирается | Ошибка | Ошибка | Ошибка |
| Строка `"aba"` | `["a", "b", "a"]` | `("a", "b", "a")` | `{"a", "b"}` | Ошибка: символы не пары ключ–значение |
| Список `[1, 2, 2]` | `[1, 2, 2]` | `(1, 2, 2)` | `{1, 2}` | Ошибка: элементы не пары |
| Кортеж `(1, 2, 2)` | `[1, 2, 2]` | `(1, 2, 2)` | `{1, 2}` | Ошибка: элементы не пары |
| Множество `{1, 2}` | `[1, 2]`* | `(1, 2)`* | `{1, 2}` | Ошибка: элементы не пары |
| Словарь `{"a": 1, "b": 2}` | `["a", "b"]` | `("a", "b")` | `{"a", "b"}` | Копия словаря |
| `range(3)` | `[0, 1, 2]` | `(0, 1, 2)` | `{0, 1, 2}` | Ошибка: элементы не пары |
| `None` | Ошибка: не перебирается | Ошибка | Ошибка | Ошибка |

\* Для исходного множества порядок элементов в полученном списке или кортеже **не гарантирован**.

### Почему `dict(x)` отличается

`dict(x)` ожидает словарь **или** перебираемый объект из пар `(ключ, значение)`. Ключи должны быть хешируемыми:

```python
dict([("a", 1), ("b", 2)])  # {"a": 1, "b": 2}
dict([1, 2])                # ошибка: 1 и 2 не пары
list({"a": 1, "b": 2})    # ["a", "b"]: по умолчанию словарь отдаёт ключи
```

Для значений словаря используем `list(data.values())`, для пар — `list(data.items())`.

### Почему внешний список иногда подходит для `set()`

```python
set([1, 2, 2])   # {1, 2}: берём из списка числа по одному
set([[1, 2]])    # TypeError: единственный элемент — нехешируемый список
{[1, 2]}         # TypeError: пытаемся сразу поместить список в set
```

**Краткое правило:** `list(x)` и `tuple(x)` требуют перебираемый `x`. `set(x)` дополнительно требует хешируемые извлечённые элементы. `dict(x)` требует пары ключ–значение с хешируемыми ключами (либо готовый словарь).
