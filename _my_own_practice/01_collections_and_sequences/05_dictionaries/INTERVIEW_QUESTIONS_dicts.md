# Словари Python — вопросы для собеседования

Сначала попробуй ответить самостоятельно, затем сверься с ответом. Примеры с вопросом «Что выведет код?» сначала разбирай без запуска.

## Основы и создание

### 1. Что такое словарь?

`dict` — изменяемая коллекция пар ключ–значение. По ключу можно получить связанное значение.

```python
student = {"name": "Roman", "age": 25}
print(student["name"])  # Roman
```

### 2. Какие основные свойства словаря?

Ключи уникальны и должны быть хешируемыми. Значения могут повторяться и быть любого типа. Словарь изменяем и сохраняет порядок добавления ключей. Обычный перебор возвращает ключи.

### 3. Как создать пустой словарь? Чем он отличается от пустого множества?

`{}` и `dict()` создают пустой словарь. Пустое множество создаётся через `set()`.

### 4. Какими способами можно создать непустой словарь?

```python
student = {"name": "Roman", "age": 25}
student = dict(name="Roman", age=25)
student = dict([("name", "Roman"), ("age", 25)])
student = dict(zip(["name", "age"], ["Roman", 25]))
```

Также можно использовать dict comprehension.

### 5. Что принимает dict() при создании словаря из пар?

Итерируемый объект, каждый элемент которого содержит ровно два элемента: ключ и значение. Ключ должен быть хешируемым.

### 6. Что произойдёт при повторении ключа?

Останется последнее значение. Позиция уже существующего ключа не изменится.

```python
data = {"name": "Roman", "age": 25, "name": "Alex"}
print(data)  # {'name': 'Alex', 'age': 25}
```

### 7. Могут ли значения повторяться?

Да. Уникальными должны быть ключи.

```python
scores = {"Roman": 90, "Anna": 90}
print(len(scores))  # 2
```

### 8. Что возвращает len() для словаря?

Количество пар ключ–значение, то есть количество ключей.

### 9. Сохраняет ли словарь порядок?

Да, порядок добавления ключей гарантирован языком начиная с Python 3.7. Это не сортировка. Замена значения не перемещает ключ, а удаление и повторное добавление помещают его в конец.

### 10. Учитывает ли == порядок ключей?

Нет. Словари равны, если содержат равные пары ключ–значение.

```python
print({"a": 1, "b": 2} == {"b": 2, "a": 1})  # True
```

### 11. Что будет при dict(zip(keys, values)), если длины источников разные?

Обычный `zip()` остановится на коротком источнике. Лишние элементы длинного источника не попадут в результат.

## Доступ и наличие

### 12. Есть ли у словаря индексы и срезы?

Нет. В `data[0]` число `0` является ключом.

```python
data = {5: "apple", 0: "banana"}
print(data[0])  # banana
```

### 13. Чем [] отличается от get()?

Оба получают значение по ключу. Если ключа нет, `[]` вызывает `KeyError`, а `get()` возвращает `None` или переданное значение по умолчанию.

### 14. Добавляет ли get() отсутствующий ключ?

Нет. Он только возвращает результат.

### 15. Что проверяет in для словаря?

Наличие ключа. Для проверки значения используют `data.values()`, для проверки пары — `data.items()`.

```python
student = {"name": "Roman"}
print("name" in student)                      # True
print("Roman" in student)                     # False
print("Roman" in student.values())            # True
print(("name", "Roman") in student.items())   # True
```

### 16. Что вернёт get(), если ключ есть со значением None?

`None`, даже если передан другой default. Default используется только при отсутствии ключа.

```python
data = {"city": None}
print(data.get("city", "Unknown"))     # None
print(data.get("country", "Unknown"))  # Unknown
```

### 17. Как отличить отсутствующий ключ от ключа со значением None?

Проверить наличие ключа через `in`. Один вызов `get(key)` эти случаи не различает.

## Изменение и удаление

### 18. Как добавить пару или заменить значение?

Через `data[key] = value`: отсутствующий ключ добавляется, существующий получает новое значение.

### 19. Что делает update() и что возвращает?

Добавляет новые пары и заменяет значения совпадающих ключей. Меняет исходный словарь и возвращает `None`.

### 20. Какие источники принимает update()?

Другой словарь, итерируемый объект с парами и именованные аргументы.

```python
data = {"age": 25}
data.update({"age": 26})
data.update([("city", "Kyiv")])
data.update(name="Roman")
```

### 21. Что делает setdefault()?

Возвращает значение существующего ключа. Если ключа нет, добавляет его с default и возвращает добавленное значение. Без default использует `None`. Существующее значение не заменяет.

### 22. Чем get() отличается от setdefault()?

Если ключ отсутствует, `get()` только возвращает default, а `setdefault()` ещё добавляет пару в словарь.

### 23. Чем pop() отличается от del?

Оба удаляют пару по ключу. `pop()` возвращает удалённое значение и может принимать default. `del` — инструкция, которая не возвращает значение. Без обработки отсутствующего ключа оба вызывают `KeyError`.

### 24. Что делает popitem()?

Удаляет последнюю добавленную пару и возвращает кортеж `(ключ, значение)`. Для пустого словаря вызывает `KeyError`.

### 25. Чем popitem() словаря отличается от pop() множества?

`dict.popitem()` удаляет последнюю добавленную пару. `set.pop()` удаляет произвольный элемент: порядок добавления множество не гарантирует.

### 26. Что делает clear()?

Удаляет все пары из существующего словаря и возвращает `None`. Сам объект словаря остаётся.

### 27. Что не так с data = data.update(other)?

`update()` изменит словарь, но вернёт `None`. После присваивания переменная `data` будет ссылаться на `None`.

## Перебор и представления

### 28. Что получаем при for item in data?

Ключи в порядке добавления.

### 29. Как перебрать ключи, значения и пары?

```python
data = {"name": "Roman", "age": 25}
for key in data:
    print(key)
for value in data.values():
    print(value)
for key, value in data.items():
    print(key, value)
```

### 30. Что возвращают keys(), values() и items()?

Динамические представления: `dict_keys`, `dict_values`, `dict_items`. При переборе `items()` получаем кортежи `(ключ, значение)`.

### 31. Почему представления называют динамическими?

Они связаны с исходным словарём и отражают его изменения, даже если были получены до этих изменений.

### 32. Можно ли получить data.keys()[0]?

Нет: представления не поддерживают доступ по индексу. Можно создать список: `list(data.keys())[0]`, если словарь непустой.

### 33. Чем list(data) отличается от list(data.items())?

Первое создаёт список ключей, второе — список кортежей `(ключ, значение)`.

### 34. Можно ли менять словарь во время перебора?

Значения существующих ключей заменять можно. Добавлять и удалять ключи при прямом переборе словаря или представлений не следует: возможен `RuntimeError` или некорректный перебор. Для удаления можно перебирать отдельный список ключей.

```python
scores = {"Roman": 80, "Alex": 70}
for name in list(scores):
    if scores[name] < 80:
        del scores[name]
```

## Копирование и объединение

### 35. Создаёт ли alias = data копию?

Нет. Обе переменные ссылаются на один объект. Изменение через одну переменную видно через другую.

### 36. Чем == отличается от is?

`==` сравнивает содержимое, а `is` проверяет, один ли это объект.

### 37. Как создать поверхностную копию?

`data.copy()` или `dict(data)`. Внешний словарь будет новым, но вложенные объекты останутся общими.

### 38. Чем изменение вложенного списка отличается от его замены в копии?

При поверхностном копировании `.append()` меняет общий список. Присваивание нового списка ключу копии меняет только эту копию.

```python
original = {"courses": ["Python"]}
copied = original.copy()
copied["courses"].append("SQL")
print(original)  # {'courses': ['Python', 'SQL']}
copied["courses"] = ["Docker"]
print(original)  # {'courses': ['Python', 'SQL']}
```

### 39. Когда нужен deepcopy()?

Когда нужна независимая копия вложенных изменяемых коллекций. `deepcopy()` из модуля `copy` рекурсивно копирует такие коллекции.

### 40. Как объединить два словаря?

| Способ | Результат |
| --- | --- |
| `left \| right` | Новый словарь |
| `{**left, **right}` | Новый словарь |
| `left \|= right` | Изменяет `left` |
| `left.update(right)` | Изменяет `left`, возвращает `None` |

### 41. Какое значение побеждает при совпадении ключей?

Значение справа или указанное позже. Поэтому `left | right` и `right | left` могут отличаться.

### 42. Объединение словарей выполняет глубокое копирование?

Нет. Вложенные объекты не копируются рекурсивно. Вложенный словарь по совпадающему ключу заменяется целиком, а не объединяется автоматически.

## Comprehension

### 43. Что такое dict comprehension?

Краткая запись создания нового словаря из итерируемого источника:

```python
numbers = [1, 2, 3]
squares = {number: number ** 2 for number in numbers}
```

### 44. Чем if после for отличается от if/else перед for?

`if` после `for` фильтрует элементы. `if/else` в выражении значения выбирает значение для каждого элемента.

```python
scores = {"Roman": 80, "Alex": 70}
passed = {name: score for name, score in scores.items() if score >= 80}
statuses = {
    name: "Passed" if score >= 80 else "Failed"
    for name, score in scores.items()
}
```

### 45. Можно ли поменять ключи и значения местами?

Да: `{value: key for key, value in data.items()}`. Новые ключи должны быть хешируемыми. Если значения исходного словаря повторяются, часть пар потеряется из-за совпадения новых ключей.

## Ключи и вложенные данные

### 46. Какие объекты могут быть ключами?

Хешируемые: например, строки, числа, `frozenset`, кортежи из хешируемых элементов. Обычные `list`, `set`, `dict` ключами быть не могут.

### 47. Что означает хешируемость?

У объекта есть хеш, который не меняется за время его жизни; равные хешируемые объекты должны иметь одинаковый хеш. Такие объекты можно использовать как ключи словаря и элементы множества. Одинаковый хеш сам по себе не означает равенство объектов.

### 48. Любой ли кортеж можно использовать как ключ?

Нет. Все его элементы должны быть хешируемыми. `(1, 2)` подходит, `(1, [2, 3])` — нет.

### 49. Хешируемость и итерируемость — одно и то же?

Нет. Число хешируется, но не перебирается. Список перебирается, но не хешируется. Строка и перебирается, и хешируется.

### 50. Почему 1, 1.0 и True не создают три разных ключа?

Они равны и имеют одинаковый хеш, поэтому относятся к одной записи.

```python
data = {1: "int", 1.0: "float", True: "bool"}
print(data)       # {1: 'bool'}
print(len(data))  # 1
```

### 51. Как получить значение из вложенного словаря или списка?

```python
student = {"courses": ["Python"], "address": {"city": "Kyiv"}}
print(student["courses"][0])       # Python
print(student["address"]["city"])  # Kyiv
```

Сначала получаем значение внешнего словаря, затем обращаемся к вложенному объекту.

### 52. Всегда ли безопасно data.get('address', {}).get('city')?

Нет. Если `address` существует со значением `None` или другим объектом без метода `get()`, возникнет `AttributeError`. Default `{}` работает только при отсутствии ключа. Когда тип данных неизвестен, можно проверить `isinstance(address, dict)`.

## Что выведет код?

### 53. Присваивание результата update()

```python
data = {"a": 1}
result = data.update({"a": 2, "b": 3})
print(data)
print(result)
```

Ответ:

```text
{'a': 2, 'b': 3}
None
```

### 54. Существующий ключ и setdefault()

```python
data = {"city": None}
print(data.setdefault("city", "Kyiv"))
print(data)
```

Ответ:

```text
None
{'city': None}
```

Ключ уже есть, поэтому его значение не заменяется.

### 55. Представление и список

```python
data = {"a": 1}
view = data.keys()
snapshot = list(data)
data["b"] = 2
print(list(view))
print(snapshot)
```

Ответ:

```text
['a', 'b']
['a']
```

### 56. Замена значения и popitem()

```python
data = {"a": 1, "b": 2}
data["a"] = 10
print(data.popitem())
print(data)
```

Ответ:

```text
('b', 2)
{'a': 10}
```

Замена значения ключа `a` не переместила его в конец.

### 57. Обмен ключей и значений

```python
scores = {"Roman": 90, "Anna": 90, "Alex": 80}
result = {score: name for name, score in scores.items()}
print(result)
```

Ответ:

```text
{90: 'Anna', 80: 'Alex'}
```

Ключ `90` повторился, поэтому осталось последнее значение — `'Anna'`.
